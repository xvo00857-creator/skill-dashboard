# Skill 评测看板（公开迁移版）

本仓库用于 GitHub Pages，保留现有页面、比较筛选和抓取日期筛选。
迁移不是重新抓取、执行 Case 或评分；页面数据更新时间不因发布而改变。

## 目录

- `site/`：唯一网站发布目录。页面、数据、附件都属于公开内容。
- `tools/`：公开副本准备与启发式敏感扫描工具；不执行任何评测附件代码。
- `tests/`：数据加载与筛选回归测试。
- `public-audit.json`：首次迁移的扫描结果与脱敏记录，不含凭证原值。

## 首次发布

1. 在你自己的 GitHub 账号下建立公开仓库（建议名 `skill-dashboard`）。
2. 上传本目录内容，不要上传旧项目整目录、凭证、缓存、日志或原始归档。
3. 在仓库 Settings → Pages → Build and deployment，将 Source 选为 GitHub Actions。
4. 推送到 `main` 或手动运行 Publish dashboard。
5. 等 Actions 部署成功，使用部署记录返回的实际网址验收。

自动化只发布 `site/`；不会刷新飞书数据，也不会修改原妙搭应用。

## 后续维护

修改 `site/index.html` 调整页面；数据文件和附件需一起更新。不要直接覆盖为未经扫描的原始快照。

在本目录执行：

```sh
python3 tools/audit_public.py site
node tests/comparison.mjs
node tests/crawl-date.mjs
node tests/refresh.mjs
```

通过后提交、推送，GitHub Actions 会重新发布。扫描失败时不要绕过门禁。
扫描只是规则检测，不保证识别所有隐私、图片/PDF 内的信息和未识别凭证。

公开副本对疑似凭证（含示例）脱敏，并从压缩附件排除环境配置文件；原数据保留在本地原项目中。
脱敏附件可能需要使用者提供自己的配置才能运行，不能视为与原始产物字节一致。

## 外部资源与权限

页面保留原始豆包/飞书/CDN 来源链接。公开本网站不会解除来源权限，也不会延长临时链接有效期。
已有外部附件未在本次迁移中全量重新下载；可访问性尚未逐项验证。
未来更新飞书源表格仍需合法授权，网站本身不会存储或使用你的飞书 Token。
