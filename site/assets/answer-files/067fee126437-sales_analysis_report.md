## 八、方法说明与 Skill 适用性

随消息上传的 Skill 为 `hv-analysis`（横纵分析法），面向产品/公司/概念/人物的深度研究，核心流程为联网信息收集→纵向生命叙事→横向竞品对比→万字 PDF 报告。本次任务为 5 行销售 CSV 的清洗与汇总，不涉及研究对象、竞品或联网调研，Skill 的主体方法论不适用。实际影响本次结果的 Skill 规则为：

1. **"绝不编造"原则**（SKILL.md 写作风格-绝对禁区）：无法确认的清洗映射不做推测，全部列入数据质量清单并标注"可确认"状态。
2. **"所有关键事实标注来源"**（SKILL.md 质检清单）：所有汇总值均可回溯至原始 CSV 行号，XLSX 中保留原始值对照列。
3. **PDF 交付要求**（SKILL.md 第五步）：Skill 自带 `scripts/md_to_pdf.py` 基于 WeasyPrint，但当前环境缺少系统库 `libgobject-2.0-0`（Pango/GLib），PDF 转换未能完成，错误信息已保留。报告以 Markdown 形式交付。
