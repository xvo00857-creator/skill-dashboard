## 四、风险分级与证据

### 发现 F-01【Critical】疑似服务令牌被盗用导致数据外泄

| 项目 | 内容 |
|---|---|
| 风险等级 | **Critical（严重）** |
| 涉及系统 | api → db（跨系统联动） |
| 涉及 IP | 203.0.113.8 |

**证据链**：

- 第 4 行：`2026-08-12T09:04:02Z, api, high, token_scope_mismatch, service-a, 203.0.113.8`
  - service-a 的令牌发起了超出其授权范围的 API 请求，被网关标记为 high。
- 第 5 行：`2026-08-12T09:07:30Z, db, critical, unexpected_export, unknown, 203.0.113.8`
  - 同一 IP 在 3 分 28 秒后对数据库执行了未预期的导出操作，用户字段为 `unknown`。

**分析**：同一来源 IP 在短时间内先触发令牌范围不匹配，随后以未知身份执行数据库导出，构成完整的"令牌滥用 → 越权 → 数据外传"攻击链。`unknown` 用户表明导出操作未关联到有效身份，可能为令牌被冒用或身份伪造。

**潜在影响**：敏感数据泄露；合规风险（如个人信息保护法、数据安全法相关要求）。
