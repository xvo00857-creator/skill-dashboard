## 3. 各阶段详细记录

### 阶段 1：认知 Awareness

- **触点 Touchpoints**：同事朋友圈分享、小红书"AI 写作工具"测评、播客口播广告
- **用户行为**：刷到测评帖 → 点进主页 → 记住产品名
- **想法与疑问**："又一个 AI 写作？和我现在用的有啥不一样？""真能省时间吗？"
- **情绪**：好奇但怀疑 😐 ｜ 情绪值 5/10
- **痛点**：
  - 同类工具太多，记不住差异化
  - 测评内容像广告，不信任
- **机会**：
  - 用"前后对比"式真实案例展示省时效果
  - 在内容工作者聚集渠道投放可验证的 demo

### 阶段 2：考虑 Consideration

- **触点 Touchpoints**：产品官网、应用商店详情页、竞品对比帖、免费试用入口
- **用户行为**：打开官网看功能 → 对比 2–3 个竞品 → 查看定价 → 决定是否试用
- **想法与疑问**："免费版够用吗？""数据会不会泄露？""写出来的东西会不会很 AI 腔？"
- **情绪**：谨慎评估 🤔 ｜ 情绪值 4/10
- **痛点**：
  - 官网文案笼统，看不到真实写作效果
  - 定价页复杂，不确定哪档适合自己
  - 担心公司数据合规
- **机会**：
  - 官网提供"输入你的题目→实时生成"的免登录试写
  - 明确展示数据安全与合规说明
  - 简化定价，突出"按篇/按月"两档

### 阶段 3：获取 Acquisition

- **触点 Touchpoints**：应用商店下载、手机号/微信注册、引导页、付费墙
- **用户行为**：下载 App → 注册 → 遇到免费额度限制 → 决定是否付费
- **想法与疑问**："怎么刚注册就要付费？""先免费试试再说。"
- **情绪**：略急躁，注册摩擦感 😤 ｜ 情绪值 3/10
- **痛点**：
  - 注册步骤多，验证码延迟
  - 免费额度仅 1–2 次，不足以判断价值
  - 首次付费墙出现过早
- **机会**：
  - 支持一键登录，减少注册字段
  - 新用户给予"首日 10 次"体验额度
  - 付费墙推迟到用户完成第一篇完整稿件后

### 阶段 4：上手 Onboarding

- **触点 Touchpoints**：新手引导浮层、模板库、第一次生成、编辑器
- **用户行为**：选模板 → 输入题目 → 生成初稿 → 手动修改 → 导出/复制
- **想法与疑问**："生成的结构还行，但这段话太套话了，怎么改？""在哪调风格？"
- **情绪**：初见成效的小兴奋 + 修改时的困惑 😐→🙂 ｜ 情绪值 6/10
- **痛点**：
  - 引导浮层一次性弹出，记不住
  - "风格/语气"调节入口隐蔽
  - 生成内容需要大改，不确定是提示词问题还是模型问题
- **机会**：
  - 用"第一篇稿"交互式任务代替静态浮层
  - 把"风格/长度/语气"做成生成前显眼的三步选择
  - 提供"选中段落→一键改写"的就近操作

### 阶段 5：参与 Engagement

- **触点 Touchpoints**：日常写作、历史文档、收藏模板、桌面端网页、快捷键
- **用户行为**：工作日每天打开 → 用模板快速起稿 → 多轮改写 → 跨设备继续编辑
- **想法与疑问**："手机上写一半，电脑上能接着改吗？""上次那个好用的模板在哪？"
- **情绪**：顺手时满意，打断时烦躁 🙂 ｜ 情绪值 7/10
- **痛点**：
  - 手机竖屏编辑区局促，改长文不便
  - 手机与电脑端不同步，需手动复制
  - 模板收藏入口深，重复找模板
- **机会**：
  - 竖屏聚焦"生成+轻改"，横屏聚焦"多轮编辑+排版"，两端自适应
  - 云端自动同步草稿
  - 常用模板置顶，支持个人模板库

### 阶段 6：留存 Retention

- **触点 Touchpoints**：推送通知、订阅续费提醒、周报功能、更新日志
- **用户行为**：持续使用 2–3 周后频率稳定 → 遇到额度/涨价提醒 → 决定续费或流失
- **想法与疑问**："这个月好像没怎么用，值不值续费？""有没有更便宜的？"
- **情绪**：续费前犹豫，被打扰时反感 😕 ｜ 情绪值 5/10
- **痛点**：
  - 感知不到"累计省了多少时间"
  - 推送频率高、内容不相关
  - 涨价或额度调整引发不信任
- **机会**：
  - 每月生成"写作省时报告"，量化价值
  - 推送改为基于使用场景的智能提醒
  - 老用户价格保护，额度调整提前透明告知

### 阶段 7：拥护 Advocacy

- **触点 Touchpoints**：分享按钮、邀请有礼、团队版、社群
- **用户行为**：被同事问起时推荐 → 偶尔主动分享作品 → 考虑推荐团队采购
- **想法与疑问**："推荐给同事有没有好处？""团队版数据能隔离吗？"
- **情绪**：满意且愿意推荐，但缺少主动动机 🙂 ｜ 情绪值 8/10
- **痛点**：
  - 没有顺手的"分享成果"入口
  - 邀请奖励吸引力弱
  - 团队版能力不清晰
- **机会**：
  - 稿件完成页提供"晒一晒我的写作效率"分享卡
  - 邀请双方各得额度，降低推荐门槛
  - 明确团队版的协作与数据隔离能力

## 4. 关键时刻（Critical Moments）

| 类型 | 发生阶段 | 描述 |
|---|---|---|
| **Aha 时刻** | 上手 Onboarding | 用户输入题目后 30 秒内得到结构完整的初稿，并发现"选中即改写"能快速消除套话——第一次真切感到"省时间了" |
| **真相时刻 1** | 获取 Acquisition | 注册后首次遇到付费墙：若免费额度不足以完成一篇完整稿件，用户大概率流失 |
| **真相时刻 2** | 留存 Retention | 首次续费决策：若用户无法感知累计价值，容易转向竞品或取消订阅 |
| **流失触发点 1** | 获取 Acquisition | 注册流程过长 + 过早付费墙 |
| **流失触发点 2** | 上手 Onboarding | 生成内容质量不达预期且不知如何调整（提示词/风格入口隐蔽） |
| **流失触发点 3** | 参与 Engagement | 跨设备不同步，导致在主力设备上放弃使用 |

## 6. 优先级改进建议

### 速赢（Quick Wins，低成本高影响）

1. **延后付费墙 + 新用户首日 10 次额度**：直接作用于"真相时刻 1"，预计可提升注册→首次完成稿件的转化。
2. **生成前增加"风格/长度/语气"三步显眼选择**：降低上手期"不会调"的困惑，减少首轮流失。
3. **稿件完成页增加"晒效率"分享卡**：把自然推荐行为产品化，低成本撬动拥护阶段。

### 深耕（Deep Investment，高投入高回报）

1. **云端草稿同步 + 竖屏/横屏自适应分工**：竖屏聚焦生成与轻改，横屏聚焦多轮编辑与排版，解决跨端流失触发点。
2. **每月"写作省时报告"**：量化价值，直接支撑续费决策（真相时刻 2）。
3. **免登录实时试写 + 真实案例库**：提升认知与考虑阶段的信任与转化。

### 影响最大的痛点（按对转化/留存影响排序）

1. 注册后过早付费墙 + 体验额度不足（影响获取→上手转化）
2. 跨设备不同步（影响参与期留存）
3. 生成内容不会调、风格入口深（影响上手期 Aha 达成）
4. 续费时感知不到价值（影响长期留存）
