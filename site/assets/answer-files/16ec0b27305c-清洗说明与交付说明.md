## 二、Skill 真实能力边界（以 SKILL.md 原文为准）

SKILL.md 定义且仅定义了以下三步：

| 步骤 | 内容 | 关键实现 |
|---|---|---|
| Step1 | 读取 Excel 所有工作表，纵向合并（`pd.concat`），总行数过大时转 Parquet 再读回 | `pd.ExcelFile` → 逐 sheet `read_excel` → `concat` → `to_parquet` → `read_parquet` |
| Step2 | 对**指定的一个文本列**，用正则 `[一-鿿]` 提取所有中文字符，拼接后回写；非中文字符（含 `#`、`-`、数字、英文字母、标点、空格等）全部移除；空值保持原样，清洗后无中文字符则置为空字符串 | `re.findall(r'[一-鿿]', s)` |
| Step3 | 将清洗后的 DataFrame 保存为单个 `.xlsx` 文件（`index=False`），打印本地路径 | `df.to_excel(output_path, index=False)` |

### 影响交付结果的关键 SKILL.md 规则（至少一条）

**规则：Step2 的清洗口径是"仅保留中文字符"，即正则 `[一-鿿]`，会移除数字、字母、`#`、`-` 及所有标点。**

这条规则直接决定了清洗结果的形态：
- 如果目标列包含金额、编号、日期等含数字的内容，这些数字会被**全部删除**，而非保留或格式化。
- 例如 `"订单#A001-合计3,500元"` 清洗后变为 `"订单合计元"`，数字和字母均丢失。
- 因此该 Skill 的设计用途是清洗**纯中文文本列**（如备注、名称、分类等），**不适合**直接用于金额、编号、日期等数值/混合列。

## 四、清洗口径说明

### 4.1 文本列清洗（Step2，严格按 SKILL.md）

- **作用对象**：用户指定的一个列（命令行第二个参数，默认为 `target_column`）。
- **清洗规则**：对每个单元格值，用正则 `[一-鿿]` 提取全部中文字符并拼接。
- **移除内容**：数字（0-9）、英文字母（a-z, A-Z）、`#`、`-`、下划线、标点符号、空格、emoji 等所有非中文字符。
- **空值处理**：`NaN`/空值保持为 `NaN`（不转换为空字符串）。
- **清洗后无中文**：若原值不含任何中文字符（如纯数字 `"123"`），结果置为空字符串 `""`。
- **不可逆**：该清洗为破坏性操作，原始值中的数字和字母无法从清洗结果恢复。

### 4.2 多工作表合并（Step1，严格按 SKILL.md）

- 读取 Excel 中**所有**工作表，按行纵向拼接（`pd.concat(ignore_index=True)`）。
- 不同工作表的列名若不一致，pandas 会取并集，缺失列填 `NaN`。
- 总行数超过阈值（脚本中设为 100,000 行）时，先写 Parquet 再读回；否则直接在内存中处理。
- **注意**：SKILL.md 未给出具体行数阈值，100,000 行为脚本中的合理默认值，可按需调整。

### 4.3 输出（Step3，严格按 SKILL.md）

- 单个 `.xlsx` 文件，不含行索引。
- 输出为合并后的全量明细，不区分原工作表来源（除非原数据本身有来源列）。

## 六、可复核的步骤与公式

### 6.1 核心清洗逻辑（可独立复核）

```python
import re
def clean_chinese_text(text):
    if pd.isna(text):
        return text
    s = str(text)
    chinese_chars = re.findall(r'[一-鿿]', s)
    cleaned = ''.join(chinese_chars)
    return cleaned if cleaned else ''
```

在 Excel 中等效复核方式（假设原文本在 A2）：
```
=TEXTJOIN("",TRUE,IF(UNICODE(MID(A2,ROW(INDIRECT("1:"&LEN(A2))),1))>=19968,
  IF(UNICODE(MID(A2,ROW(INDIRECT("1:"&LEN(A2))),1))<=40959,
    MID(A2,ROW(INDIRECT("1:"&LEN(A2))),1),""),""))
```
（数组公式，Unicode 范围 19968–40959 即 `一` 到 `鿿`）

### 6.2 多表合并逻辑

```python
xls = pd.ExcelFile(file_path)
dfs = [pd.read_excel(xls, sheet_name=s) for s in xls.sheet_names]
df_all = pd.concat(dfs, ignore_index=True)
```

### 6.3 Parquet 转换判断

```python
if len(df_all) > ROW_THRESHOLD:   # ROW_THRESHOLD = 100000
    df_all.to_parquet(parquet_path, engine='pyarrow', index=False)
    df = pd.read_parquet(parquet_path)
else:
    df = df_all
```
