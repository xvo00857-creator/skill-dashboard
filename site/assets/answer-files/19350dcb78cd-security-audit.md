## 四、风险分级

### 风险 1（严重 / Critical）：疑似数据库未授权导出（数据外泄）

- 证据：
  - 行5：`2026-08-12T09:07:30Z,db,critical,unexpected_export,unknown,203.0.113.8`
  - 行4（前驱）：`2026-08-12T09:04:02Z,api,high,token_scope_mismatch,service-a,203.0.113.8`
- 影响：数据库内容可能已被批量导出，存在敏感数据泄露风险；`unknown` 用户表明身份认证环节存在绕过或失效。
- 处置建议：
  1. 立即吊销/轮换 `service-a` 的令牌及相关密钥。
  2. 核查 09:04～09:10 期间数据库导出操作的具体内容、表范围与数据量。
  3. 在出口流量/对象存储访问日志中确认导出数据是否已外发至 203.0.113.8 或其他地址。
  4. 检查 `service-a` 令牌的签发记录、最近一次使用位置，确认是否泄露。
  5. 对数据库访问控制策略进行复盘，确保令牌 scope 与实际所需最小权限一致。

### 风险 2（高 / High）：服务令牌范围越权

- 证据：行4 `token_scope_mismatch,service-a,203.0.113.8`
- 影响：服务账号令牌被用于其授权范围之外的操作，是风险 1 的可能入口。
- 处置建议：
  1. 审计 `service-a` 的令牌 scope 配置，按最小权限原则收窄。
  2. 在 API 网关层对 scope 不匹配请求增加实时告警与自动阻断。
  3. 排查 203.0.113.8 是否属于已知可信地址段；若否，将其加入临时黑名单并监控。

### 风险 3（中 / Medium）：admin 账号短时登录失败

- 证据：行2、行3，同一 IP 198.51.100.23 在 4 秒内对 admin 连续两次登录失败。
- 影响：当前未成功，但若持续可能导致管理员账号被攻破。
- 处置建议：
  1. 对 admin 账号启用登录失败锁定/速率限制（如 5 次失败锁定 15 分钟）。
  2. 为 admin 启用多因素认证（MFA）。
  3. 监控 198.51.100.23 后续是否继续尝试或切换账号。

### 风险 4（低 / Low）：日志记录畸形

- 证据：行6 `2026-08-12T09:09:00Z,web,,malformed_record,,`
- 影响：缺失 severity/user/source_ip 影响审计完整性；若为日志注入或篡改，可能掩盖其他攻击痕迹。
- 处置建议：
  1. 检查 web 系统日志采集管道的格式化逻辑，确认是否为程序缺陷。
  2. 检查该时间点前后是否有日志缺失或被截断。
  3. 对日志写入增加输入校验，防止换行符/分隔符注入。
