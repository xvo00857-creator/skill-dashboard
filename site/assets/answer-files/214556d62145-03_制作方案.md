## 二、完整脚本（逐场景）

### 场景 1 — A-ROLL（5 秒）钩子
- **画面**：清晨山间露营地，年轻女性举起哑光黑便携咖啡机对镜头微笑，另一只手端不锈钢杯，金色阳光洒入。
- **配音**："想在山顶，喝一杯现磨咖啡？"
- **屏幕文字**：下三分之一字幕条"随咖 SUIKA"（咖啡金底 / 奶油白字）
- **转场**：硬切

### 场景 2 — FULL SCREEN B-ROLL（10 秒）核心卖点
- **画面**：纯动态图形，无人物。奶油白背景。
- **配音**："随咖便携咖啡机，九十秒现磨萃取，仅重三百八十克，比一瓶矿泉水还轻。"
- **屏幕文字**：
  - "90秒"（深棕粗体大字）+ "现磨萃取"（咖啡金中字）
  - "380g"（深棕粗体）+ 极简水瓶线图标
  - 底部信息条"USB-C充电 · 一键操作"
  - 咖啡杯填充动画
- **转场**：硬切

### 场景 3 — A-ROLL + OVERLAY（5 秒）使用场景
- **画面**：分屏，人物在左 40%（户外桌前单手按按钮），右侧 60% 内容区。
- **配音**："一键操作，在哪都是你的咖啡馆。"
- **屏幕文字**：
  - "一键萃取"（咖啡金粗体）
  - 三步图标：加水 → 放胶囊 → 按一下
- **转场**：硬切

### 场景 4 — FULL SCREEN B-ROLL（10 秒）品牌收尾 / CTA
- **画面**：纯动态图形，深咖啡棕背景。
- **配音**："随咖，让好咖啡，随你出发。立即体验。"
- **屏幕文字**：
  - "随咖"（奶油白粗体大字）+ "SUIKA"（咖啡金小字宽距）
  - "一杯好咖啡 随手可得"（奶油白中字）
  - "立即体验"按钮（咖啡金底 / 奶油白字）
  - 金色细线装饰
- **转场**：品牌名定格，音乐收束

### 脚本字数与语速核算
- 配音总字数：约 62 个汉字
- 按中文女声约 200 字/分钟（≈3.3 字/秒）计算：62 ÷ 3.3 ≈ 19 秒
- 加上句间停顿与画面留白，总时长约 30 秒，符合 config.duration_sec=30
- 注：prompt-optimizer.md 的 150 words/min 为英文语速基准，中文配音按 200 字/分钟核算

## 四、字幕方案

### 4.1 硬字幕（烧录进视频）
- HeyGen Video Agent 自动生成的 captions 将烧录在视频中
- prompt 中已要求：所有配音行均配中文字幕，居中偏下，位于下三分之一区域上方
- 字号：不小于画面高度的 5%（约 96px @1080p），高对比配色

### 4.2 外挂字幕（可编辑）
- 随片交付 `02_字幕.srt`（标准 SRT 格式，UTF-8 编码）
- 可在任意播放器加载、可在任意文本编辑器中修改文字与时间轴
- 四条字幕对应四个场景，时间码与分镜表一致

### 4.3 中文字体与可读性
- 字体：中文粗体无衬线（思源黑体 / 苹方 Bold 量级）
- 颜色：深棕 #2C1810 配奶油白底，或奶油白 #FAF6F0 配深棕底
- 对比度：深棕(#2C1810)与奶油白(#FAF6F0)的对比度约 12.6:1，远超 WCAG AAA 标准 7:1

## 五、配音与音效方案

### 5.1 配音
- **人声**：中文女声，温暖自然，语速约 200 字/分钟
- **风格**：像朋友推荐好物，不喊叫不播音腔
- **处理**：关键数字（"九十秒""三百八十克"）前略停顿；结尾"立即体验"有号召力
- **语言**：全程中文普通话，由 HeyGen Video Agent 自动选择中文语音

### 5.2 音乐
- 轻快原声吉他拨弦 + 轻柔电子节拍
- 参考风格：日系生活方式广告配乐
- 能量弧线：好奇（吉他轻拨）→ 惊喜（加入节拍）→ 向往（旋律展开）→ 行动（干净收束）
- prompt 中 MUSIC 段已写明方向

### 5.3 音效（建议后期叠加，HeyGen Video Agent 自动处理部分）
- 场景 2：咖啡液注入杯中的轻柔"咕嘟"声（配合咖啡杯填充动画）
- 场景 3：按钮按下的轻微"咔嗒"声
- 场景 4：品牌名出现时的轻柔"叮"声
- 注：HeyGen Video Agent 为一次性 prompt 生成，音效精细控制有限；如需精确音效，建议下载后用剪辑软件叠加

## 六、新增约束导致的方案变化

### 约束 1：手机端可读
| 变化点 | 具体措施 |
|--------|----------|
| 画幅 | 选用 portrait（9:16），config.orientation="portrait"，分辨率 1080×1920 |
| 字号 | 屏幕文字最小占画面高度 5%，核心数字"90秒""380g"占画面约 35% |
| 留白 | 选用 Geometric Bold 风格，强制 60% 留白，避免手机小屏信息过载 |
| 单一焦点 | 每帧只有一个视觉焦点，手机端一眼抓住重点 |
| 配色 | 仅 3 色，高对比，户外强光下仍可辨识 |

### 约束 2：可编辑
| 变化点 | 具体措施 |
|--------|----------|
| 脚本/prompt | 以纯文本 .txt 交付，可直接用文本编辑器修改后重新调用 API |
| 字幕 | 交付标准 SRT 文件，时间轴与文字均可独立编辑，无需重新生成视频 |
| API 脚本 | 交付 shell 脚本，变量化配置（时长、画幅、prompt 文件路径），改参数即可重跑 |
| 方案文档 | Markdown 格式，可编辑可版本管理 |

### 约束 3：中文信息不丢失
| 变化点 | 具体措施 |
|--------|----------|
| prompt 语言 | 整个 prompt 以中文撰写 VOICEOVER 与 CRITICAL ON-SCREEN TEXT，不依赖英文转译 |
| 关键文字清单 | CRITICAL ON-SCREEN TEXT 段逐条列出必须原样出现的中文字符串，防止 Agent 概括或改写 |
| 配音语言 | NARRATION STYLE 明确"全程中文普通话" |
| 文件编码 | 所有文本文件以 UTF-8 保存，SRT 为标准 UTF-8 |
| 数字处理 | 配音中数字写为中文汉字（"九十秒""三百八十克"），屏幕上用阿拉伯数字（"90秒""380g"），符合 prompt-optimizer.md "spell out numbers in VO, use figures on screen" 规则 |

### 约束 4：无障碍 / 低性能设备兼容
| 兼容方案 | 具体措施 |
|----------|----------|
| **低性能版本** | 提供 720p（720×1280）版本生成选项：将 config 不变，在下载后用 ffmpeg 转码为 720p；或直接接受 HeyGen 默认输出后转码。720p 文件更小、解码压力更低，适合低端手机 |
| **字幕双保险** | 硬字幕（烧录，播放器无需支持字幕轨）+ 外挂 SRT（可关闭/可调样式），听障用户可读取 |
| **高对比配色** | 深棕/奶油白对比度 12.6:1，超过 WCAG AAA，弱视用户可读 |
| **无闪烁动效** | 动效仅使用 SLAMS/CASCADE/fades/types on/COUNTS UP/DRAWS，无频闪、无高频闪烁，降低光敏风险 |
| **大字号** | 最小文字≥画面高度 5%，配合高对比，适合视力不佳用户 |
| **语音清晰** | 中文女声标准普通话，语速适中（200 字/分钟），背景音乐不压过人声 |
| **音频独立信息** | 所有关键信息（产品名、卖点、CTA）同时以配音+字幕呈现，不依赖单通道 |
