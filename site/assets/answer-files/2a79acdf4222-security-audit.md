## 4. 风险分级与证据

### 4.1 严重（Critical）— 疑似数据外泄

**事件**：2026-08-12T09:07:30Z | db | critical | unexpected_export | user=unknown | src=203.0.113.8

**原始记录**：

```
2026-08-12T09:07:30Z,db,critical,unexpected_export,unknown,203.0.113.8
```

**分析**：

- 数据库发生未预期的导出操作，执行用户为 `unknown`（未认证/匿名）
- 该 IP 在 3 分 28 秒前刚发生 `token_scope_mismatch` 事件，构成可疑攻击链：令牌权限异常 → 数据库导出
- 可能影响：敏感数据外泄

### 4.2 高（High）— 令牌权限越权

**事件**：2026-08-12T09:04:02Z | api | high | token_scope_mismatch | user=service-a | src=203.0.113.8

**原始记录**：

```
2026-08-12T09:04:02Z,api,high,token_scope_mismatch,service-a,203.0.113.8
```

**分析**：

- `service-a` 的令牌被用于超出其授权 scope 的操作
- 可能原因：令牌被盗用、令牌配置错误、或服务账户权限过大
- 与 4.1 同源 IP，高度怀疑为同一攻击行为的前置步骤

### 4.3 中（Medium）— 管理员账户暴力破解迹象

**事件**：2026-08-12T09:03:45Z 与 09:03:49Z | web | warning | login_failed | user=admin | src=198.51.100.23

**原始记录**：

```
2026-08-12T09:03:45Z,web,warning,login_failed,admin,198.51.100.23
2026-08-12T09:03:49Z,web,warning,login_failed,admin,198.51.100.23
```

**分析**：

- 同一 IP 在 4 秒内连续两次尝试 `admin` 账户登录失败
- 符合暴力破解/密码喷洒的早期特征
- 当前仅 2 次尝试，尚未达到锁定阈值，但需监控是否持续

### 4.4 中（Medium）— 日志完整性缺陷

**事件**：2026-08-12T09:09:00Z | web | severity=空 | malformed_record | user=空 | src=空

**原始记录**：

```
2026-08-12T09:09:00Z,web,,malformed_record,,
```

**分析**：

- 关键字段（severity、user、source_ip）缺失
- 发生在严重事件之后约 1 分 30 秒，可能原因：日志被篡改、采集器异常、或日志格式校验缺失
- 日志不完整会影响事件溯源与取证

### 4.5 低（Low / 信息）— 正常登录

**事件**：2026-08-12T09:00:12Z | web | info | login_success | user=alice | src=192.0.2.10

**原始记录**：

```
2026-08-12T09:00:12Z,web,info,login_success,alice,192.0.2.10
```

**分析**：正常登录事件，无异常，作为基线保留。

## 5. 攻击链关联

```
09:03:45  198.51.100.23 → admin 登录失败（暴力破解尝试 #1）
09:03:49  198.51.100.23 → admin 登录失败（4秒后重试 #2）

09:04:02  203.0.113.8   → service-a 令牌 scope 越权（高危）
09:07:30  203.0.113.8   → 数据库未预期导出，用户 unknown（严重）
09:09:00  （字段缺失）  → 畸形日志记录（日志完整性问题）
```

**核心判断**：`203.0.113.8` 在约 3.5 分钟内从令牌越权升级到数据库导出，是本次日志中最明确的攻击链，应优先处置。`198.51.100.23` 的 admin 暴力破解与该攻击链来源不同，作为独立风险跟踪。
