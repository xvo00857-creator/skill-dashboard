# 雾港的末班船

林迟赶到码头时，末班船的铜铃已经响了两次。雾从水面推过来，先吞掉对岸的钟楼，又把船头的灯晕成一团橙色的影。

"你还是来了。"售票员说。

林迟不记得自己见过他，但对方已经把一张旧船票推过窗口。票面上的日期是十年前，背面却写着今天的时间。

她登船后发现，舱内每个人都抱着一件不属于自己的东西：小孩抱着法医的工具箱，老人攥着一双新舞鞋，年轻水手怀里搂着一只布娃娃。只有林迟两手空空。

船离岸后，所有钟表同时停在十一点四十七分。林迟想起，十年前的这一分钟，她的哥哥失踪在雾里。

船尾传来三下敲击声，不重，却像敲在骨头上。

水手走到她身边，告诉她：抵达对岸之前，每位乘客都必须把怀里的东西交还给它真正的主人。

"如果你什么都没带，"他看着林迟，"那你要交还的，可能是你自己。"

林迟顺着过道往船尾走。雾从舷窗渗进来，在脚边盘成低低的一层。她推开后门，看见栏杆边立着一个身影——穿一件洗得发白的外套，侧脸的轮廓和她记忆里分毫不差。

是哥哥。和十年前一模一样。

"你敲的？"林迟问。

"三下。"他没有转身，"以前你放学晚了，我就在家门口敲三下，你一听就知道是我。"

她当然记得。可她记得的还有十年前那个雾夜，码头封航，搜救船在水面上转了一整夜，最后只捞回一盏没油的提灯。

"舱里那些人……"她开口。

"都在替别人拿东西。"哥哥说，"小孩抱着法医的箱子——他落水那天，法医在岸边守了一通宵；老人的舞鞋是他老伴的，鞋还没上脚，人就没了；水手的娃娃属于他女儿，船难以后，再没人给她讲睡前故事。"

"那你呢？"

哥哥转过身，摊开双手，掌心空空。"我什么都不用还。我留在这儿，是因为有人一直不肯让我走。"

雾从他身后漫上来，他的影子开始发淡，像墨落进水里。林迟忽然懂了那三下敲击的意思——不是求救，是道别。这十年她把自己活成了一座码头，日复一日守着一艘不会返航的船，以为念念不忘就是对得起他。可她死死抱着的不是记忆，是不肯靠岸的自己。

"哥，"她听见自己说，声音很稳，"船要开了。"

哥哥笑了。他退后一步，雾气在他身前合拢，像水面弥合。

林迟回到舱内。小孩已经把工具箱放在脚边，老人将舞鞋轻轻搁在长椅上，水手把娃娃递向空气里某只看不见的手。钟表重新走动，十一点四十八分，船身微微一震，靠了岸。

她踏上跳板时，雾正在散。对岸的钟楼重新露出尖顶，晨光从云缝里漏下来，照在湿漉漉的石板上。

她没有回头。
