# InfiniteTalk 小省导购员数字人带货视频 — 30秒竖屏改版脚本

> 依据 infinitetalk-shopping-avatar Skill 规范生成

> 适配要求：前2秒信息钩子、静音可懂、无未授权音乐/人物素材

### 角色固定特征（六幕完全一致，严禁修改）

```
25岁女性数字人，鹅蛋脸、杏眼[情绪]、浅棕色齐肩卷发，肤色白皙、唇色淡粉；
```

### 静音适配策略

每幕画面均包含大号花字/字幕（后期烧录），静音状态下仅通过画面文字+人物动作+产品展示即可理解全部信息。花字内容在各幕"画面文字"字段中标注。

### 音频合规策略

- 导购员语音：TTS合成原创语音，无真人声纹克隆
- 背景音乐：原创生成的轻节奏纯音乐（非版权曲目、非Suno受版权保护内容）
- 不使用任何未授权真人形象、品牌Logo或受版权保护的音乐素材
