# plan.md — 研究计划（Phase 1–3）

## Phase 1 — Reframe
- **RQ（最终版）**：2023–2026 年间，中国内地职业院校一年级学生（高职专科一年级、职业本科一年级，不含中职）在学习适应、心理健康、身份认同与发展支持四个维度上的现状如何？哪些证据公开可独立验证？哪些证据不足？
- **边界**：地域中国大陆；时间窗 2023-01 至 2026-08；语言中英；不含付费库全文；"一年级"以招生数近似。
- **可证伪假设**：
  - H1：近 3 年公开数据/研究一致显示高职一年级学习适应困难显著高于普通本科一年级。→ 判定：**partially supported / 直接比较证据不足**（见 F5、报告 §10）。
  - H2：近 3 年公开证据支持高职一年级心理健康风险（抑郁/焦虑/学业倦怠）检出率方向上高于普通本科同龄，但具体数值因量表/样本/口径不能合并为单一数字。→ 判定：**direction supported, numbers under-determined**（F4）。
  - H3：2022 新职教法后，职教高考扩招与职业本科扩容已在 2023–2026 公开统计中体现为一年级新生结构变化。→ 判定：**supported**（F1/F2/F3）。
  - H4：公开可查的干预研究（导师制/朋辈/心理筛查/专业认知教育）近 3 年有可复用的正向证据，但严格 RCT/大样本证据稀缺。→ 判定：**direction supported, thin RCT**（F7）。

## Phase 2 — Genre & blocks
- **Genre**：landscape（现状图谱）。
- **Blocks**：执行摘要 / 范围与术语 / 规模与结构 / 政策背景 / 学习适应 / 心理健康 / 身份认同 / 发展支持与干预 / 就业与吸引力 / 证据缺口 / 对抗性自检 / 方法自检 / 下一步。

## Phase 3 — Plan & capability
- **可用工具**：general_search、web.fetch、scholar_search（已加载）、Read/Write/Edit。
- **不可用**：CNKI/万方/维普/WoS/Scopus 全文；中文核心全文需绕到 OA 或仅取摘要。
- **来源类型目标**：每个核心 finding ≥ 2 类来源，力争 3 类（官方/学术-OA/政策-调查/媒体）。
- **Stop criteria**：
  - 每个 H 至少 3 个独立来源，或显式标"证据不足"；
  - 所有数字可在 sources/ 原文引述中找到；
  - 心理健康数字不跨量表合并；
  - 对抗性 4 问全部回答。
- **Risk register**：① 后疫情数据外推；② 单校/艺术类样本外推；③ 媒体转述当一手；④ 预印本未定稿；⑤ 发表偏倚（阴性结果在付费库）。

## 约束变化对原方案影响
见报告 §0 表格。核心：对象口径变窄 → 强制分层标注；时间 3 年 → 排除 2022 前基线；中英双语 → 纳入 PMC/Frontiers/SAGE；无付费库 → 证据强度排序调整、摘要级证据显式降级。
