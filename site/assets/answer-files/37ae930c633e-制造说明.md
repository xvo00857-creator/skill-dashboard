## 6. bambu-labs Skill dry-run

执行命令：
```
python3 scripts/bambu_lan_print.py send \
  --gcode desk_organizer_4comp.gcode \
  --handoff plain --action plan
```

结果：成功输出 JSON 计划，包含：
- FTPS 上传计划（端口 990，用户名 bblp，远程路径 cache/desk_organizer_4comp.gcode）
- MQTT 启动指令计划（端口 8883，command=gcode_file）
- 安全提示：dry-run 为默认，真实打印需 `--execute --confirm-start-print`

**注意**：本环境无真实 Bambu 打印机，仅完成 plan 模式 dry-run。真实打印需配置打印机局域网 IP 和访问码。

## 7. 制造注意事项

1. **朝向**：开口朝上打印，所有壁垂直于底板，无需支撑。
2. **壁厚**：2.4 mm 为 0.4 mm 喷嘴的 6 倍线宽；默认 2 道壁，如需更高强度可在切片器中增至 4-6 道。
3. **底板尺寸**：180 mm 宽恰好等于 A1 Mini 成型宽度，切片时需关闭自动排布（`--arrange 0`），否则排布算法的 3.4 mm 边距会判定排不下。
4. **材料**：PLA 可直接打印；若用 ABS/ASA 建议加 brim 防翘边。
5. **打印时间**：约 14.3 小时（因每层底板面积大）；可通过 0.24 mm Draft 配置或降低填充率缩短。
6. **后处理**：直角内角因喷嘴半径会有轻微圆角，不影响功能；隔墙顶部可能有轻微拉丝，可修剪。
7. **真实打印交接**：需在 bambu-labs 中执行 `config set --printer <id> --host <IP> --access-code <码>`，然后 `send --execute --confirm-start-print`。

## 8. 能力边界说明

bambu-labs Skill 是 **Bambu Lab 打印机的本地网络打印交接工具**，不具备 CAD 设计或切片能力：
- CAD 建模由 Python（trimesh + manifold3d）完成
- 切片由 OrcaSlicer 2.4.2 CLI 完成
- bambu-labs 仅负责将已验证的 G-code 通过 FTPS/MQTT 上传并启动打印
