## 二、受约束的流程方案

### 阶段 0：预检（Pre-flight）

每次执行前必须完成以下检查，任一不通过则中止并报告：

1. **Skill 文件检查**：读取 SKILL.md，确认其为有效指令文件而非占位文件。若为占位文件，标记为"降级模式"并提示人工补充真实 Skill 内容。
2. **输出目录检查**：确认输出目录存在且可写；若不存在则创建（仅在工作目录内）。
3. **模型可用性检查**：确认指定的生图模型（本次为 Seedream 5.0 Pro）在工具中可用。
4. **参数完整性检查**：确认图标主题、尺寸、风格参数已提供或使用默认值。
5. **幂等检查**：根据输入参数计算哈希，检查是否已存在相同参数的产物；若存在且未强制覆盖，跳过生成并直接返回已有产物路径。

### 阶段 1：人工确认点 A（生成前确认）

在调用生图模型前，需人工确认以下内容：
- 图标主题与用途
- 视觉风格参数（色彩、形状语言、尺寸）
- 输出路径与命名规则
- 是否为降级模式（SKILL.md 为占位文件时）

> 本次演示中，用户已通过任务指令授权使用 Seedream 5.0 Pro 生成一次演示图标，视为已通过确认点 A。

### 阶段 2：图像生成（含重试）

1. 使用 `image_gen` 工具，`model_version` 设为 `seedream_5.0_pro`。
2. 尺寸：1024×1024（1:1，图标标准基准尺寸）。
3. **重试策略**：
   - 最多重试 3 次。
   - 第 1 次失败后等待 2 秒重试；第 2 次失败后等待 5 秒重试。
   - 重试仅针对网络超时、服务临时不可用等可恢复错误；参数错误、内容安全拒绝等不可恢复错误立即中止。
   - 每次重试记录失败原因。
4. 生成成功后，将图片保存至输出目录，文件名包含参数哈希前缀以保证幂等。

### 阶段 3：人工确认点 B（产物验收）

生成后需人工确认：
- 图像内容是否符合主题与风格要求
- 尺寸、格式是否正确
- 是否需要调整参数重新生成

> 若验收不通过，回到阶段 1 调整参数；若通过，进入交付。

### 阶段 4：规范化交付

1. 记录产物元数据（生成时间、模型、参数、文件路径、尺寸）。
2. 交付产物文件与流程记录。
3. 不删除、不覆盖任何已有文件（除非人工明确要求）。

### 幂等设计

- 输入参数（主题、风格、尺寸、模型）经 SHA-256 哈希后取前 12 位作为文件名前缀。
- 若 `icon-output/` 下已存在相同前缀的文件，默认跳过生成，返回已有文件。

## 三、视觉系统规范（默认推断，非来自 SKILL.md）

> 以下规范为降级模式下的默认设定，因 SKILL.md 占位文件未提供任何风格指令。待真实 Skill 内容补充后应以其为准。

### 3.1 风格定位

- **风格**：扁平化设计（Flat Design），辅以微妙渐变和柔和投影
- **形状语言**：圆角矩形底托 + 中心符号图形，圆角半径为底托边长的 22%
- **透视**：正面平视，无 3D 透视变形
- **整体气质**：现代、简洁、专业，符合"自动化与工具"分类

### 3.2 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#4F6BF6`（靛蓝） | 底托渐变起点 |
| 主色深 | `#3B4FD4` | 底托渐变终点 |
| 符号色 | `#FFFFFF`（纯白） | 中心图形/符号 |
| 高光 | `rgba(255,255,255,0.15)` | 顶部微妙高光 |

### 3.3 尺寸与格式

- 基准尺寸：1024×1024 px（1:1）
- 输出格式：PNG
- 安全边距：图形主体占画布 70%，四周留 15% 边距
- 可扩展性：矢量感造型，缩小至 16×16 仍可辨识

### 3.4 一致性规则

- 同一组图标使用相同底托形状、圆角半径和渐变方向（从上到下）
- 符号线条粗细统一
- 光源方向统一（顶部）
- 不使用照片、纹理或复杂插画元素
