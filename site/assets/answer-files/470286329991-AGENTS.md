## 项目概述

这是一个 **Copilot CLI Skill 包装器**，名称为 `ai-ready`。它本身不执行代码库分析，
唯一作用是引导用户安装由 John Papa 维护的完整 `johnpapa/ai-ready` Skill。

- 内容格式：Markdown（含 YAML frontmatter）
- 运行时/构建系统/测试框架：**无**（纯说明文件，无源代码）
- 唯一文件：`SKILL.md`（27 行）

## 目录结构

```
ai-ready/
└── SKILL.md   # 包装器：4 步安装引导，无脚本、无模板、无引用资源
```

## 核心行为约定（来自 SKILL.md 原文，不得扩张）

1. 告知用户在 **Copilot CLI 内**执行 `/skills add johnpapa/ai-ready` 安装完整 Skill。
2. 提醒用户加载前先审阅：`head -20 ~/.copilot/skills/ai-ready/SKILL.md`。
3. 用户确认审阅并安装后，告知其执行 `/skills reload`，再说 `make this repo ai-ready`。
4. **禁止代理代替用户运行安装命令**，必须由用户本人执行。

## 给协作智能体的约束

- 不要把本包装器当作"代码库分析器"调用；它不具备该能力。
- 不要为本仓库虚构 `npm install`、`pip install`、构建或测试命令——本仓库无构建步骤。
- 不要静默修改 `~/.copilot/` 下的任何文件；安装与更新由用户在 Copilot CLI 中完成。
- 引用本 Skill 行为时，以 `SKILL.md` 原文为准；完整能力清单以 `johnpapa/ai-ready` 上游为准。
- 若需要在真实代码库生成 AI 协作配置，请先满足《受约束流程方案.md》中的预检条件。
