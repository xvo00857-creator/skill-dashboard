## 二、坐标与尺寸说明

- **坐标系**：右手坐标系，原点位于底座底面圆心；X 轴向右，Y 轴竖直向上，Z 轴指向观察者。
- **单位**：毫米（mm）；网页中 1 毫米 = 1 像素，并按视口自适应缩放。
- **部件尺寸**（零位姿态）：

| 部件 | 类型 | 尺寸 | 零位中心坐标 (X,Y,Z) |

| 肩关节 | 球体 | 直径 40 | (0, 40, 0) |
| 大臂 | 长方体 | 30 × 150 × 30 | (0, 115, 0) |

- **关节**：J1 底座旋转（Y 轴，±180°）、J2 肩俯仰（X 轴，±90°）、J3 肘俯仰（X 轴，−150°–0°）、J4 腕俯仰（X 轴，±90°）、J5 夹爪开合（线性，0–50 mm）。
- **工作空间**：最大水平半径约 350 mm，最小约 60 mm，最大高度约 430 mm。

## 三、使用方式

1. 双击 `robot-arm.html` 在任意现代浏览器打开（无需联网、无需服务器）。
2. **桌面端**：鼠标拖拽旋转视角；右侧滑块控制各关节；方向键在场景聚焦时可旋转视角。
3. **手机端**：单指拖拽旋转视角；下方滑块控制关节；布局自动切换为上下结构。
4. 点击“低性能模式”按钮或开关，切换到 2D SVG 侧视图（低性能 / 无障碍方案）。
5. URL 参数：
   - `?lowperf=1` 直接进入 2D 模式；
   - `?j1=35&j2=10&j3=0&j4=15&j5=20` 设置初始关节角度，便于分享姿态。

## 四、如何编辑

- **改尺寸 / 颜色 / 关节范围 / 中文说明**：编辑 `robot-arm-scene.json`（权威数据源）。
- `robot-arm.html` 内嵌了与 JSON 同构的 `SCENE` 对象；修改后刷新即可生效。所有源文件均为纯文本 UTF-8，记事本、VS Code 等任意编辑器均可编辑。
- 中文标注、关节名称、提示文案均为中文，直接在 HTML/JSON 中搜索替换即可，不会因编码丢失。

## 五、新增约束导致的方案变化

本次在原“桌面机械臂三维资产”任务上增加了四项约束，方案相应调整如下：

1. **手机端可读**
   - 未采用固定宽度的桌面布局，而是使用弹性布局 + `viewport` 元标签 + JS 自适应缩放（`fitScale`）；≤820px 宽时控制面板自动移至场景下方。
   - 触控事件（`touchstart/touchmove/touchend`）与鼠标事件并存，单指即可旋转视角；滑块尺寸放大便于触摸。

2. **可编辑**
   - 未使用二进制 `.glb/.gltf` 模型或 Three.js 等需构建的方案，而是采用 **纯文本 CSS 3D + JSON 描述**：尺寸、颜色、关节范围全部在 JSON/JS 对象中，改数字即改模型，无需任何专业建模软件。
   - 单 HTML 文件零依赖，可离线编辑、离线运行。

3. **中文信息不丢失**
   - 所有文件统一 UTF-8 编码，`<html lang="zh-CN">`、`<meta charset="UTF-8">`；
   - 标注、控件、说明、JSON 键名与元数据全部使用中文，并经脚本校验中文字符数与关键文案完整性。

4. **无障碍 / 低性能设备兼容**
   - 提供 **2D SVG 侧视图降级方案**：一键关闭所有 CSS 3D 变换与网格，改用 SVG 绘制，关节滑块仍可联动；SVG 含 `role="img"` 与中文标注，便于读屏软件识别。
   - 响应系统 `prefers-reduced-motion`，自动关闭过渡动画；
   - 自动检测低核 / 低内存设备并提示切换；
   - 所有滑块含 `aria-label`、`aria-valuemin/max/now`、中文 `aria-valuetext`；按钮含 `aria-pressed`；场景可 Tab 聚焦、方向键操作；
   - 中文标注采用 billboard 平面文字（始终朝向相机），而非 3D 挤出文字，保证小字号下可读——这也正是 3d-ui Skill 的明确要求。

## 七、遵循的 3d-ui Skill 规则

- **Core Principle 1 真实 Z 轴深度**：臂杆、关节、标注均使用 `translateZ` 产生真实前后关系，而非仅靠阴影。
- **Core Principle 2 透视**：舞台使用 `perspective: 700px` 产生灭点。
- **Core Principle 3 交互旋转**：3D 旋转绑定到鼠标拖拽（桌面）与触摸拖拽（手机），符合 Skill “DO: Tie 3D rotation to user input”。
- **Visual DNA**：采用高对比的 Industrial Chic 深色工业配色；3D 图元由 CSS 构建（Skill 所述 `.glb/.gltf/PNG` 的等价纯文本实现）。
- **Web Implementation**：使用 `perspective`、`transform-style: preserve-3d`、`rotateX/rotateY`。
- **Do's and Don'ts**：未将小字号做成 3D 文字，所有中文标注为平面 billboard 文本。
- **Limitations**：Skill 声明不替代无障碍与响应式验证，本资产已补充对比度、键盘、读屏、 reduced-motion 与低性能降级方案。
