## ADR-000：在时间与资源受限下采用"最小可验证方案"

### Status
Accepted

### Date
2026-08-12

### Context
需要为一款在线课程制定付费广告素材与落地页检查方案，交付受众、信息主张、素材规格、转化路径和可验证清单。

**已知约束：**
- 时间与资源受限（具体可用工时、预算、截止日期 **【待确认】**）
- 课程名称、主题、定价、目标人群、投放平台、历史投放数据均未提供，全部 **【待确认】**
- 无广告平台账户访问权限，无法实际拉取数据或上线测试
- 无素材制作工具/设计资源可用

**Skill 约束（来自 SKILL.md）：**
- 文档应记录"为什么"，而非复述"是什么"
- 决策须列出备选方案及被拒绝的理由
- 交付物须附可勾选的验证清单

### Decision
采用"最小可验证方案"（Minimum Verifiable Plan）：
1. 不追求全平台、全格式覆盖，按优先级分 P0/P1/P2 三档
2. 所有具体数值（课程信息、预算、平台规格）以 **【待确认】** 标注，待业务方填入后即可执行
3. 方案本身可被逐项检查（checklist），不依赖未提供的数据即可评审
4. 以 ADR 形式记录每个取舍，便于后续资源充足时 supersede（替代）本方案

### Alternatives Considered

#### 方案 B：完整全平台方案
- Pros：覆盖所有主流平台与素材格式，一次到位
- Cons：在课程信息缺失、无数据支撑的情况下，大量规格为臆测；制作成本高，不符合资源受限约束
- Rejected：信息不足时铺开面越大，无效工作越多；违背"先验证再放大"原则

#### 方案 C：仅交付检查清单，不做决策
- Pros：最省时
- Cons：只有"检查什么"没有"为什么这样选"，执行者无法判断优先级；不符合 Skill 对记录决策理由的要求
- Rejected：清单是必要交付物，但不能替代决策记录

### Consequences
- 方案可立即用于评审和分工，业务方补齐 **【待确认】** 项后即可进入执行
- P0 项可在最少资源下启动并验证；P1/P2 待数据反馈后再投入
- 当课程信息和预算明确后，应新建 ADR 替代本方案中的假设部分（不删除本 ADR）
- 本方案不包含实际素材产出和上线数据，这些属于执行阶段，需相应资源

## ADR-001：受众——优先聚焦单一核心人群，暂缓多人群测试

### Status
Accepted

### Date
2026-08-12

### Context
- 课程具体主题与定位 **【待确认】**，无法从课程内容反推受众
- 资源受限，无法同时为多个人群制作差异化素材
- 付费广告冷启动阶段，人群越分散，学习期数据越难收敛

### Decision
**P0：聚焦 1 个核心受众画像**，用最小素材组验证该人群的点击与转化。

核心画像框架（待业务方填入具体内容）：
| 维度 | 内容 | 验证状态 |
|------|------|----------|
| 人群名称 | 【待确认：如"0-3 岁转行求职者"】 | 待确认 |
| 核心痛点 | 【待确认：如"缺乏系统学习路径，自学效率低"】 | 待确认 |
| 已有认知 | 【待确认：如"知道该技能有需求，但不知从何学起"】 | 待确认 |
| 决策障碍 | 【待确认：如"担心学不会、价格高、没时间"】 | 待确认 |
| 平台分布 | 【待确认：如"抖音/小红书/微信"】 | 待确认 |

**P1：** 若 P0 人群 CPA（单次转化成本）达标，扩展 1 个相邻人群。
**P2：** 多人群并行投放与 Lookalike 扩展（需积累转化数据后）。

### Alternatives Considered

#### 多人群同时冷启动
- Pros：可能更快找到最优人群
- Cons：预算分散，每个人群样本量不足，平台算法无法完成学习；素材制作量成倍增加
- Rejected：资源受限下，分散等于没有重点

#### 不定义人群，直接通投
- Pros：无需前期调研
- Cons：流量不精准，转化率低，CPA 高；无法沉淀人群洞察
- Rejected：通投是最后手段，不是策略

### Consequences
- 前期需要业务方确认 1 个核心画像（**【待确认】**项），这是启动前提
- 单人群验证速度快，3-7 天可获得初步数据（具体时长取决于预算量级，**【待确认】**）
- 若 P0 人群不达标，再切换人群的成本较低（仅需调整定向，素材框架可复用）

## ADR-002：信息主张——单一价值主张 + 一个明确行动号召

### Status
Accepted

### Date
2026-08-12

### Context
- 课程卖点、差异化优势、价格、师资、学员成果均 **【待确认】**
- 广告素材停留时间短（信息流广告通常 1-3 秒决定是否停留），信息过载会降低完播与点击
- 落地页需要与素材主张一致，否则用户预期断裂导致跳出

### Decision
**P0：素材与落地页统一使用 1 个核心价值主张 + 1 个 CTA（行动号召）。**

价值主张公式（待填入）：
> 【目标人群】+【核心痛点】→【课程提供的结果】+【可信证据】

示例框架（非真实数据，仅作格式参考）：
> "【想转行的人】，【不用辞职也能学会 XX】，【已有 N 名学员拿到 offer】"——其中 N 与 offer 数据 **【待确认，须有真实凭据，不得编造】**

CTA 统一为一个动作，P0 建议：
- 若课程有免费试看/低价体验课：CTA = "免费试听" / "1 元体验"（低门槛，**【待确认是否有此产品形态】**）
- 若仅正价课：CTA = "了解课程大纲"（中等门槛）
- 避免同时放"立即购买"+"加微信"+"下载资料"多个按钮

**P1：** 测试 2 个不同主张变体（A/B），但每个变体仍只含一个主张。
**P2：** 按人群阶段（认知/考虑/决策）分层主张。

### Alternatives Considered

#### 素材罗列全部卖点
- Pros：信息全面
- Cons：用户记不住，没有记忆点；与落地页难以一一对应
- Rejected：广告不是说明书，一个主张打透胜过五个卖点罗列

#### 用夸张/虚假承诺吸引点击
- Pros：可能短期点击率高
- Cons：转化率低、退款投诉、平台处罚风险；违背合规要求
- Rejected：不可接受，所有主张必须有可验证证据支撑

### Consequences
- 业务方必须提供至少 1 个有证据支撑的核心卖点（**【待确认】**）
- 素材与落地页主张一致性可被逐项检查（见验证清单）
- 无证据的承诺一律标注 **【待确认】**，在证据补齐前不得用于上线素材

## ADR-003：素材规格——P0 仅做 1 个平台的 2 种核心规格

### Status
Accepted

### Date
2026-08-12

### Context
- 投放平台 **【待确认】**，不同平台规格差异大（抖音/快手竖版视频、微信朋友圈图片、小红书图文、百度搜索文字等）
- 无设计/视频制作资源确认，制作能力 **【待确认】**
- 资源受限，多平台多规格会导致每个素材质量下降

### Decision
**P0：选定 1 个主投平台（**【待确认】**），仅制作该平台最核心的 2 种规格。**

| 优先级 | 素材类型 | 规格 | 数量 | 用途 |
|--------|----------|------|------|------|
| P0 | 竖版短视频 | 9:16，15-30 秒，分辨率 1080×1920（以投放平台最新官方规格为准，**【待确认】**） | 2 条 | 信息流主力素材 |
| P0 | 竖版封面图/首帧 | 9:16，与视频配套 | 2 张 | 视频首帧/封面 |
| P1 | 横版视频 | 16:9，30 秒内 | 1 条 | 横版广告位/落地页嵌入 |
| P1 | 方形图片 | 1:1 | 2 张 | 朋友圈/信息流备用 |
| P2 | 多版本扩展 | 按 P0 数据优胜方向扩展 | 按需要 | 放量阶段 |

**素材内容结构（P0 视频，15-30 秒）：**
1. 前 3 秒：痛点钩子（对应核心人群痛点）
2. 中间：解决方案 + 可信证据（师资/成果/演示，**【待确认】**）
3. 结尾：单一 CTA（与 ADR-002 一致）

**注意：** 以上规格为通用参考值，实际投放前必须核对目标平台最新官方广告规格文档（**【待确认】**），平台规格会更新，不得凭记忆执行。

### Alternatives Considered

#### 一次制作全平台全套规格
- Pros：后续无需补做
- Cons：平台未定即制作，可能规格作废；制作量大，资源不足
- Rejected：先定平台再做素材，避免返工

#### 只做图片不做视频
- Pros：成本低、速度快
- Cons：多数主流信息流平台视频效果优于图片；课程类内容视频更易展示教学场景
- Rejected：除非主投平台为搜索广告（**【待确认】**），否则视频为 P0

### Consequences
- 启动前必须确认主投平台（**【待确认】**），这是 P0 前置条件
- 2 条视频可做最低限度的 A/B 对比（钩子或主张不同）
- 规格以平台官方文档为准，本方案中的数值为参考，执行前须核对

## ADR-004：转化路径——最短路径，减少跳转环节

### Status
Accepted

### Date
2026-08-12

### Context
- 课程售卖方式 **【待确认】**：直接购买 / 留资后销售跟进 / 加企微 / 下载 App
- 落地页技术能力 **【待确认】**：是否有现成建站工具、是否需要开发
- 转化环节越多，流失越大；资源受限下应优先保证路径通畅而非功能丰富

### Decision
**P0：采用最短可行转化路径，跳转不超过 3 步。**

路径选项（按课程售卖方式选择，**【待确认】**）：

| 路径 | 步骤 | 适用场景 | 优先级 |
|------|------|----------|--------|
| A：直接购买 | 广告 → 落地页 → 支付页 | 低客单价、决策轻、有在线支付能力 | P0（若适用） |
| B：留资 | 广告 → 落地页 → 表单提交（姓名+手机） | 高客单价、需销售跟进 | P0（若适用） |
| C：加企微 | 广告 → 落地页 → 扫码/跳转企微 | 私域转化为主 | P1 |
| D：下载 App | 广告 → 应用商店 → 下载 → 注册 | 课程在 App 内交付 | P2（路径长，非首选） |

**落地页 P0 必备元素（按从上到下顺序）：**
1. 首屏：核心价值主张（与素材一致）+ CTA 按钮
2. 痛点共鸣区：3 个以内核心痛点
3. 课程解决方案：学什么、怎么学（**【待确认：课程大纲】**）
4. 可信证据：师资介绍、学员评价/成果（须真实可查，**【待确认】**）
5. 常见问题：3-5 个（价格、时长、退款、适合人群）
6. 底部/悬浮 CTA：与首屏相同的单一行动号召

**P0 不做：** 弹窗、在线客服浮窗（除非已有现成客服）、多按钮、用户评论区（开发成本高）。

### Alternatives Considered

#### 长落地页 + 多模块（品牌故事、媒体报道、详细大纲、社区展示）
- Pros：信息充分，有助于高客单价决策
- Cons：制作成本高，加载慢，移动端跳出率高
- Rejected：P0 阶段先验证核心转化，长页面留待 P1 根据数据优化

#### 广告直接跳转支付页（无落地页）
- Pros：少一步跳转
- Cons：用户缺乏决策信息，支付转化率低；无法承接素材主张
- Rejected：除低价冲动消费品外，课程需要落地页建立信任

### Consequences
- 必须先确认售卖方式（**【待确认】**）以选择路径 A/B/C
- 落地页可用建站工具快速搭建（具体工具 **【待确认】**），无需定制开发
- 路径中每一步都可埋点追踪（埋点方案 **【待确认】**），P0 至少追踪：点击量、落地页访问量、CTA 点击量、转化量

## 约束导致的方案变化说明

| 维度 | 无约束理想方案 | 资源受限方案（本方案） | 变化原因 |
|------|----------------|------------------------|----------|
| 受众 | 3-5 个人群并行测试 | 仅 1 个核心人群（P0） | 预算分散导致学习期数据不收敛 |
| 信息主张 | 多主张、多版本矩阵 | 1 个主张 + 1 个 CTA | 素材制作资源有限，先打透一个点 |
| 素材 | 全平台 5+ 种规格、10+ 条素材 | 1 个平台、2 种规格、2 条视频 | 平台未定、制作能力未确认 |
| 转化路径 | 长落地页 + 多触点 + 再营销 | 最短 3 步路径 + 精简落地页 | 开发资源有限，先保证路径通畅 |
| 数据验证 | 完整埋点 + 归因模型 + A/B 平台 | 基础 4 指标追踪 | 技术资源未确认 |
| 上线节奏 | 一次性全量上线 | P0 先验证，达标后再 P1/P2 | 降低试错成本 |

**核心取舍逻辑：** 资源受限时，优先保证"可验证"而非"全覆盖"。每一档优先级都设定了进入条件（P0 数据达标才进 P1），避免在未验证的方向上持续投入。

## 可验证清单

> 对应 SKILL.md "Verification" 模式。以下每项均可在上线前逐项检查，结果为"是/否/待确认"。

### A. 前置条件检查（任一为否则不能启动 P0）
- [ ] 课程名称、主题、大纲已确认（当前：**【待确认】**）
- [ ] 课程定价与售卖方式已确认（当前：**【待确认】**）
- [ ] 1 个核心受众画像已填写并经业务方确认（当前：**【待确认】**）
- [ ] 1 个有证据支撑的核心价值主张已确认（当前：**【待确认】**）
- [ ] 主投平台已确认（当前：**【待确认】**）
- [ ] 投放预算与时间周期已确认（当前：**【待确认】**）
- [ ] 落地页搭建工具/能力已确认（当前：**【待确认】**）

### B. 素材检查
- [ ] 素材规格已对照目标平台最新官方文档核对（当前：**【待确认】**）
- [ ] 前 3 秒包含痛点钩子，且钩子对应核心人群
- [ ] 素材中只传达 1 个核心价值主张
- [ ] 素材结尾只有 1 个 CTA，且与落地页 CTA 一致
- [ ] 所有数据/成果/承诺均有真实凭据，无编造内容（当前：**【待确认】**）
- [ ] 素材无平台违禁内容（极限词、虚假承诺等，对照平台广告审核规则，**【待确认】**）
- [ ] 视频字幕清晰，无声播放可理解（移动端常见场景）
- [ ] 至少 2 条素材可用于最低限度 A/B 对比

### C. 落地页检查
- [ ] 首屏价值主张与广告素材一致（无预期断裂）
- [ ] 首屏可见 CTA 按钮
- [ ] 全页 CTA 统一为同一个动作（无多个互相竞争的按钮）
- [ ] 痛点区不超过 3 个核心痛点
- [ ] 可信证据真实可查（师资、学员案例均有出处，**【待确认】**）
- [ ] 包含价格/退款/适合人群等 FAQ
- [ ] 移动端可正常加载与操作（**【待确认：需实际设备测试】**）
- [ ] 页面加载速度可接受（**【待确认：需实测，建议首屏 < 3 秒】**）
- [ ] 表单字段最少化（留资路径仅收集必要信息）
- [ ] 转化路径从广告到完成不超过 3 步

### D. 追踪与验收检查
- [ ] 广告点击可追踪（UTM/平台参数，**【待确认】**）
- [ ] 落地页访问量可统计
- [ ] CTA 点击量可统计
- [ ] 最终转化（支付/留资）可统计
- [ ] 已定义 P0 验收标准（建议：CPA ≤ 【待确认】、落地页转化率 ≥ 【待确认】）
- [ ] 已设定 P0 验证周期（建议：3-7 天或累计转化 ≥ 【待确认】个，以先到为准）
- [ ] 明确 P0 达标后进入 P1 的决策人（**【待确认】**）

### E. 合规检查
- [ ] 广告内容符合《广告法》及平台规则（无"最""第一"等极限词，无虚假承诺）
- [ ] 学员案例/评价已获授权（**【待确认】**）
- [ ] 收集用户信息有隐私政策与勾选同意（留资路径）
- [ ] 课程涉及资质领域（如职业资格、医疗、金融）已确认是否需特殊资质（**【待确认】**）
