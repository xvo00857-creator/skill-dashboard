# 在线课程付费广告素材与落地页检查方案

> 版本：v1.0 ｜ 日期：2026-08-12 ｜ 适用平台：主流信息流/搜索/社媒广告
>
> **自动化说明**：本方案中标注 `[可由 adrapid-automation Skill 执行]` 的检查项，在 Rube MCP 连通且 Adrapid 账户授权后可自动完成；当前环境因 Rube MCP 不可达、无 Adrapid 账户，仅执行到确认前步骤，其余项以本地脚本+人工核验方式验证。

## 一、目标受众

| 层级 | 人群画像 | 核心痛点 | 触达平台优先级 |
|------|---------|---------|--------------|
| 核心受众 | 25-35 岁职场人，希望通过技能提升获得晋升或转行 | 学了用不上、课程质量无保障、时间碎片化 | 微信朋友圈、抖音信息流、知乎 |
| 次核心受众 | 20-24 岁在校大学生/应届生，求职前补技能 | 缺乏实战项目、简历无亮点、预算有限 | B站、小红书、抖音 |
| 拓展受众 | 35-45 岁中年职场人，面临职业瓶颈 | 担心学不会、怕被割韭菜、需要灵活学习时间 | 微信朋友圈、百度搜索 |

**受众定向参数建议**：
- 地域：一线及新一线城市优先，可按课程品类扩展
- 兴趣标签：职业教育、在线学习、技能提升、目标岗位关键词
- 行为：近 30 天搜索过相关课程/职业关键词
- 排除：已购买用户（基于转化数据排除）、近 7 天已点击广告未转化用户（频次控制）

## 二、信息主张

### 2.1 核心价值主张

> **「[具体技能] 实战营 —— [具体时长] 掌握 [可验证成果]，学完即有 [作品集/证书/内推机会]」**

主张必须包含三要素：
1. **具体技能**：不使用"提升自我""赋能"等模糊词，明确到岗位技能名
2. **可验证成果**：作品集、证书、项目经历、可量化的能力变化
3. **信任背书**：讲师履历、学员案例、合作企业、退款保障

### 2.2 文案主张矩阵

| 诉求类型 | 主张方向 | 示例文案框架 | 适用受众 |
|---------|---------|-------------|---------|
| 痛点型 | 直击职业焦虑 | "做了 3 年 [岗位] 还在重复劳动？是时候掌握 [技能] 了" | 核心受众 |
| 利益型 | 强调成果回报 | "[时长] 从零到独立完成 [项目]，作品集直接写进简历" | 次核心受众 |
| 权威型 | 讲师/机构背书 | "前 [大厂] [职级] 亲授，已帮助 [N] 人转行成功" | 全受众 |
| 紧迫型 | 限时/限额 | "本期仅剩 [N] 个名额，[日期] 前报名享早鸟价" | 再营销受众 |
| 社交型 | 学员真实故事 | "零基础转行 [岗位]，[时长] 后薪资涨了 [X]%" | 拓展受众 |

### 2.3 落地页信息层级

1. **首屏**：核心主张 + 主视觉 + 主 CTA 按钮
2. **第二屏**：课程能解决什么问题（痛点共鸣）
3. **第三屏**：课程大纲/学习路径（具体内容）
4. **第四屏**：讲师介绍 + 资质背书
5. **第五屏**：学员评价/成功案例（真实可查）
6. **第六屏**：常见问题 FAQ（降低决策门槛）
7. **第七屏**：价格/优惠 + 最终 CTA + 风险逆转（退款承诺）

## 三、素材规格

### 3.1 图片素材规格

| 平台/版位 | 尺寸（宽×高） | 文件格式 | 大小上限 | 文案占比 |
|----------|-------------|---------|---------|---------|
| 微信朋友圈单图 | 800×800 px | JPG/PNG | ≤300KB | ≤30% |
| 微信朋友圈卡片 | 800×450 px | JPG/PNG | ≤300KB | ≤30% |
| 抖音信息流竖版 | 1080×1920 px | JPG/PNG | ≤500KB | ≤20% |
| 抖音信息流横版 | 1280×720 px | JPG/PNG | ≤500KB | ≤20% |
| 小红书竖版 | 1080×1440 px | JPG/PNG | ≤500KB | ≤20% |
| B站信息流 | 1146×717 px | JPG/PNG | ≤300KB | ≤20% |
| 百度搜索凤巢 | 121×75 px（头像）/ 200×200 px | JPG/PNG | ≤100KB | — |
| 通用 Banner 横幅 | 728×90 px | JPG/PNG/GIF | ≤150KB | ≤30% |
| 通用矩形大图 | 300×250 px | JPG/PNG | ≤150KB | ≤30% |
| HTML5 动态素材 | 按平台尺寸 | HTML5 ZIP | ≤2MB（ZIP） | — |

### 3.2 视频素材规格

| 平台 | 分辨率 | 时长 | 格式 | 大小上限 | 字幕要求 |
|------|-------|------|------|---------|---------|
| 抖音信息流 | 1080×1920（9:16） | 15-60 秒 | MP4/H.264 | ≤100MB | 必须内嵌字幕 |
| 微信朋友圈 | 1080×1920 或 1280×720 | 15-30 秒 | MP4/H.264 | ≤50MB | 建议内嵌字幕 |
| B站 | 1920×1080（16:9） | 30-90 秒 | MP4/H.264 | ≤200MB | 建议内嵌字幕 |
| 小红书 | 1080×1440（3:4）或 1080×1920 | 15-60 秒 | MP4/H.264 | ≤100MB | 必须内嵌字幕 |

### 3.3 文案规格

| 元素 | 字数限制 | 要求 |
|------|---------|------|
| 广告标题 | ≤20 字（朋友圈）/ ≤30 字（抖音） | 包含核心关键词，不用夸张绝对化用语 |
| 广告描述 | ≤40 字 | 补充利益点或 CTA |
| 落地页 H1 | ≤30 字 | 与广告主张一致 |
| CTA 按钮文案 | ≤6 字 | 动作导向："免费试听""立即报名""领取大纲" |
| 表单字段 | ≤4 项 | 仅收集必要信息（姓名+手机为必填，其余选填） |

### 3.4 合规红线（所有素材必须通过）

- 不得使用"最""第一""国家级"等《广告法》禁止的绝对化用语
- 不得承诺保过、包就业、保证薪资等无法保证的效果
- 不得使用虚假学员案例或伪造数据
- 教育培训广告不得出现升学/通过考试的明示或暗示保证
- 价格表述必须真实，划线价需有销售依据
- 涉及证书需说明颁发机构及性质（非国家承认学历需注明）

## 四、转化路径

### 4.1 路径设计

```
广告曝光 → 点击 → 落地页 → 主 CTA → 表单/试听 → 提交成功页 → 后续触达
   │          │        │         │          │            │            │
   │          │        │         │          │            │            ├─ 短信/电话跟进（24h 内）
   │          │        │         │          │            │            ├─ 微信社群/私域添加
   │          │        │         │          │            │            └─ 未付费：7 日内再营销
   │          │        │         │          │            └─ 展示报名号/试听链接+优惠倒计时
   │          │        │         │          ├─ 表单：姓名+手机（必填）+意向方向（选填）
   │          │        │         │          └─ 或：直接跳转免费试听课（降低门槛）
   │          │        │         ├─ 首屏 CTA（主转化点）
   │          │        │         ├─ 中部 CTA（阅读后转化点）
   │          │        │         └─ 底部 CTA（最终转化点）
   │          │        ├─ 加载时间 ≤3 秒（4G 网络）
   │          │        ├─ 移动端适配（首屏无需横向滚动）
   │          │        └─ 与广告主张一致（无标题党跳转）
   │          ├─ UTM 参数完整（source/medium/campaign/content/term）
   │          └─ 点击到落地页首字节 ≤1 秒
   └─ 频次控制：同一用户每日 ≤3 次
```

### 4.2 转化节点与监测指标

| 节点 | 关键指标 | 基准值 | 监测方式 |
|------|---------|-------|---------|
| 曝光→点击 | CTR（点击率） | 图片 ≥1.5%，视频 ≥2.5% | 广告平台后台 |
| 点击→落地页 | 到达率 | ≥90% | UTM+页面埋点 |
| 落地页→表单 | 表单完成率 | ≥8% | 表单提交事件 |
| 表单→有效线索 | 有效率 | ≥60% | 人工/系统核验 |
| 线索→付费 | 转化率 | ≥10% | CRM 回传 |
| 全链路 | CPA（单线索成本） | 按课程定价 ≤客单价 15% | 平台+CRM |

### 4.3 追踪配置要求

- 所有广告 URL 必须携带 UTM 参数：`utm_source`、`utm_medium`、`utm_campaign`、`utm_content`、`utm_term`
- 落地页必须部署转化追踪代码（像素/JS SDK）
- 表单提交按钮绑定转化事件
- 配置转化回传（API 回传或像素回传）
- 落地页不得使用影响追踪的跨域跳转

## 六、Skill 自动化映射（Rube MCP 连通后）

以下为 `adrapid-automation` Skill 在环境就绪后可自动执行的检查流程，严格遵循 SKILL.md 规定的工作流：

### 步骤 1：发现工具（必须最先执行）
```
RUBE_SEARCH_TOOLS
queries: [{use_case: "List all ad banners and their statuses for online course campaign audit", known_fields: ""}]
session: {generate_id: true}
```
> SKILL.md 规则："Always search first — Tool schemas change. Never hardcode tool slugs or arguments"

### 步骤 2：检查 Adrapid 连接状态
```
RUBE_MANAGE_CONNECTIONS
toolkits: ["adrapid"]
session_id: "<步骤1返回的session_id>"
```
> 若状态非 ACTIVE，需通过返回的 auth link 完成授权后再继续。

### 步骤 3：执行 Banner 审计
```
RUBE_MULTI_EXECUTE_TOOL
tools: [{
  tool_slug: "<步骤1发现的 List Banners 工具 slug>",
  arguments: {<按搜索返回的 schema 填写>}
}]
memory: {}
session_id: "<同一 session_id>"
```
> SKILL.md 规则："Memory parameter — Always include memory in RUBE_MULTI_EXECUTE_TOOL calls, even if empty"

### 步骤 4：获取 API 与账户信息（健康检查）
```
RUBE_MULTI_EXECUTE_TOOL
tools: [
  {tool_slug: "<Get API info slug>", arguments: {}},
  {tool_slug: "<Get user and API info slug>", arguments: {}}
]
memory: {}
session_id: "<同一 session_id>"
```

### 步骤 5：分页拉取完整 Banner 列表
> SKILL.md 规则："Pagination — Check responses for pagination tokens and continue fetching until complete"

### 自动化结果映射
| Skill 返回 | 对应检查项 |
|-----------|-----------|
| List Banners 返回的 Banner 状态字段 | C-11（素材状态为 ready） |
| List Banners 返回的 Banner ID 列表 | C-12（无失效素材被引用） |
| Get API info 返回版本 | A-04（API 可访问） |
| Get user and API info 返回账户 | A-05（账户信息可获取） |
| RUBE_MANAGE_CONNECTIONS 状态 | A-03（连接 ACTIVE） |

**重要限制说明**：Adrapid 工具包仅含 3 个只读工具（Get API info、Get user and API info、List Banners），**不具备**创建/修改/删除 Banner、上传素材、创建落地页或管理广告投放的能力。因此本方案中素材规格校验、落地页技术检查、文案合规扫描等均由本地脚本完成，不依赖该 Skill。

## 七、约束导致的方案变化说明

| 约束 | 对方案的影响 | 应对方式 |
|------|------------|---------|
| 不新增非必要依赖 | 验证脚本仅使用系统自带工具（bash/grep/awk/file/curl/openssl），不安装 npm/pip 包 | 编写纯 POSIX shell 脚本 `verify_plan.sh` |
| 不修改无关文件 | 所有产物仅写入当前任务目录，不触碰系统或其他项目文件 | 脚本仅在 `./ad-campaign-review/` 下读写 |
| 本地可重复验证 | 检查逻辑不依赖在线服务，可离线运行 | 素材规格检查基于本地文件元数据；合规检查基于关键词词库 |
| 外部账号只做到确认前步骤 | 不实际调用 Rube MCP/Adrapid API，不完成 OAuth 授权 | 提供连通性测试命令（curl），标注 Skill 执行流程供授权后使用 |
| Rube MCP 端点不可达 | Skill 的 3 个工具均无法执行 | 清单中 [可由 Skill 执行] 项标注为"待 MCP 连通后执行"，当前以人工核验替代 |
| 无 Adrapid 账户 | 无法拉取真实 Banner 列表 | 提供模拟输出格式说明，不伪造数据 |

## 八、验证证据

验证脚本 `verify_plan.sh` 的执行结果见同目录 `verification-evidence.txt`。

脚本验证范围：
1. 方案文档结构完整性（五个必交付章节均存在）
2. 素材规格表关键字段完整性（尺寸/格式/大小/文案占比）
3. 合规词库覆盖（绝对化用语/效果承诺关键词）
4. 转化路径节点完整性（曝光→点击→落地页→CTA→表单→成功页→跟进）
5. 检查项编号唯一性与覆盖（C-/L-/A- 系列无缺号、无重复）
6. Rube MCP 端点连通性（安全的只读探测，不发送凭证）
7. 脚本自身幂等性（重复运行结果一致）
