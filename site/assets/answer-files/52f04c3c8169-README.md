# 城市共享工具借用

一个纯前端、可直接打开的响应式网页，用于社区共享工具的浏览、筛选与借用。

## 运行方式

### 方式一：直接双击打开（推荐）
直接用浏览器打开 `index.html` 文件即可，无需任何服务器或依赖。

### 方式二：本地 HTTP 服务
```bash
# Python 3
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080

# 或 Node.js
npx serve .
```

## 功能说明

| 功能 | 说明 |
|------|------|
| 物品筛选 | 支持按分类（电动工具、手动工具、清洁工具、户外园艺、测量仪器）筛选，支持关键词搜索 |
| 可借状态 | 每件工具显示"可借"（绿色）或"已借出"（橙色）状态标签，已借出工具的借用按钮禁用 |
| 借用说明 | 页面底部包含 6 步借用流程说明及注意事项 |
| 移动端操作区 | 屏幕宽度 ≤640px 时，底部显示固定操作栏，选择工具后可一键借用 |
| 借用确认 | 点击借用后弹出确认窗口，显示工具详情、押金、借用期限等信息 |
| 统计概览 | 顶部显示工具总数、可借数量、已借出数量 |

## 技术栈

- 纯 HTML + CSS + JavaScript，无任何外部依赖
- CSS Grid + Flexbox 响应式布局
- CSS 媒体查询适配桌面端（多列网格）和移动端（单列 + 底部操作栏）
- 适配 iOS 安全区域（`env(safe-area-inset-bottom)`）
