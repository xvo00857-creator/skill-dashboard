## 二、实际影响交付结果的 SKILL.md 规则

1. **视频能力边界（SKILL.md 视频章节）**：Skill 视频模块为"MoviePy + Ken Burns 慢推拉、商品图片轮播 + 标题叠加、9:16 竖屏、时长可配置（默认 15 秒）、3 秒文字钩子 + 2 秒 CTA、无 `bgm.mp3` 时不挂音轨"。
   - 影响：30 秒竖屏版本在 Skill 能力内，我通过参数/脚本适配实现（钩子 3s→2s、时长 15s→30s、分辨率提升至 1080×1920），未引入 Skill 之外的视频能力；无音轨直接满足"不使用未授权音乐"。
2. **"网络不可用回退 Mock 数据（开发调试用）"（SKILL.md 注意事项）**：实际运行 `scrape` 时，1688 搜索页经 BeautifulSoup 解析到 0 条（页面为 JS 渲染），Skill 按此规则回退内置 5 条充电宝 Mock 数据。
   - 影响：本次选品、定价、上架模板、推广方案均基于该 Mock 数据，**不是真实 1688 商品**，已在下文标注。
3. **"推广文案和关键词为 AI 生成参考，实际投放需人工审核"（SKILL.md 注意事项）**：阅读 `promoter.py` 确认 `search_volume`/`competition`/`suggested_bid` 由 `random` 生成，非真实平台数据。
   - 影响：推广方案仅作格式参考，数值不可用于真实投放决策。

## 四、数据来源与局限（务必注意）

- **商品数据为 Skill 内置 Mock 回退数据**：5 个充电宝的标题、价格（¥19.80–¥68.00）、供应商、评分、图片 URL（`O1CN01xxxx.jpg` 等占位链接，无法下载）均为 `scraper.py` 中硬编码的开发调试数据，**不代表真实 1688 在售商品**。
- **定价为公式计算结果**：视频中 $19.31 是 `cleaner.py` 对 Mock 商品"迷你胶囊充电宝 5000mAh"（供货价 ¥19.80）按 config.yaml 参数计算的上架价（总成本 $6.44，3.0 倍加价，毛利率 66.67%），计算过程真实，但底层成本来自 Mock。
- **英文标题/关键词质量有限**：`cleaner.py` 的标题"翻译"为关键词提取 + 拼音占位，纯中文标题会变成"5000mAh - Wholesale"这类残缺形式，导致推广关键词出现"wholesale Wholesale"等低质词；真实使用需人工改写文案。
- **推广数值为算法/随机生成**：`search_volume`、`competition`、`suggested_bid` 为 `random` 生成；"蓝海市场""预期日销 $200"为规则判断与简单公式输出，**非真实平台数据**，SKILL.md 亦声明需人工审核。
- **上架仅导出模板文件**：未配置各平台 API 密钥，未真实发布到任何平台；模板中的图片 URL 为 Mock 占位链接，上架前需替换为真实图床。
- **未执行真实代发/下单**。

## 五、视频适配点（相对 Skill 原生视频模块）

| 项 | Skill 原生 | 本次适配 | 原因 |
|---|---|---|---|
| 钩子时长 | 3 秒纯文字页 | 2 秒（黑底大字"PHONE AT 1%?"+ 产品图） | 题目要求前 2 秒建立信息钩子 |
| 总时长 | 默认 15 秒，可配 | 30 秒 | 题目要求 30 秒 |
| 分辨率 | 720×1280 | 1080×1920 | 提升清晰度，仍为 9:16 |
| 字体 | Linux DejaVuSans 路径（macOS 不存在会回退 PIL 默认字体） | macOS Arial Bold / Helvetica | 运行环境为 macOS |
| 音轨 | 有 `assets/bgm.mp3` 才加 BGM | 显式 `audio=False`，无音轨 | 不使用未授权音乐 |
| 文案语言 | 英文模板（HOOK_TEMPLATES） | 英文（跨境 TikTok Shop 场景） | 与 Skill 一致；交付文档为中文 |
| moviepy 版本 | 1.x API | 适配 2.x API | 环境已装 moviepy 2.2.1 |
| 静音可懂 | 底部标题+价格 | 每段大字幕 + 卖点 + 价格 + CTA | 题目要求静音可理解 |

## 六、素材合规

- 5 张商品图均由 **Seedream 5.0 Pro** 文生图生成，提示词明确要求无人物、无手、无品牌 Logo、无文字、无水印。
- 视频无音轨、未使用任何第三方音乐；未使用任何真实人物肖像或素材。
- 视频中产品为生成的虚构外观，不含真实品牌标识。
