# 第三章 旧地址

槐树街在桥西区最老的一片居民区里，街两边是上世纪八十年代的红砖楼，外墙皮剥落，露出灰色的水泥。网约车开不进去，沈渡在街口下了车，步行往里走。

凌晨三点，整条街黑着，只有路口的小卖部亮着一盏白炽灯，卷帘门拉了一半。47号在巷子深处，一栋六层的老楼，单元门的铁门虚掩着，门锁被撬过，金属搭扣歪在一边。

沈渡推门进去，楼道里堆着自行车和纸箱子，墙面上贴满了疏通下水道的小广告。他摸黑上了三楼，302的门也虚掩着，门缝里透出一点路灯的光。

他推开门。

房间不大，一室一厅，家具还在，但全被翻过了。抽屉拉出来扔在地上，衣柜门敞着，衣服被褥丢了一地。书架上的书散落在桌面和地板上，相框碎了，玻璃碴子踩上去咯吱响。

沈渡站在门口扫了一眼，然后走进去，尽量不碰任何东西。

客厅的墙上有图钉的痕迹，纸被撕掉了，留下几个长方形的浅色印子。赵国富的记忆里，墙上贴着照片和地图，用红线连着。那些东西被那个男人扯走了。

他蹲下来，翻看地上的书和纸。大部分是旧报纸和杂志，和案件无关。他在书桌底下摸到一个铁盒子，打开，里面是几支笔、一个放大镜、一沓名片。和赵国富身上的名片一样。盒底压着一张超市小票，日期是上周，买了面包、矿泉水和一卷胶带。

沈渡把铁盒子放回去，继续找。他翻了厨房，灶台是冷的，冰箱里只有半瓶酱油和两个发了霉的馒头。卫生间的镜子裂了一道纹，洗手台上有一个漱口杯和一支牙刷。赵国富在这里住过一段时间，不是一天两天。

卧室里更乱。床垫被掀开，斜靠在墙上，床板下面的空间也被翻过。他蹲在床边，手指沿着地板缝隙摸过去。在床腿旁边，他的指尖碰到一个硬物。

是一张折叠的纸，塞在地板缝里，翻东西的人没发现。

他抽出来，展开。是一份病历，纸已经发黄，边角磨损。上面印着江城市第一人民医院的抬头，日期是三年前的六月十七日。

患者姓名：沈渡。性别：男。年龄：二十五岁。

诊断：头部钝器伤，头皮裂伤，逆行性遗忘。建议住院观察。

沈渡盯着病历上的名字和日期。三年前六月十七日，他就是那天在江边被发现的。但这份病历上的就诊日期比他被发现早了至少两天。他被路人发现时身上没有任何证件，也没有就医记录。

这意味着，在被发现之前，他已经去过医院。

病历里夹着一张照片。彩色的，有些褪色，看起来是在某个公园拍的。照片上是两个十四五岁的少年，站在一棵柳树下面，穿着一样的白色T恤。两个人长得一模一样，同样的短发，同样的高眉骨。左边那个少年的左眉骨上有一道新鲜的疤，结着痂。右边那个没有疤，笑着，露出一颗虎牙。

沈渡拿着照片的手开始发抖。

他摸了摸自己眉骨上的疤。照片上左边那个少年，就是他。右边那个，他从来没有见过。但那张脸，和他在赵国富记忆里看到的那个男人，是同一个人。

两兄弟。双胞胎。

"你找谁啊？"

声音从门口传来。沈渡猛地回头，一个老太太站在门口，穿着棉袄，手里拎着一个垃圾袋，正探头往屋里看。

"我，"沈渡把照片和病历塞进外套内袋，"我以前住这儿，回来看看。"

老太太打量了他几眼，哦了一声。"你是老沈家的吧？这房子空了三年了。"

"您认识以前住这儿的人？"

"怎么不认识，老沈家那对双胞胎，老大叫沈渡，老二叫沈江。"老太太把垃圾袋放在门口，"他爸妈走得早，哥俩自己过。三年前出了那档子事，老二没了，老大也不见了。"

沈渡的喉咙发紧。"什么事？"

"说是在江边出的事，具体我也不清楚，警察来了好几趟。"老太太摆摆手，"后来这房子就空了，前几天还有个老头来翻东西，说是搞什么调查。那老头也怪，白天不来，专挑晚上来，戴个眼镜，在屋里一待就是半宿。"

沈渡问："那个老头是不是姓赵？"

"对，姓赵，戴个眼镜。"老太太看了他一眼，"你真是老沈家的？我怎么看你和照片上不太一样了？"

"过了很多年了。"沈渡说。

老太太又看了他两眼，拎着垃圾袋走了。

沈渡在原地站了很久。他叫沈渡，他有一个双胞胎弟弟叫沈江。三年前在江边出了事，沈江死了，他失了忆。然后有人杀了赵国富，那个人长着他的脸。

他拿出手机，打开相册，对着镜子拍了一张自己的脸。左眉骨上的疤，和照片上左边少年的位置一模一样。

他把手机收起来，最后看了一眼房间，转身下楼。

同一时间，江城市公安局刑侦支队。

陆征坐在办公室里，面前的电脑屏幕上是赵国富所住旅馆周边的监控。技术队已经把案发时段的录像调了出来。九点四十七分，一个穿深色外套的男人从旅馆后门出来，帽檐压得很低，走路时左肩略向前倾。

陆征把画面暂停，放大。男人经过路灯下时抬了一下头，监控拍到了半张脸。像素不高，但眉骨的弧度和那道疤清晰可辨。

陆征盯着屏幕，手指在桌面上敲了两下。他拿起手机，翻到一个号码，殡仪馆的工作手机，沈渡。他看了两秒，把手机放下了。

"陆队，"下属推门进来，手里拿着一个U盘，"殡仪馆那边的监控调来了，昨晚那个遗容修复师值夜班，八点到早上八点，门禁和监控都有，全程没离开过。周素梅十点去送过夜宵，能作证。"

陆征把U盘插进电脑，调出殡仪馆的监控。九点四十七分，沈渡在操作间里给死者描眉，低着头，侧脸对着摄像头。同一时间，旅馆后巷的监控里，另一个"沈渡"正压低帽檐走过路灯。

陆征把两个画面并排放大。两张脸，一样的眉骨，一样的鼻梁，一样的疤。一个在殡仪馆，一个在旅馆。

"查这个人。"陆征指着屏幕上沈渡的脸，"所有背景，三年前的，全部。另外，查他有没有兄弟姐妹。"

沈渡回到殡仪馆时天快亮了。他在门口的早餐摊买了两个包子，没吃，揣在兜里。值夜的老头还在看电视，换了个早间新闻频道，主持人在念天气预报，说今天有小雨。

他往地下室走，想去冷库把赵国富的遗物再检查一遍。走到走廊尽头，他停住了。

冷库的门虚掩着，留了一条缝。他记得自己昨晚锁了门，钥匙一直在周素梅那里，他今早还的时候周素梅还没上班。

冷气从门缝里渗出来，在走廊的地砖上结了一层薄霜。

沈渡推开门。

冷库里的灯亮着，嗡嗡作响。赵国富的遗体还在原来的位置，裹尸袋拉得好好的。但冷库最里面，靠墙的位置，多了一具担架床。

担架床上盖着白布。白布下面是人的轮廓，长度和他差不多。

沈渡站在原地，手在口袋里攥着那张双胞胎照片。他走过去，每一步都能听见自己的鞋底踩在水泥地上的声音。

他伸手，掀开白布。

一张脸。闭着眼，面色灰白，嘴唇发紫。短发，高眉骨，左眉骨上有一道疤。

和他一模一样。

遗体的右手放在身侧，手里攥着什么。沈渡蹲下来，一根一根掰开那只僵硬的手指。

是一张纸条，从笔记本上撕下来的，上面用圆珠笔写了三个字：

"别找了。"

冷库的灯闪了一下。沈渡跪在地上，手里攥着纸条，看着担架上那张和自己一模一样的脸。死者的皮肤是冷的，灰白色，和他修过的每一张脸都不同。这张脸的眉骨、鼻梁、下颌线，甚至左眉上那道疤的位置，和他分毫不差。

排气扇在头顶转，发出有规律的咔嗒声，像倒计时。
