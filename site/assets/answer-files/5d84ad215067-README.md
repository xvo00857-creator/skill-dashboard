# 用户反馈处理最小可用工作流

输入用户反馈，输出去重后的主题、优先级和下一步行动。

基于 `product_brief.md`（智能随行杯）领域配置，遵循 `agent-platform-deploy` Skill 的安全分层与部署规范。

## 目录结构

```
feedback-workflow/
├── feedback_workflow.py          # 主程序（CLI + Python API）
├── README.md                     # 本文档
└── examples/
    ├── sample_feedback.json      # 样例输入（12 条真实结构反馈）
    └── sample_output.json        # 样例输出（由程序实际运行生成）
```

## 运行环境

- Python 3.8+（实际验证环境：Python 3.13.13）
- 零第三方依赖，仅使用标准库
- `--backend rule`（默认）可完全离线运行
- `--backend agent` 需要 gcloud CLI 且已部署 Agent Platform 端点（见下文）

## 接口定义

### 1. 命令行接口（CLI）

```bash
# 基本用法：读取 JSON 文件，结果输出到 stdout
python3 feedback_workflow.py --input feedback.json --pretty

# 从标准输入读取（支持纯文本/JSONL）
cat feedback.txt | python3 feedback_workflow.py --stdin --pretty

# 写入文件
python3 feedback_workflow.py -i feedback.json -o result.json --pretty

# 使用 Agent Platform 端点（需 gcloud + 已部署模型）
python3 feedback_workflow.py -i feedback.json \
    --backend agent \
    --endpoint-url https://<DEDICATED_DNS> \
    --model-id feedback-analyzer
```

**参数说明：**

| 参数 | 必填 | 说明 |
|------|------|------|
| `--input/-i` | 二选一 | 输入文件路径（JSON 数组 / JSONL / 纯文本） |
| `--stdin` | 二选一 | 从标准输入读取 |
| `--backend/-b` | 否 | `rule`（默认，本地规则引擎）或 `agent`（Agent Platform 端点） |
| `--endpoint-url` | agent 时必填 | 已部署端点的 dedicated DNS URL |
| `--model-id` | 否 | 端点上的模型 ID |
| `--output/-o` | 否 | 输出文件路径；不指定则输出到 stdout |
| `--pretty` | 否 | 格式化 JSON 输出 |

### 2. Python API

```python
from feedback_workflow import RuleBasedBackend, AgentPlatformBackend, run_workflow, result_to_dict

# 本地规则引擎
backend = RuleBasedBackend()
result = run_workflow("杯子漏水了\n有塑料味", backend)
data = result_to_dict(result)

# Agent Platform 端点
backend = AgentPlatformBackend(endpoint_url="https://...", model_id="feedback-analyzer")
result = run_workflow(raw_text, backend)
```

### 3. 输入格式

支持三种格式，自动识别：

- **JSON 数组**：`[{"id":"fb-001","text":"反馈内容","source":"来源","created_at":"日期"}, ...]`
- **JSONL**：每行一个 JSON 对象
- **纯文本**：每行一条反馈，自动分配 `fb-NNN` 编号

每条反馈至少需要 `text`（或 `content`/`feedback`）字段。

### 4. 输出格式

```json
{
  "product": "智能随行杯",
  "analyzed_at": "2026-08-13T22:34:58+08:00",
  "total_feedback": 12,
  "deduplicated_theme_count": 11,
  "backend_used": "rule",
  "themes": [
    {
      "theme_key": "safety_material",
      "theme_label": "材质与安全",
      "priority": "P0",
      "count": 1,
      "feedback_ids": ["fb-005"],
      "representative_feedback": ["杯子有股塑料味..."],
      "next_actions": ["立即暂停相关批次发货..."],
      "related_gaps": ["食品接触材料报告尚未提供"]
    }
  ],
  "notes": ["结论基于规则引擎...", "禁止编造：...", "产品不完整信息（待补）：..."]
}
```

**优先级定义：**

| 级别 | 含义 | 示例 |
|------|------|------|
| P0 | 紧急，涉及安全 | 材质异味、有毒、食品接触安全 |
| P1 | 高，核心功能问题 | 漏水、保温不达标、杯盖无法拆洗 |
| P2 | 中，一般功能/体验 | 重量、容量、智能功能、包装物流 |
| P3 | 低，外观/正面评价/建议 | 颜色偏好、好评、价格反馈 |

## 去重逻辑

1. 同一条反馈可命中多个主题（多标签），分别计入各主题计数
2. 同一主题下，完全相同的反馈文本只保留一条作为代表（`representative_feedback`，最多 5 条）
3. 同一主题的优先级取该主题下所有反馈的最高优先级
4. 主题按优先级排序，同优先级按反馈数量降序

## 失败处理

| 场景 | 退出码 | 处理方式 |
|------|--------|----------|
| 输入文件不存在 | 2 | stderr 输出错误信息，不产生输出 |
| 输出文件无法写入 | 2 | stderr 输出错误信息 |
| 输入为空 | 3 | stderr 提示"输入为空" |
| JSON 格式错误 | 3 | stderr 输出解析错误位置 |
| 反馈缺少 text 字段 | 3 | stderr 指出第几条缺少字段 |
| agent 后端 gcloud 未安装 | 4 | stderr 提示安装 gcloud 或改用 rule 后端 |
| agent 后端认证失败 | 4 | stderr 输出 gcloud 错误信息 |
| agent 端点 HTTP 错误 | 4 | stderr 输出 HTTP 状态码和响应体 |
| agent 端点网络不可达 | 4 | stderr 输出连接错误 |
| LLM 返回非 JSON | 4 | stderr 提示解析失败并截断原文 |
| `--backend agent` 未指定 `--endpoint-url` | 2 | stderr 提示参数缺失 |

## Agent Platform 端点部署说明（被阻塞）

`--backend agent` 需要一个已部署的 Agent Platform 端点。按 `agent-platform-deploy` Skill，部署流程为：

1. 安装并认证 gcloud（Tier R，只读操作，无需确认）
2. `gcloud ai model-garden models list` 发现可用模型
3. `gcloud ai model-garden models list-deployment-config --model=<ID>` 验证可部署性
4. `gcloud ai model-garden models deploy ...`（Tier M，需用户确认费用后执行）
5. `gcloud ai endpoints describe <ID> --format="value(dedicatedEndpointDns)"` 获取端点 URL

## 产品约束遵循

以下约束来自 `product_brief.md`，已内置于程序：

- **禁止编造**：第三方检测结论、销量、用户评价、竞品价格（输出 notes 中持续提醒，行动建议中不包含此类内容）
- **结论与假设分开**：`notes` 字段标注规则引擎的局限性，建议人工复核 P0/P1
- **待补项明确列出**：首发日期、防水等级、食品接触材料报告在 `related_gaps` 和 `notes` 中标注
- **中文交付**：所有输出为中文
- **核心卖点对齐**：保温/重量/杯盖三个核心卖点的反馈优先处理（P1）
