## 四、利益冲突声明（Conflict of Interest Declaration）

> 规则依据：SKILL 角色激活表将并购/term sheet/legal exposure 类议题的必激活角色列为 **GC、CEO、CFO**；本部分由 GC 牵头，在会议开始、议题 1 进入审议**之前**完成。任何未完成声明的董事不得参与该议题表决（回避）。

**4.1 须主动声明的情形（任一命中即须声明并由董事会决定是否回避）：**
1. 在目标公司或其控股股东、实际控制人处任职、担任董事/顾问、或过去 24 个月内曾任上述职务；
2. 直接或间接持有目标公司股权、期权、可转债或其他经济利益（含通过 SPV、基金、代持）；
3. 与目标公司创始人、实控人、关键高管存在配偶、直系亲属、三代以内旁系亲属或共同生活关系；
4. 过去 24 个月内与目标公司存在重大业务往来（供应、客户、借款、担保），或正在谈判此类往来；
5. 从本次交易中可能获得除董事/股东身份常规收益之外的任何个人收益（董事席位、顾问费、留任奖金、对赌收益等）；
6. 其他可能影响独立判断的情形（含声誉、竞业、未来雇佣安排等）。

**4.2 操作流程：**
1. 会前 T-2：GC 将本声明模板随预读材料一并发全体董事；
2. 会前 T-1：每位董事书面回复（邮件/飞书即可）"无利益冲突"或"存在以下冲突：…"；
3. 会议开始、议题 1 之前：Chief of Staff 当场宣读声明结果；存在冲突的董事由董事会决定其**全程回避**或**仅就相关子议题回避**；
4. 回避情况记入会议纪要（Layer 2），并在决议中注明"本决议经 X 名无关联董事审议/表决通过"。

**4.3 本次会议声明结果（待填写）：**

## 五、决策条件（Conditions for Decision）

> 规则依据：SKILL Phase 4/5 要求"Decision Required（一句话）+ Recommended Decision + Action Items（owner、deadline）"，且 Phase 5 必须由创始人确认；Phase 3 批评者须指出"谁不在场/未被提及的风险/共享但未验证的假设"。下列条件用于约束本次会议**能决到哪一步**，防止在信息不足时做出不可逆的重大资本决策。

**5.1 本次会议可直接做出的决策（满足全部前置条件）：**
- [ ] 预读材料中"必读"项齐备（见第三节）；
- [ ] 利益冲突声明已完成，需回避董事已回避；
- [ ] 董事会法定人数满足章程要求，且无关联董事比例导致表决无效；
- [ ] CFO 明确给出估值区间、资金来源、对现金流/跑道影响，并标注数据为 VERIFIED 或 ASSUMED（按 SKILL Phase 2 贡献格式，🟢/🟡/🔴）；
- [ ] GC 明确给出交易结构、监管/反垄断初判、重大法律风险，并标注置信度；
- [ ] Executive Mentor（批评者）已完成 Phase 3，且未指出"未被回应的致命风险"或"全员一致但无独立证据"的群体思维信号；
- [ ] 创始人在 Phase 5 明确选择 ✅ Approve / ✏️ Modify / ❌ Reject（不可默认通过）。

**5.2 分级决策建议（防止一步到位）：**
| 决策层级 | 内容 | 本次是否建议表决 | 前置条件 |
|----------|------|------------------|----------|
| L1 | 启动正式尽调 + 授权签署 NDA/排他期条款 | **建议可决** | 目标 One-Pager + CFO/GC 初步意见齐备 |
| L2 | 认可谈判估值上限与交易结构边界 | 视材料齐备度 | L1 + CFO 估值备忘录 + GC 结构意见 + 资金来源确认 |
| L3 | 原则同意推进至最终签约（以尽调结果为准） | **原则上本次不表决** | L2 + 尽调初步发现 + 整合方案 + 融资到位证明 |
| L4 | 批准最终签约与交割 | 另开专题董事会 | 完整尽调报告、最终交易文件、融资文件、监管批准路径 |

**5.3 触发"暂缓/不收购"的条件（任一命中即应默认暂缓，由支持方举证推翻）：**
- 尽调或初步材料发现**未披露的重大负债、诉讼、税务或合规问题**；
- 核心团队留任无法保障，且业务高度依赖关键人；
- 估值超出 CFO 给出区间上限，且协同效应无法量化支撑溢价；
- 资金来源未落实或显著影响公司 12 个月以上跑道；
- 触发反垄断/外资/行业监管审批且路径不确定；
- 数据/IP/隐私存在无法通过常规条款救济的瑕疵；
- Executive Mentor 指出"全员一致但无独立证据"的群体思维信号且未被消除。

**5.4 决策记录要求（依据 SKILL Phase 6）：**
- 本次决议写入 Layer 2（`~/.cls/decisions/approved/2026-08-10-acquisition-<slug>.md`）并追加到 `decisions.md` 索引；
- 被否决的方案标记 `[DO_NOT_RESURFACE]`，除非有新信息；

## 六、可推迟事项（Deferrable / Out of Scope / Parking Lot）

> 规则依据：agenda 模板"Out of Scope"段 + facilitation"Scope Creep → parking lot"规则。下列事项**本次会议不做决定**，明确推迟到何时/由谁异步处理，避免 bikeshedding 挤占重大议题时间。

**6.1 明确推迟到尽调完成后 / 签约前专题会决定：**
- 最终交易价格、支付节奏、对赌/earn-out 具体条款；
- 收购后品牌是否保留、产品命名、路线图合并细节；
- 被收购方法人主体存续/注销、股权置换比例等交割细节；
- 整合后的组织架构、汇报线、办公地点合并；
- 非核心人员的安置与补偿方案；
- 系统/IT/数据迁移的具体时间表。

**6.2 由责任人异步处理、下次会议报备即可：**
- 外部顾问（律所、财顾、审计、技术尽调机构）的选聘与费用——授权 CFO/GC 在预算内确定；
- 尽调资料室（VDR）的搭建与权限管理——GC 牵头；
- 内部知情人范围控制与沟通口径——CEO + GC；
- 对外披露/新闻稿口径（如需）——CEO + GC + 市场负责人。

**6.3 本次会议期间若被提出，直接进停车场（Parking Lot），不展开讨论：**
- 与本次收购无关的其他潜在并购目标讨论；
- 本次交易完成后的长期战略叙事/资本市场故事；
- 与目标公司产品 UI/命名等次级细节；
- 任何在 40 分钟时间盒内无法收敛、且不影响 L1/L2 决策的子问题。

**6.4 原议程的顺延建议：**
- 若本次新增议题导致总时长超出可承受范围，建议将原议程中**纯更新类（Update）**项改为书面预读 + 异步确认，本次会议保留**决策类（Decision required）**项；
- 被顺延的原议程项须明确新的处理时间（下次例会或异步截止日），不得悬空。
