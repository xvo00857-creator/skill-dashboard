# Decision Report: Local-First Knowledge Base for a 20-Person Cross-Platform Team

**Date:** 2026-08-07
**Decision context:** 20-person team, privacy-conscious, mixed macOS/Windows, choosing between Obsidian, Logseq, and Anytype for a shared knowledge base
**Depth:** Medium (per deep-research Skill)
**Sources:** 23 per-source files in `sources/`, 7 findings in `findings/`

---

## Executive Summary

**Recommendation: Obsidian** — with caveats.

Obsidian is the only tool of the three that is production-ready for a 20-person team today. It has the lowest direct TCO ($960/year for all 20 users with Sync), the strongest data portability (plain .md files), a mature cross-platform desktop app for both macOS and Windows, and a large ecosystem. Its weaknesses — no real-time co-editing, no fine-grained permissions, a 20-user hard cap, and a non-trivial learning curve for non-technical members — are real but manageable with conventions, a Git or Relay overlay, and a structured onboarding program.

Anytype has the most principled privacy architecture (CRDT-based, E2EE by default, no account required, open-source protocol) but its team collaboration is immature, Business edition is not yet GA, mobile is weak, and the object model creates the steepest learning curve. Logseq is open-source and beloved by individuals but its real-time collaboration (RTC) is still in alpha, there is no per-seat team pricing, and the dual-track file/DB migration creates risk.

**This is a "least-bad option" decision, not an enthusiastic endorsement.** No tool fully satisfies all six criteria for this team. The recommendation is contingent on mitigations listed in §6.

## 2. Comparative Analysis

### 2.1 Collaboration

| | Obsidian | Logseq | Anytype |
|---|---|---|---|
| Real-time co-editing | No (sync-based, no cursors) | Alpha (DB version only) | Yes (CRDT-based, but immature for 5+ users) |
| Max collaborators | 20 (hard cap per vault) | No team pricing; RTC in testing | No hard cap stated; independent reviews say "limited" for 10-50 |
| Permissions | All-or-nothing (owner can invite) | N/A (not team-ready) | ACL-based (more granular) |
| Comments/@mentions | Via plugins | Limited | Yes (basic) |
| Third-party overlay | Relay, Git, Self-hosted LiveSync | Git (file version) | None (by design) |

**Winner: Obsidian** — not because its collaboration is good, but because it's the only one that works for 20 people today. Anytype's ACL is architecturally superior but practically immature. Logseq's RTC is alpha. (Sources: 01, 10, 11, 16, 19, 21)

### 2.2 Data Portability

| | Obsidian | Logseq | Anytype |
|---|---|---|---|
| On-disk format | Plain .md files in folders | .md/.org (file version) / DB (beta) | Encrypted object store |
| Human-readable on disk | Yes | Yes (file version) | No |
| Export formats | N/A (already open) | Markdown, EDN | Markdown, Any-Block (Protobuf/JSON) |
| Import from competitors | N/A (it's the standard) | Markdown, OPML | Obsidian, Notion, MD, HTML, TXT, CSV |
| Lock-in risk | Minimal | Medium (DB version) | High (proprietary object graph) |

**Winner: Obsidian** — plain text files are the gold standard. Anytype's Markdown export loses object relationships. Logseq's DB version introduces migration uncertainty. (Sources: 01, 07, 12, 13, 14)

### 2.3 Offline Capability

| | Obsidian | Logseq | Anytype |
|---|---|---|---|
| Works offline (single user) | Yes | Yes | Yes |
| Offline team sync | No (needs connection to sync) | No (Sync needs connection) | Yes (mDNS P2P on local network) |
| Conflict resolution | Sync-merge (file-level) | File-level / CRDT (DB) | CRDT (automatic) |

**Winner: Anytype** (architecturally) — but all three work offline for individual use. Anytype's mDNS P2P is the only one that syncs between devices on a local network without internet. For a team in an office together, this is a genuine advantage. However, ACL changes require network connectivity. (Sources: 01, 06, 12)

### 2.4 Security & Privacy

| | Obsidian | Logseq | Anytype |
|---|---|---|---|
| E2E encryption | Optional (AES-256-GCM, scrypt) | Yes (DB version, RSA) | Default (Ed25519, always on) |
| No account required | Yes (core app) | Yes (core app) | Yes (no email) |
| No telemetry | Yes | Yes (open source) | Yes |
| Self-hosting | No (Sync is cloud-only) | Yes (DIY) | Yes (open-source protocol) |
| Third-party audit | Yes | Not found | Not found |
| Server locations | DigitalOcean (SG, FRA, SFO, SYD) | TBD | Distributed (P2P + self-hosted) |
| Data ownership model | Files on your device | Files on your device | Encrypted objects on your device |
| Governance | Private company | Open source (AGPL) | Dutch nonprofit (Any Association) |

**Winner: Anytype** — default-on E2EE, open-source protocol, no account, nonprofit governance, and self-hostable. Obsidian's privacy is good (no telemetry, optional E2EE, audited) but Sync is a cloud service you must trust. Logseq is open-source but its security story is less mature. (Sources: 01, 02, 06, 10)

### 2.5 Learning Cost

| | Obsidian | Logseq | Anytype |
|---|---|---|---|
| Core concept | Folders + Markdown + links | Outliner + daily journal | Objects + types + relations |
| Time to first useful system | 1-2 weeks (non-technical) | 1 week (if you like outlines) | 1-2 weeks (object model) |
| Onboarding quality | Large community, many guides | Smaller community | Insufficient documentation |
| Non-technical friendliness | Moderate (Markdown barrier) | Moderate (outliner barrier) | Low (conceptual barrier) |
| Real team failure reports | Yes (Worktile: >50% non-tech failure) | Not found | Multiple reviews cite steep curve |

**Winner: Tie between Obsidian and Logseq** — both have learning curves, but Obsidian's Markdown is a known quantity for many, and Logseq's outliner is intuitive for some. Anytype's object model is the most alien concept. However, the Worktile case study shows Obsidian can fail badly for non-technical teams. (Sources: 22, 23, jakeinsight, aisotools)

### 2.6 Total Cost of Ownership (20 users, 1 year)

| | Obsidian | Logseq | Anytype |
|---|---|---|---|
| Core app | Free (commercial use free since Feb 2025) | Free (AGPL open source) | Free (100MB) |
| Sync/collaboration | $48/user/year × 20 = **$960/year** | ~$60/user/year × 20 = ~$1,200/year (no team collab) | $96/user/year × 20 = **$1,920/year** (Pro) |
| Self-hosted option | No (Sync is cloud-only) | Yes (DIY, $0) | Yes ($0, or $300/mo Business when GA) |
| Commercial license | Optional ($50/user/year) | N/A | N/A |
| Training/onboarding | High (plan for it) | Medium | High (plan for it) |
| Admin overhead | Low-Medium | Medium (beta risk) | Medium-High (new paradigm) |

**Winner: Obsidian** (direct cost) — $960/year is the lowest paid option that actually works for 20 people. Self-hosted Anytype is $0 but requires ops capacity and the Business edition isn't GA. Logseq's paid sync doesn't include team collaboration. (Sources: 02, 03, 05, 08, 18)

## 3. Hypothesis Verification

Four falsifiable hypotheses were stated in Phase 1:

### H1: Obsidian lacks native real-time multi-user collaboration; Logseq's collaboration is weaker; Anytype's is the most immature
**Verdict: CONFIRMED with nuance.** Obsidian has no live co-editing (confirmed by official docs). Logseq's RTC is in alpha (confirmed by changelog and multiple independent sources). Anytype has CRDT-based real-time editing architecturally but independent reviews consistently rate it "limited" or "not suitable" for 5+ person teams. The nuance: Anytype's collaboration *technology* is the most advanced (CRDTs, ACLs), but its *maturity for teams* is the least proven.

### H2: Data portability hierarchy is Obsidian > Logseq > Anytype
**Verdict: CONFIRMED.** Obsidian's plain .md files are universally readable. Logseq's file version uses Markdown/Org-mode but the DB version introduces a new format. Anytype's encrypted object store is not human-readable; Markdown export loses structure. This is supported by official docs, independent technical analyses, and user reports.

### H3: All three are fully offline-capable, but Anytype's local-first implementation is the most thorough
**Verdict: CONFIRMED.** All three work offline for individuals. Anytype's CRDT/P2P/mDNS architecture is the only one that enables local-network sync without internet. However, this advantage is partially theoretical for a distributed team (not all on the same LAN).

### H4: Obsidian has the lowest direct software cost; Anytype has the strongest privacy model; there's a real tradeoff
**Verdict: CONFIRMED.** Obsidian Sync for 20 users is $960/year vs. Anytype Pro at $1,920/year. Anytype's privacy model (default E2EE, open protocol, no account, nonprofit governance) is objectively stronger. The tradeoff is real: you can have the cheapest mature option (Obsidian) or the most private option (Anytype), but not both in one tool today.

## 4. Adversarial Review

### Steel-man for Anytype (why we might be wrong)
1. **Privacy is the stated #1 priority.** If the team's privacy concerns are not just "we care about privacy" but "we handle sensitive data and need cryptographic guarantees," Anytype's default-on E2EE, open-source protocol, and nonprofit governance may outweigh maturity concerns. Obsidian Sync, even with E2EE enabled, routes through DigitalOcean and requires trusting Obsidian Labs.
2. **CRDT collaboration will mature.** Anytype's collaboration architecture is technically superior. If the team can tolerate 6-12 months of growing pains, they may end up with a better long-term platform.
3. **Self-hosting eliminates the cloud trust question entirely.** Anytype can be self-hosted for $0. Obsidian cannot. For a team with ops capacity, this is a decisive privacy advantage.
4. **The 20-user Obsidian cap is exactly at team size.** If the team grows to 21+, Obsidian Sync breaks. Anytype has no such hard cap.

### Steel-man for Logseq (why we might be wrong)
1. **It's fully open-source (AGPL).** No vendor lock-in at all. If the company behind Logseq disappears, the software continues. Obsidian is closed-source freeware; Anytype is open-core with a nonprofit.
2. **RTC may ship soon.** The changelog shows rapid progress. By Q4 2026 or Q1 2027, RTC could be production-ready.
3. **Outliner workflow may suit the team.** If the team's knowledge is heavily bullet-pointed, meeting-noted, or daily-journaled, Logseq's outliner is more natural than Obsidian's document model.
4. **$0 TCO with Git sync.** For a technical team, Logseq + Git is fully functional and free.

### Steel-man against Obsidian (why our recommendation might fail)
1. **The Worktile failure is a red flag.** A real team with >50% non-technical members failed at Obsidian onboarding. If this 20-person team has similar composition, the same could happen.
2. **No real-time collaboration is a daily friction point.** Teams accustomed to Notion/Google Docs will feel the absence of live cursors acutely. "Sync-based" collaboration means you won't see someone's changes until they sync, which can be minutes.
3. **20 users is the absolute max.** No room for growth. Adding a contractor or new hire requires a different approach.
4. **Obsidian Sync is a closed cloud service.** Despite E2EE, the team must trust Obsidian Labs and DigitalOcean. There is no on-prem option.

### What would change the recommendation
- If the team has **strong ops capacity** and **extreme privacy requirements** (e.g., handling regulated data), self-hosted Anytype becomes more attractive despite maturity risk.
- If the team is **growing beyond 20** in the next 6 months, Obsidian's hard cap is a problem.
- If **>40% of the team is non-technical**, none of these tools are ideal; consider whether a simpler tool (or Notion with E2EE via a third party) might be more pragmatic.
- If Logseq **ships RTC GA** with team pricing before the decision deadline, re-evaluate.

## 5. Confidence and Evidence Gaps

### High confidence (3+ independent source types)
- Obsidian's 20-user cap, no live editing, no fine-grained perms (official docs + independent + user reports)
- Obsidian's plain .md storage and portability (official + 3+ independent)
- Anytype's E2EE-by-default and CRDT architecture (official technical docs + independent)
- Anytype's encrypted on-disk format (official + 3+ independent)
- Pricing for all three (official pricing pages)
- Logseq RTC in alpha/beta (official changelog + 3+ independent)

### Medium confidence (2 source types)
- Anytype's team collaboration limitations (independent reviews + official docs, but no large-scale case studies found)
- Learning curve estimates (multiple independent reviews, but self-reported and variable)
- Obsidian's onboarding failure rate for non-technical users (one detailed case study + general reviews)

### Evidence gaps (flagged as insufficient)
- **Anytype "10 editor cap"** reported by popi.ai (Source 15) could not be verified against official docs. It may be outdated or refer to a previous plan limit. Not used as a decisive factor.
- **Logseq RTC GA date** is unknown. The changelog shows active development but no timeline.
- **Anytype Business edition GA date** is "coming soon" with no specific date.
- **No large-scale (20+ person) Anytype case studies** were found. Most Anytype team reviews are 2-5 person teams.
- **Security audits for Anytype and Logseq** were not found in public sources. Obsidian has been audited.
- **Logseq DB version migration stability** has user reports of issues but no comprehensive data.

## 6. Recommendation: Obsidian — with mitigations

If the team chooses Obsidian, these mitigations address its key weaknesses:

| Weakness | Mitigation |
|----------|-----------|
| No real-time co-editing | Add **Relay** (third-party CRDT layer with live cursors) for folders that need simultaneous editing, or accept async-by-design and establish "edit ownership" conventions |
| No fine-grained permissions | Structure vault so sensitive content is in a separate vault with restricted Sync access; use folder-level sharing via Relay |
| 20-user hard cap | If growth beyond 20 is expected within 12 months, plan a migration path now (the .md files make this easier) |
| Non-technical onboarding | Designate 1-2 "Obsidian champions"; create team templates and a style guide; run 2-hour onboarding workshops; allow a 30-day ramp-up period; consider a "starter vault" with pre-configured plugins |
| Obsidian Sync is cloud-only | If trust model requires it, use **Self-hosted LiveSync** (CouchDB/S3/MinIO) or **Git** instead of Obsidian Sync — this eliminates the DigitalOcean dependency at the cost of ops overhead |
| Privacy/Sync trust | Enable E2EE on the shared vault; review Obsidian's security audit report; consider self-hosted sync for maximum control |

### Pilot before full rollout
Run a 2-week pilot with 5 users (mix of technical and non-technical) before committing all 20. Test: creating/editing/syncing across macOS and Windows, conflict resolution, offline work then sync, and the onboarding experience for a non-technical user.

## 7. When to Revisit This Decision

- **3 months after rollout** (November 2026): Assess adoption rate, friction points, whether mitigations are working
- **If Anytype Business ships GA**: Re-evaluate Anytype as a migration target (Markdown export from Obsidian makes this feasible)
- **If Logseq RTC ships GA with team pricing**: Re-evaluate, especially if cost-sensitive
- **If team grows beyond 20**: Obsidian Sync cap forces a decision
- **If a team data incident occurs**: Re-evaluate the privacy/security tradeoff
