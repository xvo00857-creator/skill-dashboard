# 门店订单数据清洗与分析 — 交付说明

## 一、Skill 能力边界与任务假设的冲突（重要）

随消息上传的 `dummy-dataset.zip` 解压后仅含一个文件：`dummy-dataset/SKILL.md`，**未附带任何业务数据文件**。

SKILL.md 对该 Skill 的定义为：

> "Generate realistic dummy datasets for testing with customizable columns, constraints, and output formats (CSV, JSON, SQL, Python script)."

即 dummy-dataset 是一个**模拟数据生成**技能，其 8 步流程为：识别数据类型 → 定义列 → 确定行数 → 选择输出格式 → 套用真实模式 → 加业务约束 → 生成数据 → 校验输出。它**不包含**读取既有数据集、清洗、去重、缺失值处理、统计分析等能力。

题目假设该 Skill 可对"数据量较大、门店名称不一致、有缺失值与重复订单"的既有数据做读取/清洗/分析，这与 SKILL.md 的定义冲突。按要求"以文件规则为准"，本次处理方式为：

1. **在 Skill 能力边界内**：按 SKILL.md 的 "Template: Python Script Output" 模板，生成一份**明确标注为模拟（dummy）数据**的门店订单数据集，其中可控地注入了门店名称不一致、缺失值、重复订单、异常值等质量问题；
2. **以通用脚本能力补充**：另写清洗分析脚本对该模拟数据做真实处理，所有数字均来自实际运行，未编造；
3. **明确标注**：以下所有统计结果均基于模拟数据，不代表任何真实业务；题目所称"数据量较大"的真实数据集并未提供，因此无法对真实数据出结论。

## 三、实际影响交付结果的 SKILL.md 规则（至少一条）

**规则：SKILL.md 第 30–73 行的 "Template: Python Script Output"** 规定了生成器脚本的结构——Configuration（ROWS / FILENAME）、columns 定义、`generate_dataset()` 函数、`save_as_csv()` 函数、`__main__` 入口。

**对交付的实际影响**：`01_generate_dataset.py` 严格遵循该模板结构编写（含 ROWS、FILENAME 配置、columns 字典、generate_dataset 与 save_as_csv 函数、main 入口），因此交付的是"可执行的 Python 生成器脚本 + 由它生成的 CSV"，而非直接手写一个 CSV。这同时决定了数据是可复现的（固定随机种子 20260812），任何人重新运行脚本都会得到完全相同的 8160 条数据。

另一条相关规则是 SKILL.md 第 95–103 行 "Output Deliverables" 要求"Data validation and constraint compliance"与"Documentation of data generation logic"，因此生成脚本中显式声明了各缺失率/异常率/脏名称率，并在本说明中文档化。

## 五、可扩展处理方案要点

- **门店标准化**：采用显式映射表 `STORE_MAPPING`（标准名→已知写法列表），反查后无法匹配的标记为"未识别门店"，不做模糊猜测；新增门店只需在映射表追加一行。
- **缺失值不补零**：`amount`/`unit_price` 缺失时保留为空，打 `flag_missing_amount`/`flag_missing_price` 标记，汇总时排除并单独计数；`member_id` 缺失视为非会员（业务允许），单独统计但不作异常。
- **重复处理**：完全重复行打 `is_exact_dup` 标记（保留首条），不物理删除；同时检测同 `order_id` 多行。
- **异常检测**：负数量、零金额、金额与"数量×单价"不一致分别标记。
- **可复现**：生成器固定随机种子；管线记录输入文件 MD5；抽样固定种子。
- **可扩展**：映射表、抽样数、输入输出路径均在脚本顶部配置；管线按步骤函数化，便于追加新校验。

## 六、关键结果（均基于模拟数据，实际运行得出）

- 原始数据：8160 行；完全重复行 160 行；去重后 8000 行。
- 缺失：amount 234 行（2.87%）、unit_price 165 行（2.02%）、member_id 1939 行（23.76%，非会员）。
- 异常：负数量 39 行、零金额 26 行。
- 门店名称：33 种写法全部归一到 8 家标准门店，未识别 0 行。
- 有效计费订单 7707 笔，有效销售额合计 533,397 元（已排除重复、缺失金额、零金额、负数量行；缺失金额未按零计算）。
