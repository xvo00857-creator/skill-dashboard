# 权限清单（最小权限原则）

> 对应 SKILL.md 规则："CI should never have production secrets"、"Secrets stored in secrets manager, not in code"。
> 本自动化流程同样遵循：凭据不硬编码、不写入配置文件、按环境变量注入。

## 运行所需权限

| 操作 | 所需权限 | 凭据来源 | 当前状态 |
|---|---|---|---|
| 读取待办数据 | 任务系统只读权限（建议使用专用机器人账号） | 环境变量 `TASK_API_TOKEN` | 未配置（使用本地模拟数据） |
| 生成摘要 | 无外部权限（本地计算） | 不需要 | 已实现 |
| 发送摘要到群聊 | 群机器人 webhook（仅发消息权限，不可读历史） | 环境变量 `DIGEST_WEBHOOK_URL` | 未配置（占位） |
| 发送邮件 | SMTP 发件账号（仅发件权限） | 环境变量 `SMTP_USER` / `SMTP_PASS` | 未配置（占位） |
| 写入日志 | 本地日志目录写权限 | 不需要凭据 | 未启用 |

## 明确不需要的权限

- 不需要任务系统的写权限（本流程只读，不修改任何任务状态）
- 不需要管理员权限
- 不需要生产环境凭据
- 不需要访问团队成员个人信息（仅使用任务中已有的负责人字段）

## 凭据管理要求

1. 所有凭据通过环境变量注入，禁止写入代码、配置文件或版本库
2. `.env` 文件加入 `.gitignore`，仅保留 `.env.example` 模板
3. 机器人账号遵循最小权限：只读 + 仅发消息
4. webhook URL 视为密钥，不在日志中明文打印
5. 凭据轮换周期建议不超过 90 天

## 授权范围（待用户确认）

以下授权项当前均未获得，需用户逐项确认后方可执行：

- [ ] 授权读取指定任务系统中的待办数据
- [ ] 授权将摘要发送到指定群聊/邮件列表
- [ ] 确认接收方范围（五人团队全员？仅负责人？）
- [ ] 确认运行频率与时间
- [ ] 确认日志保留策略
