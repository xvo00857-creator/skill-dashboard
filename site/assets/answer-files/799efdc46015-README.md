# 3D 收集闯关 - 单关卡原型

一个基于 Three.js 的 3D 小游戏原型：控制蓝色小球在场地中收集金币、避开红色箱子，收集全部金币即过关。

## 运行方式

### 方式一：直接打开（推荐）
用现代浏览器（Chrome / Edge / Firefox / Safari）直接打开 `index.html` 即可。
Three.js 已随附在 `js/three.min.js`，**无需联网、无需安装任何依赖**。

### 方式二：本地静态服务器（可选）
若浏览器对 `file://` 协议有限制，可在本目录启动任意静态服务器：

```bash
# Python 3
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

```bash
# Node.js（若已安装 npx）
npx serve -l 8080 .
```

## 操作说明

| 操作 | 按键 |
|------|------|
| 移动 | W A S D 或 方向键 |
| 重新开始 | R 键 或 结算面板按钮 |

- 移动方向相对相机朝向（第三人称跟随）。
- 收集金色八面体 **+10 分**。
- 碰到红色箱子 **-5 分**并被弹开。
- 收集全部 10 枚金币即过关，显示得分与用时。

## 系统需求

- 支持 WebGL 的现代浏览器
- 鼠标 / 键盘
- 无需联网

## 已知限制（原型范围）

- 仅单关卡，金币与障碍物位置固定（便于复现验收）。
- 无音效、无粒子特效、无移动端触屏控制。
- 无存档 / 排行榜 / 多关卡。
- 碰撞为 XZ 平面近似（球-AABB、球-球），未做完整 3D 刚体物理。

## 自检

- 浏览器打开 `index.html?selftest=1` 可运行内置冒烟测试，自动验证移动、收集、碰撞、过关、重置，右上角显示结果。
- Node 单元测试：`node test/collision_test.js`（碰撞逻辑，10 项）。
- 详细结果见 `TEST_REPORT.md`。
