## 一、Skill 能力核实与能力匹配结论

### 1.1 `computer-use` 的真实能力（据 SKILL.md 原文）

该 Skill 是 **DeepChat 内置插件提供的桌面 GUI 自动化能力**，通过一组 CUA（Computer Use Agent）工具驱动**本机桌面应用**完成操作。其规定的强制循环为：

1. `start_session({ session, capture_scope: "auto" })` 声明会话
2. `list_apps` 解析应用
3. `launch_app` 启动目标
4. `list_windows({ pid })` 枚举窗口
5. `get_window_state({ pid, window_id, session })` 快照（动作前必拍）
6. `click` / `type_text` / `press_key` / `hotkey` / `set_value` 等执行动作
7. 读取 `## CUA action result`，仅 `effect="confirmed"` 可继续
8. `verify_state` 验证后置条件（仅 `status="satisfied"` 且 `stable=true` 算成功）
9. `end_session({ session })` 结束

**前置条件**：
- 必须在 DeepChat 宿主中运行，插件 id 为 `${OWNER_PLUGIN_ID}`、根目录 `${PLUGIN_ROOT}`（均为未解析模板变量）。
- 需要平台运行时：macOS 为 `DeepChat Computer Use.app`，Windows/Linux 为 `cua-driver(.exe)`。
- macOS 需辅助功能与屏幕录制权限（`check_permissions`）。
- 支持目标：`darwin/arm64`、`darwin/x64`、`win32/x64`、`win32/arm64`、`linux/x64`；不支持 `linux/arm64`。

**适用范围**：操作、检查、自动化真实桌面应用中的 GUI 任务（如操作飞书客户端、邮件客户端、浏览器页面等）。

### 1.2 当前环境的能力匹配结论：不匹配

| 检查项 | 结果 |

| 真实待办数据源、凭据、授权范围 | **未提供**。无飞书/项目管理工具的 API 凭据或登录态。 |
| 发送渠道凭据 | **未提供**。无邮件/IM webhook 或 token。 |

**结论**：无法按 SKILL.md 的强制循环真实驱动桌面应用。本次交付为**只读预演（dry-run）最小可用版本**：用本地脚本模拟"收集→筛选→摘要→人工确认"全流程，发送动作以桩函数拦截，不触达任何真实渠道。所有运行结果均来自合成数据，非真实执行。

## 三、风险识别

| 风险 | 等级 | 说明 | 预演中的处理 |
|---|---|---|---|
| **不可逆发送** | 高 | 邮件/群消息一旦发出无法可靠撤回；错误摘要可能引发误解或泄露个人工作状态。 | 发送为桩函数，零真实外发；`--send` 仍需终端输入 `CONFIRM` 二次确认。 |
| **个人敏感信息泄露** | 高 | 待办完成情况可反映个人绩效/工作负荷；若发错范围构成隐私泄露。 | 模拟数据全部虚构；脚本不读取任何真实系统；真实上线需脱敏与最小可见范围。 |
| **未核实事实被当作真实数据** | 中 | 无真实数据源时若直接编造待办并发送，等于传播不实信息。 | 预演输出明确标注"只读预演/合成数据"，不对外发送。 |
| **凭据滥用** | 中 | 脚本若硬编码 token 或使用个人登录态自动发送，存在越权与审计风险。 | 脚本不含任何凭据；真实版须从安全配置读取，遵循最小权限。 |
| **误操作 / 批量错误** | 中 | 自动化可能在数据异常时（缺日期、字段错位）产生错误分类。 | 数据结构校验、无截止日期单独列出待人工确认、异常退出码。 |
| **GUI 自动化误点** | 中 | 若未来用 CUA 操作真实桌面客户端，可能误点其他窗口或弹窗。 | 当前未使用 CUA；若启用须遵循 SKILL.md 的快照→动作→验证循环与 `capture_scope: "auto"` 窗口隔离。 |
| **剪贴板隐私** | 低 | CUA 的 `clipboard_read` 被 Skill 明确禁止（隐私敏感）。 | 预演脚本不使用剪贴板；未来 CUA 实现同样不得读取剪贴板。 |

## 六、停止条件（满足任一立即停止）

1. 数据源连接失败、鉴权失败或返回结构异常。
2. 待办数量为 0 或超出合理阈值（如 >200，可能拉取范围错误）。
3. 分类结果中"无截止日期"或"无法解析日期"占比 >30%。
4. 收件人名单与授权清单不一致。
5. 人工复核人未在规定时间内确认。
6. 脚本任何步骤返回非预期退出码（见下表）。
7. 若使用 CUA：出现 `effect="refused"`/`"partial"`/`"unverifiable"`/`"suspected_noop"`，或 `verify_state` 非 `satisfied + stable`。
8. 检测到弹窗/权限请求/登录页等非预期界面（CUA 场景）。

| 退出码 | 含义 |
|---|---|
| 0 | 正常完成（预演模式下未发送） |
| 2 | 数据文件错误（不存在/结构非法） |
| 3 | 日期参数错误 |
| 4 | 用户取消发送（未输入 CONFIRM） |
| 5 | 无发送记录可回滚 |
| 6 | 未授权（真实上线预留） |
