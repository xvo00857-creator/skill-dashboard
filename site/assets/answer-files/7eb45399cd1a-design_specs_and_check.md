## 1. 关键设计规范

### 1.1 色彩系统（仅三色）

| 角色 | 名称 | HEX | RGB | 用途 |
|------|------|-----|-----|------|
| 主色 | 深蓝 Deep Blue | `#0E2D52` | 14, 45, 82 | 外画布、深色面板、标题文字、Logo 框架 |
| 中性色 | 米白 Cream | `#F5F0E8` | 245, 240, 232 | 浅色面板、深色背景上的文字、名片底色 |
| 强调色 | 亮橙 Bright Orange | `#FF6B26` | 255, 107, 38 | Logo 信号三角、关键词高亮、CTA 芯片、点缀 |

**用色规则：**
- 深蓝为支配色（画布与节奏锚点），米白为内容承载色，亮橙仅作强调（建议占比 ≤ 10%）。
- 三色在每个面板中重复出现，保持跨面板一致性。
- 禁止引入第四色；阴影使用深蓝同色系加深，不使用纯黑或灰色。
- 摄影氛围面板（山景）允许大气透视产生的同色系明暗变化，但不得出现异色。

### 1.2 Logo 系统

**标志构成：**
- 圆角方形外框（米白描边 / 深蓝填充变体）+ 内部向上的等边三角形（亮橙）。
- 隐喻：方形 = 结构与聚焦窗口；三角 = 灯塔光束 / 向上信号。
- 设计方法：Monogram + Meaning（首字母 B 的几何抽象）+ Negative Space（三角在框内形成正负形）。

**变体：**
- 完整版：图标 + "BEACON" 字标
- 图标版：仅圆角方+三角（用于 App 图标、浏览器标签、芯片、头像）
- 反白版：深蓝底米白框 / 米白底深蓝框

**使用规则：**
- 四周留空 ≥ 标志高度的 1/4。
- 禁止拉伸、倾斜、换色（三色之外）、添加阴影或描边效果。
- 最小使用尺寸：图标 ≥ 24px。

### 1.3 字体规范

- **风格**：现代几何无衬线体（Geometric Sans-serif），笔画均匀，字怀开放。
- **推荐方向**：类似 Inter / DM Sans / Manrope 的人文几何无衬线（实际落地时需确认授权）。
- **层级**：
  - 展示级（字标 / 标语）：Bold / Black，大字号，宽松字距
  - 面板标签：Small Caps 或全大写，Regular，小字距
  - UI 芯片 / 组件：Medium，中等字号
- **可读性要求**：正文与标签必须足够大、足够稀疏；禁止小于 12px 的伪文本；禁止 lorem ipsum 与密集段落。

### 1.4 网格与间距

- **桌面横屏（16:9）**：3×3 网格，9 个等大面板，面板间 gutter 统一，外边距 = gutter × 1.5。
- **手机竖屏（9:16）**：自定义纵向网格，节奏为「全宽 → 双列 → 全宽 → 双列 → 全宽 → 双列」，gutter 与外边距同桌面版逻辑。
- 对齐：所有面板严格左对齐 / 居中对齐，使用隐形基线网格。

### 1.5 面板系统（9 面板）

|---|------|----------|----------|------|
| 1 | Logo 封面 | 左上 | 全宽顶部 | 深蓝 |

### 1.6 质感与细节

- 微妙纸张颗粒纹理（paper grain），低透明度。
- 山景面板使用半色调（halftone）/ 颗粒质感。
- 小页码 "01" 位于外画布右下角。
- 面板标签为全大写小字，位于面板底部。
- 不使用霓虹光、渐变彩虹、廉价投影。

## 2. 一致性检查结果

### 2.1 检查方法

- 人工目视检查两张成品图的每个面板。
- Python PIL 色彩量化分析（16 级色阶分桶 + 与目标三色的欧氏距离）。
- 逐条对照 SKILL.md 规则与用户约束。

### 2.2 色彩纪律

| 检查项 | 桌面 16:9 | 手机 9:16 | 结果 |
|--------|-----------|-----------|------|
| 主色是否为深蓝系 | 是（深蓝系色桶合计约 46%） | 是（深蓝系色桶合计约 70%） | 通过 |
| 米白面板是否统一 | 是（#F0E0D0 附近，JPEG 压缩偏暖） | 是 | 通过 |
| 亮橙是否仅作强调 | 是（占比小，集中在 Logo 三角/关键词/芯片） | 是 | 通过 |
| 是否出现第四色 | 结构面板无；山景面板有大气透视产生的青灰/暖黄过渡 | 同左 | 基本通过（见说明） |
| 色值标签准确性 | 橙色标签渲染为 "FX6P26"（AI 文字误差），米白为 "F5FOE8"（0 误为 O） | 橙色 "FF6B26" 正确，米白 "F5FOE8" 同样有误 | 部分通过（见说明） |

**说明：**
- 山景面板（#8）因大气透视自然产生青灰与暖黄过渡色，属于 SKILL.md "IMAGE DIRECTION" 允许的 cinematic 氛围范围，但严格来说超出三色限制。若需绝对三色，可将该面板替换为几何图形 / 纯色摄影处理。
- 色值标签中的字符错误是 AI 图像生成模型渲染小字的已知局限；**准确色值以本规范文档第 1.1 节为准**，图片中的标签仅作示意。

## 5. 实际影响交付结果的 SKILL.md 规则

**规则：TEXT RULES — "Use very little text" / "Text should be large enough and sparse enough to render well" / "No tiny fake body copy, no lorem ipsum"。**

这条规则直接决定了两张品牌板的文字策略：全图仅出现品牌名 "BEACON"、一句标语 "Clarity cuts through."、7 个短面板标签和极少量 UI 芯片文字，没有任何段落或伪文本。这同时满足了用户"正文必须保持清晰可读"的要求——因为文字极少且字号大，所有可见文字都保持了高可读性。若按常规品牌手册填充大量说明文字，既违反 SKILL.md，也会因 AI 渲染小字导致可读性下降。
