## 四、履约模式选择：FBT vs 自发货

基于 Skill 提供的"策略对比（pros/cons）"能力，对两种模式做框架级对比。具体费率需以 TikTok Shop 卖家后台当期规则为准（待核实）。

| 维度 | Fulfilled by TikTok (FBT) | 自发货 (Self-fulfillment) |
|---|---|---|
| 时效与体验 | 平台仓配，时效稳定，利于转化与标签加权 | 取决于自有/3PL 能力，时效波动风险自担 |
| 运费成本 | 平台按件/重计费，轻小件可能有规模优势；具体费率待核实 | 可与快递议价，但单量起量前议价能力弱 |
| 运营投入 | 入库、补货、库存管理由平台承接，团队投入低 | 需自建打包、发货、售后链路或对接 3PL |
| 库存风险 | 需提前备货入仓，滞销占压库存与仓储费 | 库存自有，灵活但缺货/延迟风险自担 |
| 退货处理 | 平台承接退货质检与二次销售流程（以平台规则为准） | 需自建退货地址、质检、退款流程 |
| 适用阶段 | 首发期单量不确定时可先小批量试仓；验证爆款后加大入仓 | 首发测款期、SKU 少、单量低时更灵活 |
| 带电/特殊品限制 | 若含电池，需确认 FBT 仓是否接收及运输限制（待核实） | 可选择支持带电产品的快递渠道，但合规要求同样适用 |

**结论（基于已知信息）**：
- 首发期建议采用**"自发货为主 + FBT 小批量试仓"的混合策略**：先用自发货跑通链路、验证转化与退货率，待单量稳定且食品接触合规报告齐备后，再将主力库存转入 FBT。
- 该结论依赖以下假设（需验证）：① 产品不含无法运输的电池类型；② 首发期日单量处于中低水平；③ 团队具备基础打包发货能力或可对接 3PL。

## 五、运费模板设计（框架）

依据 Skill 的"shipping templates"能力范围，给出模板结构；具体金额与时效需按快递公司报价与平台规则填写（待核实）。

**模板分层建议**：

1. **包邮模板（默认）**：199 元客单价具备包邮空间，建议全国大部分地区包邮以提升转化；偏远地区（新疆、西藏等）设为不配送或加收运费，具体加收金额待核实快递报价后填写。
2. **承诺时效模板**：按"下单后 X 小时内发货 + 运输 Y 天"设置。发货时效建议首发期保守设置（如 48 小时内发货），避免延迟发货罚分；具体承诺值待核实仓储与快递截单时间后确定。
3. **重量/尺寸档位**：产品 280g + 包装，预估落在 0.5–1kg 档位（**假设，待包装称重后确认**），按此档位匹配快递报价。

**待补输入**：包装后重量与尺寸、首发仓库发货地、合作快递报价、平台对饮具类目的运输限制（尤其若含电子元件）。

## 六、退货政策设计（框架）

依据 Skill 的"return policies"能力范围：

- **退货窗口**：遵循 TikTok Shop 平台最低要求（以当期卖家中心规则为准，待核实），建议不低于平台法定/规则要求，不建议首发期自行缩短窗口以免影响转化。
- **退货原因与责任划分**：
  - 质量问题（保温不达标、杯盖故障、破损）：商家承担退货运费。
  - 七天无理由/不喜欢：在不影响二次销售前提下支持，运费承担方式按平台规则与店铺策略确定（待核实平台规则后定）。
  - 食品接触类产品的卫生特殊性：已使用/已拆封影响二次销售的退换边界需在政策中写清，同时不得违反消费者权益相关法规。
- **退货地址**：自发货阶段使用自有/3PL 退货地址；FBT 阶段按平台退货仓流程。
- **前置依赖**：食品接触材料报告缺失期间，若因合规问题导致下架或批量退货，风险敞口较大（见风险节）。

## 七、分阶段实施计划（MVP → 长期）

### MVP（最小可验证版本，首发前必须完成）

| 步骤 | 内容 | 依赖/待补 |
|---|---|---|
| M1 | 确认产品是否含电子元件/电池及防水等级 | 需产品方提供，直接影响运输合规 |
| M2 | 取得食品接触材料合规报告 | 上架前置条件，当前缺失 |
| M3 | 确定包装后重量、尺寸、发货地 | 运费模板基础数据 |
| M4 | 选定首发快递/3PL，获取报价与时效 | 待 M3 |
| M5 | 配置默认运费模板（包邮+偏远地区规则+保守发货时效） | 待 M4 |
| M6 | 配置退货政策与退货地址 | 待平台规则核实 |
| M7 | 小批量试发：内部下单走通打包→交接快递→物流回传→退货全链路 | 验证可执行性 |

**MVP 验收方法**：在不产生真实客诉的前提下，内部/测试单完整跑通"下单→发货→物流轨迹可查→模拟退货→退款"闭环；运费模板与退货政策在卖家中心保存成功且无平台报错。

### 中期（首发后 2–6 周）

- 监控发货时效达成率、物流异常率、退货率，用真实数据校准模板。
- 若单量与退货率达标，启动 FBT 小批量入仓试运营，对比 FBT 与自发货的时效、成本、转化差异。
- 根据真实退货原因分布优化包装（防破损）与品控。

### 长期

- 主力库存转 FBT，自发货作为大促/爆单缓冲。
- 建立安全库存与补货预警阈值。
- 按 Skill 建议，用本店实际数据持续验证并迭代策略（Skill Limitations 明确要求）。

- 本方案为 Beta Skill 产出的战略框架，上线前须以 TikTok Shop 卖家中心最新规则与本店真实数据复核。
