## 三、适配说明

### 1. 竖屏适配（9:16）
- 按 SKILL.md 中 YouTube Shorts / TikTok / Reels 的竖屏规范，输出 1080×1920。
- 背景图经 `scale=force_original_aspect_ratio=increase,crop=1080:1920` 裁切填充，无黑边。
- 文字安全区控制在画面中部偏上（y≈780–1020），避开顶部状态栏和底部手势条区域。

### 2. 前2秒信息钩子
- 0.3s 出现「30秒学会」大字（120px），0.6s 出现青色副标题，1.0s 出现内容提要。
- 钩子直接点明价值主张（30秒学会5个技巧），配合双音提示吸引注意力。

### 3. 静音观看可理解
- 全片所有信息均通过屏幕文字传达，无依赖语音旁白的内容。
- 每个段落有独立标题+说明文字，字号分别为 76–88px 和 42–44px，手机端可读。
- 音频仅起节奏提示作用（低频铺底+段落切换短音），静音不影响信息获取。

### 4. 版权合规
- **音乐**：未使用任何外部音乐文件。全部音频由 FFmpeg `aevalsrc` 滤镜实时合成正弦波（110Hz/220Hz 铺底 + 880Hz 提示音 + 660/990Hz 收尾音），为原创生成音频。
- **人物素材**：全片无任何人物影像。背景为 Seedream 5.0 Pro 生成的抽象科技图（无人物、无文字、无logo），文字和图形由 FFmpeg drawtext/drawbox 绘制。
- **字体**：使用 macOS 系统自带的 STHeiti（华文黑体），未嵌入第三方字体文件。

### 5. 编码与播放兼容性
- 按 SKILL.md「Video won't play in browser」修复方案：使用 `-pix_fmt yuv420p -c:v libx264 -movflags +faststart`。
- H.264 High@4.0 + AAC LC，兼容主流手机播放器和各短视频平台。
- CRF 20（SKILL.md 质量表中 Production 级别），文件仅 1.7MB，适合移动端快速加载。

## 四、制作流程（实际执行）

1. 解压 ffmpeg.zip，阅读 `ffmpeg/SKILL.md` 和 `ffmpeg/reference.md`。
2. 确认本机 FFmpeg 路径（imageio-ffmpeg 捆绑的 7.1 静态二进制），验证 drawtext/libx264/aac 等滤镜和编码器可用。
3. 用 Seedream 5.0 Pro 生成 1080×1920 抽象暗色科技背景图（无人物无文字）。
4. 编写 FFmpeg 脚本：
   - 视频轨：背景图缩放裁切 → 暗色遮罩 → 标签/进度条/drawbox 强调色 → 7段 drawtext 按 `enable='between(t,...)'` 分时显示 → 淡入淡出 → libx264 CRF20 编码。
   - 音频轨：`aevalsrc` 合成30秒原创提示音 → afade 淡入淡出 → AAC 128kbps。
   - 合并：视频流 copy + 音频 AAC，faststart 封装。
5. 抽取 1s/4s/9s/14s/19s/24s/28s 关键帧目视验证文字渲染和布局。
6. ffprobe 确认时长、分辨率、编码、码率均符合预期。

### 影响交付结果的 SKILL.md 规则（至少一条）

1. **竖屏输出规范**（SKILL.md「YouTube Shorts」段落）：`-vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920..."` —— 本视频据此确定 1080×1920 目标分辨率，并采用 scale+crop 填充策略而非 pad 留黑边，直接决定了画面构图和背景裁切方式。
2. **浏览器/移动端播放兼容三件套**（SKILL.md「Video won't play in browser」）：`-movflags faststart -pix_fmt yuv420p -c:v libx264` —— 最终编码命令严格遵循，确保产出的 MP4 可在手机端直接播放。
3. **CRF 质量分级表**（SKILL.md「Quality Guidelines」）：Production 级 CRF 20–22，本视频选用 CRF 20，在画质和文件体积间取得平衡（最终 1.7MB）。
4. **音频淡入淡出**（SKILL.md「Add Fade In/Out」）：`afade=t=in:st=0:d=0.3,afade=t=out:st=29:d=1` —— 用于音频轨，避免开头爆音和结尾突兀。

## 六、需说明的假设与限制

- **「同一主题」的理解**：本次对话中未提供原始横屏视频或其他参考素材，唯一主题上下文为 ffmpeg Skill 本身。因此将「同一主题」理解为 FFmpeg 视频处理技巧，制作了一支该主题的30秒竖屏科普短片。如有原始视频需要改版，请提供源文件。
