## 三、步骤（关键执行步骤）

### 步骤 1：现状评估（基于已有信息）

- 已有白底图可直接复用为 Etsy 主图候选，但需核验分辨率（Etsy 建议最短边 ≥ 2000px 以支持缩放）与背景纯净度。
- 三大卖点中，"可拆洗杯盖"最适合用静态特写表达；"280g 轻量"需要参照物或手持场景；"12 小时保温"需注意不能用未经证实的检测画面背书。
- 品牌主色 #176B87（青蓝色）可作为道具/背景点缀色，统一视觉调性。

### 步骤 2：确定 10 张图的拍摄清单（Etsy 单条 listing 最多 10 张）

按"主图 → 卖点 → 场景 → 细节 → 信任"排序，见第四节结论。

### 步骤 3：制定拍摄技术规范

- 光线：自然光 + 柔光板，或两盏柔光箱 45° 夹光，避免硬阴影。
- 背景：主图纯白 #FFFFFF；生活方式图用低饱和中性色（米白/浅灰/原木），点缀品牌色 #176B87。
- 构图：产品占画面 70%–85%，留白用于 Etsy 搜索缩略图裁切；竖图 4:5 优先（移动端信息流占比大）。
- 后期：白平衡统一、轻微去瑕疵、背景抠净；不过度饱和，避免色差导致退货差评。

### 步骤 4：明确待补项与拍摄禁区

- 防水等级未提供 → 不拍浸水、雨淋、水杯倒置漏水测试等画面。
- 食品接触材料报告未提供 → 不出现"食品级认证"徽章或检测报告画面。
- 首发日期未定 → 时间线中不锁定首发日，以"素材就绪日 T"为基准排期。

### 步骤 5：验收与上线

- 每张图按验收标准逐项检查（见第六节）。
- 上线后跟踪 KPI（见第七节），用真实店铺数据验证假设。

## 五、工具与策略建议（含 pros/cons）

| 工具/方式 | 用途 | 优点 | 缺点 |
|---|---|---|---|
| 手机（近年旗舰）+ 自然光 | P0/P1 图片 | 零成本、上手快、画质足够 Etsy | 弱光/微距受限，需手动控制曝光 |
| 柔光箱 ×2 + 纯白背景纸 | 主图与白底图 | 光线均匀、可重复 | 需小预算与空间 |
| 手机/相机转盘 | 图 9 360° 视图 | 提升互动与停留时长 | 后期合成需学习；Etsy 对动图格式有要求 |
| 免费后期（Canva / 手机自带编辑） | 裁切、调色、加尺寸标注 | 模板丰富、上手快 | 批量处理能力弱；注意色差 |
| Lightroom / Capture One | 批量调色统一 | 专业、效率高 | 学习成本与订阅费用 |

> 策略建议：主图坚持纯白底（Etsy 搜索与广告场景兼容性最好）；生活方式图统一用 #176B87 青蓝色系点缀形成品牌记忆点；所有图片保持相同白平衡与曝光区间，避免 listing 内视觉跳脱。

## 六、验收标准（最小可验证）

### 单图通用验收（每张必过）

- [ ] 分辨率：最短边 ≥ 2000px（支持 Etsy 点击放大）
- [ ] 格式：JPG 或 PNG，单张 ≤ 1MB（Etsy 上限，实际建议 ≤ 500KB 以利加载）
- [ ] 比例：主图 4:5 或 1:1；无黑边、无水印、无多余文字（Etsy 主图规范）
- [ ] 色差：与实物一致，不过度饱和
- [ ] 焦点：产品主体清晰，无明显噪点/手抖模糊

### 逐图专项验收

| # | 验收点 |
|---|---|
| 1 | 背景纯白无杂物；产品居中；缩略图缩小至 200px 仍可辨认杯型 |
| 2 | 热气/冷感表达自然；**画面中不出现任何未经证实的检测认证标识或报告** |
| 3 | 轻量感传达明确（手持姿态自然或秤面读数清晰）；读数/文案仅用简报确认的 280g |
| 4 | 拆解部件完整、排列清晰；部件名称与实物一致（拍摄前对照实物核对） |
| 5 | 通勤场景真实自然，无违和摆拍感；品牌色点缀不喧宾夺主 |
| 6 | 尺寸数值与基础规格表一致；参照物比例真实 |
| 7 | 工艺细节清晰；**不出现防水等级标识、食品级认证标识等未确认信息** |
| 8 | 色调与 #176B87 协调；整体风格与其他图统一 |
| 9 | 多角度光照一致、杯身无旋转偏移；若为 360° 动图，旋转流畅无跳帧 |
| 10 | 仅展示实际随箱配件；包装外观与实物一致 |

### 整体 listing 验收

- [ ] 10 张图覆盖：主图、三大卖点、使用场景、尺寸、细节、品牌、多角度、包装
- [ ] 三大核心卖点（保温/轻量/可拆洗）均有至少一张图对应
- [ ] 无任何编造的检测结论、销量、评价、竞品价格
- [ ] 待补项（防水等级、食品接触报告）相关画面均未越界
