# 示例请求与响应

> 来源说明：以下示例基于通用 REST 工程实践，非 accelerate Skill 内容。
> 所有 token、ID、时间戳均为模拟值（SIMULATED）。

## 1. 批量创建任务 — 全部成功

### Request
```http
POST /v1/tasks:batch HTTP/1.1
Host: api.example.com
Authorization: Bearer <SIMULATED_JWT_with_tasks:write>
Content-Type: application/json
Idempotency-Key: 9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d

{
  "tasks": [
    {
      "client_task_id": "job-20260810-001",
      "type": "training",
      "payload": {"model": "gpt2", "epochs": 3, "batch_size": 32},
      "priority": "NORMAL"
    },
    {
      "client_task_id": "job-20260810-002",
      "type": "evaluation",
      "payload": {"checkpoint": "ckpt-1000", "dataset": "test-set"}
    }
  ]
}
```

### Response (201 Created)
```http
HTTP/1.1 201 Created
Content-Type: application/json
X-Idempotent-Replay: false

{
  "batch_id": "batch_SIMULATED_001",
  "results": [
    {
      "client_task_id": "job-20260810-001",
      "task_id": "t_SIMULATED_aaa",
      "status": "PENDING",
      "created": true
    },
    {
      "client_task_id": "job-20260810-002",
      "task_id": "t_SIMULATED_bbb",
      "status": "PENDING",
      "created": true
    }
  ]
}
```

## 2. 批量创建 — 幂等重放（相同 Idempotency-Key 重发）

### Request
与上面完全相同（相同 header + 相同 body）。

### Response (201 Created)
```http
HTTP/1.1 201 Created
X-Idempotent-Replay: true

{
  "batch_id": "batch_SIMULATED_001",
  "results": [
    {"client_task_id": "job-20260810-001", "task_id": "t_SIMULATED_aaa", "status": "PENDING", "created": true},
    {"client_task_id": "job-20260810-002", "task_id": "t_SIMULATED_bbb", "status": "PENDING", "created": true}
  ]
}
```
注意：返回的 task_id 与首次一致，不会重复创建。

## 3. 批量创建 — 键冲突（相同 Key 不同 Body）

### Response (409 Conflict)
```json
{
  "error": {
    "code": "IDEMPOTENCY_KEY_CONFLICT",
    "message": "Idempotency-Key already used with different request body",
    "request_id": "req_SIMULATED_xxx"
  }
}
```

## 7. 分页列表 — 翻页

### Request
```http
GET /v1/tasks?status=RUNNING&limit=2&cursor=cursor_SIMULATED_page2 HTTP/1.1
```

### Response (200)
```json
{
  "items": [
    {"task_id": "t_SIMULATED_eee", "type": "training", "status": "RUNNING", "created_at": "2026-08-10T12:50:00Z", "updated_at": "2026-08-10T13:04:00Z"}
  ],

```
`next_cursor: null` 表示无更多页。

## 8. 错误码示例

| HTTP | code | 场景 |
|------|------|------|
| 400 | INVALID_REQUEST | 参数校验失败（含 details） |
| 401 | UNAUTHORIZED | 缺失/无效 token |
| 403 | INSUFFICIENT_SCOPE | token 缺少所需 scope |
| 404 | TASK_NOT_FOUND | task_id 不存在 |
| 409 | IDEMPOTENCY_KEY_CONFLICT | 幂等键冲突 |
| 413 | BATCH_TOO_LARGE | tasks 数量超过 1000 |
| 429 | RATE_LIMITED | 触发限流（含 Retry-After） |
| 500 | INTERNAL_ERROR | 服务端错误（客户端可安全重试幂等请求） |
