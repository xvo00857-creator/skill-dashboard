## Mode 1：AI/套话模式诊断

### 机械评分

> 注：`humanizer_scorer.py` 针对英文词表设计，中文套话不在其检测范围内。以下为按同等逻辑做的人工诊断，分类标准对齐 `ai-tells-checklist.md`。

| 检测类别 | 命中数 | 严重度 | 具体命中 |
|---|---|---|---|
| 滥用套话词（对应英文 AI Vocabulary） | 12+ | 🔴 | 赋能×2、闭环、全面×2、打通、沉淀、组合拳、抓手、拉齐、合力、深化、持续赋能 |
| 模糊承诺（对应 Vague Authority） | 3 | 🔴 | "精准触达"（多精准？什么渠道？）、"多维度全面提升"（提升多少？哪些维度？）、"高质量按期落地"（什么标准？哪天？） |
| 缺乏具体性（对应 Lack of Specificity） | 3 | 🔴 | "核心模块"（哪些模块？）、"AI能力"（什么能力？）、"统一客户画像与标签体系"（哪些标签？哪些字段？） |
| 段落结构单一（对应 SEEB Pattern） | 全文1段 | 🔴 | 整段一个长句群，无短句、无分段、无节奏变化 |
| 虚假热情（对应 False Warmth/Enthusiasm） | 2 | 🟡 | "协同合力"（谁不协同？）、"持续赋能业务增长"（收尾套话，无信息量） |

**判定**：套话密度远超阈值（>5个/百字），属于🔴"需要重写而非修补"级别。逐词替换不够——需要从句法层面重建节奏。

## Mode 2 + Mode 3：改写稿

这个项目要做一件事：给一线销售团队搭一个客户运营平台，管从线索到客户成功的整条链路。

眼下的问题是数据散在三个地方：CRM、客服系统、产品后台，各存各的。项目要把这三块数据接到一起，做出统一的客户画像和标签体系，让销售能基于数据去触达客户，而不是凭感觉。

产品、运营、销售三方需要在这个方向上对齐，一起推。

一期核心模块已经上线。二期会加入AI能力，继续支撑业务增长。

## 逐处删改理由

| 原文 | 改写 | 理由 |
|---|---|---|
| "旨在打造智能化客户运营平台，全面赋能一线销售团队" | "要做一件事：给一线销售团队搭一个客户运营平台" | 🔴"旨在打造"是公文腔；"全面赋能"是空动词——赋能什么？怎么赋能？直接说"给谁做什么"。"智能化"无具体所指，删。 |
| "实现从线索获取到客户成功的全链路业务闭环" | "管从线索到客户成功的整条链路" | 🔴"闭环"是典型套话，此处只表示"覆盖完整流程"，用"整条链路"直说即可。"全链路业务闭环"三词一意，精简。 |
| "打通CRM、客服系统、产品后台三方数据孤岛" | "数据散在三个地方：CRM、客服系统、产品后台，各存各的" | "打通""数据孤岛"是隐喻套话。改写先说现状（散、各存各的），再说动作（接到一起），读者更容易跟上。"孤岛"删——说"各存各的"更直白。 |
| "沉淀统一客户画像与标签体系" | "做出统一的客户画像和标签体系" | "沉淀"是企业黑话，=做/建。换成"做出"。 |
| "以数据驱动的组合拳方式精准触达客户" | "让销售能基于数据去触达客户，而不是凭感觉" | 🔴"组合拳"无实际含义（什么拳？）；"精准"无支撑（多精准？）。改为"基于数据而不是凭感觉"——把"数据驱动"的对比关系说清楚，比空喊"精准"有说服力。 |
| "多维度全面提升转化率与留存率" | "目标就两个：提转化率，提留存率" | 🔴"多维度全面提升"是模糊承诺。直接列出两个指标，不夸大。提升多少原文没给，不编。 |
| "以客户生命周期价值为核心抓手" | "衡量标准看客户生命周期价值" | "抓手"是企业黑话，=重点/衡量标准。直说。 |
| "拉齐产品、运营、销售各方认知，形成协同合力" | "产品、运营、销售三方需要在这个方向上对齐，一起推" | "拉齐认知""形成协同合力"是双重套话，意思就是"对齐了一起干"。"一起推"比"协同合力"具体。 |
| "确保项目高质量按期落地" | （删） | 🔴"高质量按期落地"是无信息量的保证——哪个项目不要求高质量按期？删去不影响事实。 |
| "项目一期已完成核心模块上线" | "一期核心模块已经上线" | 语序调整，更口语。"核心模块"具体指什么原文未说，保留原表述，不编造。 |
| "二期将进一步深化AI能力，持续赋能业务增长" | "二期会加入AI能力，继续支撑业务增长" | "深化"是空 intensifier；"持续赋能"改为"继续支撑"——AI能力具体做什么原文没给，不补。 |

### 节奏调整说明

- 原文：1段、约180字、全是长句（每句25-40字），读起来像机器输出。
- 改写：5段，长短交替——"目标就两个：提转化率，提留存率。"（7字短句）紧接长句；单句成段（"一期核心模块已经上线。"）制造停顿。这是 Skill 要求的"Long. Short. Long, long. Short."节奏。
- 最后加了一句括号说明，标注原文未明确的信息——这是 Skill 要求的"be honest about what you don't know"，不替原文编细节。
