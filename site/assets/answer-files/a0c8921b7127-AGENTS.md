## CONVENTIONS
- 阶段跟踪必须用 TodoWrite，四阶段实时标记 in_progress→completed
- 发现阶段必须并行：后台探索代理 + bash + LSP/codegraph 同时进行
- LSP 与 codegraph 是同级一等公民，须同时运行；二者皆无时才用 ast-grep(`sg`) 并在 CODE MAP 标注 centrality unmeasured
- 代理数量按项目规模动态计算（文件数/行数/深度/大文件/monorepo/语言数），禁止固定数量
- 写文件前必须先检查存在性：存在→Edit，不存在→Write
- 根 AGENTS.md 50-150 行；子 AGENTS.md 30-80 行；子文件不得重复父内容
- 文风：电报体，删除所有适用于任意项目的通用建议
- `--create-new` 模式也必须先读已有文件保留上下文，再删除重建

## ANTI-PATTERNS (THIS PROJECT)
- 禁止固定代理数量——必须随项目规模/深度变化
- 禁止串行执行——探索/LSP/codegraph 必须并发
- 禁止忽略已有文件——即使 `--create-new` 也要先读
- 禁止过度文档化——不是每个目录都需要 AGENTS.md
- 禁止冗余——子文件不得重复父文件内容
- 禁止通用内容——删除所有对所有项目都适用的建议
- 禁止冗长文风——电报体，否则删

## UNIQUE STYLES
- 顶部 Harness 兼容段声明优先级：与下方代码块冲突时以该段为准
- 用评分矩阵（8 因子加权）量化决定 AGENTS.md 落点，而非凭直觉
- 动态代理表：按文件数/行数/深度/大文件数/monorepo/语言数增减探索代理
- 同时覆盖 multi_agent_v1 与 v2 两套子代理工具表面，含字段级转换规则
