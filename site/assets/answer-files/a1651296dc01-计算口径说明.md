> 本文件由 `run_demo.py` 自动生成，数据为程序合成的模拟数据，不代表任何真实业务。

## 一、数据来源
- 原始文件：`销售明细_原始_合成.xlsx`（程序生成，非真实数据）
- 工作表：华东, 华南, 华北（共 3 个，按地区分表）
- 字段：日期、地区、品类、订单量、销售额、联系电话（合成虚构）

## 二、清洗规则（对应 SKILL.md Step1）
- 前向填充列「日期」：填充 0 个空值（合并单元格还原）
- 前向填充列「地区」：填充 21 个空值（合并单元格还原）
- 识别到「联系电话」列：原始号码已删除，仅保留脱敏字段（138****0001），不进入汇总统计
- 品类别名归并：10 条记录按映射表统一为标准品类名
- 品类缺失 2 条：标记为「未知」，保留行不删除
- 订单量缺失 1 条、销售额缺失 0 条：不做臆造填充，汇总时按非空值计算（分母相应剔除）

## 三、统计口径（对应 SKILL.md Step2）
1. **汇总维度**：地区 × 品类，指标为订单量（求和）、销售额（求和）。
2. **缺失值处理**：订单量或销售额为空的行，不参与对应指标求和；客单价仅在两列均非空时计算。
3. **品类归并映射**：电子/数码产品/数码 → 电子产品；家居 → 家居用品；食品 → 食品饮料。
4. **未知品类**：品类原始为空且无法归并的记录标记为「未知」，保留在明细中，单独成组统计。
5. **小计与总计**：
   - 地区小计 = 该地区所有品类之和；
   - 品类小计 = 该品类所有地区之和；
   - 总计 = 全部有效记录之和。
6. **客单价** = 销售额 ÷ 订单量，保留两位小数。
