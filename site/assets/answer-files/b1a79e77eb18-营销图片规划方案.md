# 营销内容图片主题与提示词规划方案（最小安全版）

> 状态：占位/模板阶段，非最终营销素材。生成日期：2026-08-10。

---

## 一、目标

在信息不完整的前提下，为营销内容规划可安全执行的图片主题与提示词框架，并产出一张不依赖任何未确认产品信息的占位 PNG 图片，作为后续正式素材的视觉方向参考。

## 二、依据

- **已确认事实**：团队提供了产品名称和三项已确认功能（但本次对话中未实际传达具体内容）。
- **明确缺失**：转化率数据、竞品分析、客户评价/口碑、合规审查结论均不存在。
- **硬性约束**：不得制造虚假稀缺（如"仅剩X名""限时"等无依据表述）；不得自动外联；不得将推断表述为事实。
- **Skill 规范**：遵循 `image` Skill（v2.0.1）的提示词结构（主体+场景+风格+光线+构图+技术参数）、常见错误规避（不用 AI 生成产品 UI 截图、不在图中放大段文字、指定尺寸、明确风格方向）、以及图片优化建议（WebP 格式、压缩、懒加载等）。

## 三、事实 / 推断 / 待确认 分类

| 类别 | 内容 |
|------|------|
| **事实** | 存在一个待推广的产品；团队已确认三项功能；转化率/竞品/评价/合规结论缺失；本次需规划图片主题与提示词。 |
| **推断（非事实）** | 该产品可能为 SaaS/工具类（基于"功能"表述习惯，但未确认）；营销渠道可能包含博客/社交媒体（未确认）；目标受众可能为企业或个人用户（未确认）。 |
| **待确认** | ① 产品名称与具体三项功能；② 目标平台与投放位置（博客头图/社交/横幅/列表页）；③ 品牌资产（配色、字体、Logo、风格指南）；④ 目标受众与调性；⑤ 合规审查结论（能否使用特定表述/徽章/认证）；⑥ 客户评价是否存在且可引用；⑦ 是一次性素材还是可复用模板；⑧ 是否需要 Web 性能优化。 |

## 四、步骤（最小可执行方案）

1. **信息核查**：检查 `product-marketing.md` 上下文文件（已确认不存在）；确认当前对话中未提供产品名称与功能细节。
2. **风险规避**：因产品细节缺失，不生成任何包含具体产品 UI、功能名称、客户证言、数据声明、稀缺性话术的图片。
3. **生成占位图**：产出一张抽象的营销规划主题俯拍摄影图（2048×1072，约 1.91:1 博客头图/OG 比例），内容为桌面色卡、相机、植物、铅笔、笔记本等中性物品，无文字、无屏幕、无人物、无 Logo。
4. **提示词模板**：提供结构化提示词框架（见第六节），待产品信息补齐后填入。
5. **格式交付**：输出 PNG 格式占位图 + 本方案文档。

## 五、关键取舍

| 取舍 | 选择 | 原因 |
|------|------|------|
| 生成产品展示图 vs 抽象占位图 | 抽象占位图 | 产品名称与功能未实际提供，任何产品图均为编造。 |
| 图中含文字标题 vs 纯视觉 | 纯视觉 | Skill 明确指出 AI 模型渲染文字不可靠；且无确认文案，避免错误声明。 |
| 人物/使用场景 vs 物品俯拍 | 物品俯拍 | 人物场景可能暗示特定用户群体或使用方式，构成未确认推断。 |
| 多尺寸批量生成 vs 单张 | 单张 | 信息不足，多尺寸会放大未确认假设；Skill 建议先确定最高分辨率再用 Canva Magic Resize 适配。 |
| 立即交付多套方案 vs 单套最小方案 | 单套最小方案 | 信息缺口过大，多套方案会产生更多无法验证的推断。 |

## 七、风险

1. **误用风险**：占位图可能被误认为正式营销素材直接发布——已在文档和文件名中标注"placeholder/占位"。
2. **推断越界风险**：任何关于产品形态、用户群体、效果数据的表述在补齐信息前均不得出现在图片或文案中。
3. **合规风险**：无合规结论前，图片中不得出现认证徽章、数据排名、客户 Logo、对比性声明。
4. **AI 生成 UI 风险**：Skill 明确列为常见错误 #1——AI 会编造界面，产品截图必须用真实截图。
5. **文字渲染风险**：Skill 指出除 Ideogram 外多数模型文字渲染不可靠，正式素材中的标题/标语建议后期叠加而非 AI 生成。

## 八、衡量方式

- **合规自检**：图片中是否出现任何未确认的产品名、功能声明、数据、客户名、稀缺话术？（当前：无）
- **Skill 规范自检**：是否指定了尺寸？是否明确了风格？是否避免了 AI 生成 UI？是否避免了大段文字？（当前：全部满足）
- **信息完整性检查**：待确认项是否已全部闭环？（当前：8 项待确认，0 项闭环）
- **可用性**：占位图是否可作为视觉方向参考（色调、构图、氛围）供团队讨论？（当前：是）

## 九、停止条件（出现以下任一情况应暂停并等待输入）

1. 产品名称和三项已确认功能未提供 → 不生成产品相关图片。
2. 合规审查结论未出具 → 图片中不出现任何声明类、对比类、认证类元素。
3. 客户评价不存在或未获授权 → 不使用任何人物肖像、证言、评分。
4. 品牌资产（配色/字体/Logo）未提供 → 不尝试匹配品牌视觉，仅产出中性方向稿。
5. 目标平台/投放位置未确认 → 不批量生成多尺寸，仅产出单一最高分辨率方向稿。

## 十、下一步

1. **补齐产品信息**：提供产品名称、三项已确认功能的具体描述。
2. **确认投放渠道**：明确图片用途（博客头图/社交媒体/产品列表/横幅等），以确定尺寸规格。
3. **提供品牌资产**：配色（HEX）、字体、Logo 文件、风格指南（如有）。
4. **合规审查**：完成法务/合规对营销表述的审核，明确可用与禁用表述。
5. **客户评价收集**：如计划在素材中使用社会证明，需确认评价来源与授权。
6. **正式生成**：信息齐备后，按提示词模板生成正式素材；如需图中文字，使用 Ideogram 或后期叠加；产品 UI 展示一律使用真实截图+设备样机方案。
7. **图片优化**：正式上线前按 Skill 优化清单执行——转 WebP（质量 75-85%）、压缩至 <200KB、设置懒加载与显式宽高、添加描述性 alt 文本。
