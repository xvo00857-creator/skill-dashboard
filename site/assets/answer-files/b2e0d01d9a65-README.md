## 一、Skill 真实能力确认

依据 ZIP 内 `ably-automation/SKILL.md` 原文：

- **用途**：通过 Rube MCP（Composio）自动化 Ably 平台操作。
- **依赖**：必须连接 MCP `rube`，且 Ably toolkit 连接状态为 ACTIVE。
- **核心流程**：`RUBE_SEARCH_TOOLS`（发现工具与最新 schema）→ `RUBE_MANAGE_CONNECTIONS`（确认连接）→ `RUBE_MULTI_EXECUTE_TOOL`（执行）。
- **能力范围**：经核实 Composio 官方文档，Ably toolkit 提供的工具包括发布消息到频道（`ABLY_PUBLISH_MESSAGE_TO_CHANNEL`）、批量发布消息、发布推送通知、列出频道/设备、获取应用统计、管理推送设备注册、请求访问令牌等。
- **关键结论**：Ably 是**实时消息平台**（pub/sub、推送、在线状态），该 Skill **只能做消息发布与 Ably 平台管理**，**不具备**待办事项收集、任务管理、逾期筛选等能力。"收集待办、筛逾期"需要独立的任务数据源（如飞书任务、Jira 等），该 Skill 不覆盖。
