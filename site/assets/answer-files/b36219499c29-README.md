# SwiftUI 任务清单演示 —— 受约束流程方案

## 一、Skill 能力边界说明

本次严格按 `swiftui-expert-skill` 的 `SKILL.md` 执行。该 Skill 的能力范围是：

- 编写、重构 SwiftUI 代码
- 验证命令、代码和依赖
- 遵循最新 API 与正确性检查清单
- 建议性能优化（非强制）

**不包含**的能力（题目未要求扩张，故未执行）：
- 不负责 App Store 发布、签名、证书管理
- 不替代完整 Xcode 的模拟器运行和 UI 测试
- 不安装或升级 Xcode / iOS SDK

## 二、环境预检结果

| 检查项 | 结果 |
|--------|------|
| swiftc | 可用，Swift 6.2.4（swiftlang-6.2.4.1.4） |
| macOS SDK | 可用，版本 26.2 |
| iOS SDK | **不可用**（仅安装 Command Line Tools，无完整 Xcode） |
| `#Preview` 宏 | **不可用**（宏插件 PreviewsMacros 需完整 Xcode） |
| `PreviewProvider` 协议 | 可用，已用于命令行类型检查验证 |
| `@Observable` 宏 | 可用 |

**环境限制的影响**：
- 无法编译 iOS 目标或运行 iOS 模拟器
- 无法在命令行验证 `#Preview` 宏（源码中保留，在完整 Xcode 中可正常使用）
- 验证方式为 `swiftc -typecheck` 类型检查，非运行时验证

## 三、受约束流程设计

### 3.1 预检（Pre-flight）

在任何写操作之前执行：
1. 检查 `swiftc` 是否存在
2. 检查 macOS SDK 路径是否有效
3. 检查 iOS SDK 是否可用（不可用时标注但不阻断）
4. 检查所有源文件是否存在
5. 检查 `#Preview` 宏文件是否存在（标注需完整 Xcode）

预检失败则立即终止，不进入后续步骤。

### 3.2 幂等（Idempotency）

- 验证脚本每次运行前删除并重建 `.build-check` 目录，不产生累积状态
- 类型检查使用 `-typecheck` 只读模式，不生成可执行文件
- 所有写操作仅在项目目录内进行，不触碰外部资源
- 重复运行 `verify.sh` 产生相同结果（已验证两次）

### 3.3 重试（Retry）

- 类型检查最多重试 3 次，间隔 2 秒
- 重试仅针对瞬时失败（如编译器守护进程未就绪）
- 确定性编译错误（如 API 不可用）不会因重试而改变，重试后仍报错并终止
- 首次运行时 `.insetGrouped` 在 macOS 不可用的错误在 3 次重试后正确报告，随后修复

### 3.4 人工确认点

| 操作 | 是否需确认 | 说明 |
|------|-----------|------|
| 在项目目录内创建源文件 | 否 | 任务要求的正常产出 |
| 运行 `swiftc -typecheck` | 否 | 只读操作，不修改系统 |
| 删除临时测试文件 | 是（系统弹窗） | 删除操作由系统自动提示确认 |
| 安装/升级 Xcode | 是 | 超出当前权限，需用户手动操作 |
| 写入项目目录之外 | 是 | 本次未发生 |
| 运行可执行程序 | 是 | 本次仅类型检查，未生成可执行文件 |

## 四、交付文件清单

| 文件 | 说明 |
|------|------|
| `TaskModels.swift` | 数据模型：TaskItem、TaskFilter、@Observable TaskStore、模拟数据 |
| `TaskComponents.swift` | 可复用组件：TaskRow、TaskFilterBar、TaskSummaryCard、AddTaskField、EmptyTaskView |
| `TaskListView.swift` | 主视图与应用入口：响应式布局、导航、工具栏、动画 |
| `TaskPreviews.swift` | `#Preview` 宏预览（需完整 Xcode 15+） |
| `TaskPreviewVerification.swift` | `PreviewProvider` 协议预览（命令行可验证） |
| `verify.sh` | 类型检查与正确性规则验证脚本 |
| `README.md` | 本文件 |

## 五、验证方式

```bash
cd swiftui-demo
bash verify.sh
```

验证内容：
1. 预检工具链与 SDK
2. 幂等清理构建目录
3. `swiftc -typecheck` 类型检查（含 3 次重试）
4. 正确性规则静态扫描（@State private、@FocusState private、.animation value 参数、ForEach 身份、废弃 API、Button 优先）

## 六、仍需确认的假设

1. **目标部署版本**：代码按 macOS 14 / iOS 16 最低版本编写（使用 NavigationSplitView、ViewThatFits 等）。若项目要求更低版本，需添加 `#available` 门控和降级方案。
2. **运行时行为**：当前仅通过类型检查，未在模拟器或真机上运行。UI 渲染、手势、动画的实际效果需在完整 Xcode 中验证。
3. **`#Preview` 宏**：源码中使用了 `#Preview`，符合 Skill 推荐，但未在当前环境编译验证。在完整 Xcode 15+ 中应可正常工作。
