# 任务清单：受限预算与窗口下的迁移决策与执行

> 每个任务都有验收标准与验证步骤；规模按 Skill 指南控制在 S/M，超过则继续拆分。高风险任务（数据、试点、门槛）前置。

## Task 1：导出并核对现有系统用量与费用基线

**描述：** 从现有平台导出最近一个完整账单周期的账单与监控数据，形成可复算的用量与费用基线表，作为后续一切外推的输入。

**验收标准：**
- [ ] 拿到计算、存储、出口流量、请求量的均值与峰值
- [ ] 现有年度支出有单据或可核实来源（含人力/运维等隐性成本，能取则取，取不到明确标注）
- [ ] 无法获取的数据项列入"未知项清单"，不臆造数字

**验证：**
- [ ] 每条数据记录来源、时间范围、口径，可由第二人复算
- [ ] 与业务/财务核对无异议

**依赖：** 无

**涉及文件/系统：**
- `tasks/plan.md`（更新基线与未知项）
- 现有平台账单与监控导出（本地核对，不入库）

**规模：** S

---

## Task 2：确认预算口径、业务约束与决策人

**描述：** 与业务、财务确认 12 万预算口径，以及中断窗口、性能阈值、决策人/回退决策人。

**验收标准：**
- [ ] 12 万是否含一次性迁移成本、人力、数据出口费，有书面结论
- [ ] 可接受中断窗口、P95/错误率退化阈值有书面确认
- [ ] Go/No-Go 决策人与回退决策人已指定

**验证：**
- [ ] 邮件/文档记录在案
- [ ] 确认后的阈值写回 `tasks/plan.md` 的决策门槛章节

**依赖：** 无

**涉及文件/系统：**
- `tasks/plan.md`

**规模：** S

---

## Task 3：合规与数据驻留核查

**描述：** 核查目标方案是否满足数据驻留与合规要求，不满足项具有一票否决性。

**验收标准：**
- [ ] 形成合规结论：满足 / 不满足 / 待补充材料
- [ ] 不满足项立即记录并通知决策人，不进入后续试点

**验证：**
- [ ] 合规/法务确认记录在案

**依赖：** 无

**涉及文件/系统：**
- `tasks/plan.md`（更新合规结论）

**规模：** S

---

## Checkpoint：基线就绪（第 1 周末）
- [ ] Task 1–3 全部完成
- [ ] 用量与费用基线可复算，未知项清单收敛
- [ ] 预算口径、中断窗口、性能阈值有书面确认
- [ ] 合规结论明确
- [ ] 与人评审通过后再进入试点

---

## Task 4：选择试点切片并定义边界与依赖

**描述：** 选 1 个非核心、低流量、边界清晰的工作负载作为最小验证试点，画出其依赖图与回退边界。

**验收标准：**
- [ ] 试点切片选定并有书面选择理由（非核心、可独立切流/回退）
- [ ] 切片依赖图绘制完成
- [ ] 回退边界明确（数据范围、流量范围、影响面）

**验证：**
- [ ] 技术负责人确认该切片可独立切流与回退

**依赖：** Task 1、Task 2

**涉及文件/系统：**
- `tasks/plan.md`（试点切片与依赖图）

**规模：** S

---

## Task 5：获取目标方案书面报价

**描述：** 向目标方案提供方获取书面报价，费用项须与试点将实测的项目一一对应。

**验收标准：**
- [ ] 拿到书面/邮件形式报价
- [ ] 报价费用项覆盖计算、存储、流量、请求、迁移传输、支持等
- [ ] 报价口径与 Task 1 基线可比

**验证：**
- [ ] 报价为书面形式，口头报价不采信
- [ ] 费用项与试点测量项对照无遗漏

**依赖：** Task 1

**涉及文件/系统：**
- `tasks/plan.md`（报价口径记录）

**规模：** S

---

## Task 6：执行试点迁移与测量

**描述：** 在目标环境完成试点切片的端到端迁移与切流，采集真实工时、性能、费用与回退数据。

**验收标准：**
- [ ] 试点切片在目标环境正常运行
- [ ] 记录实际迁移工时、切流后 P95/错误率、目标侧单位用量费用
- [ ] 完成一次回退操作并记录回退耗时与数据一致性结果

**验证：**
- [ ] 试点验收清单通过
- [ ] 原始测量数据留存，来源与时间可查

**依赖：** Task 3、Task 4、Task 5

**涉及文件/系统：**
- `tasks/plan.md`（试点结果）
- 目标环境试点配置（按实际系统填写）

**规模：** M

---

## Task 7：外推并完成 Go/No-Go 门槛评估

**描述：** 用试点数据按用量占比外推全量/部分迁移的成本与工期区间，逐项核对决策门槛，形成书面判定。

**验收标准：**
- [ ] 给出成本与工期区间（非点估计），外推假设写明
- [ ] 决策门槛逐项判定 Go/No-Go
- [ ] 决策人书面记录判定结果

**验证：**
- [ ] 外推方法与假设可由第二人审查
- [ ] 门槛判定表签字/邮件确认

**依赖：** Task 6

**涉及文件/系统：**
- `tasks/plan.md`（门槛判定结果）

**规模：** M

---

## Checkpoint：Go/No-Go 门槛（第 3 周末）
- [ ] Task 7 完成，门槛逐项判定
- [ ] No-Go → 执行回退方案 / 转 O3 延期，本计划在此收尾并输出延期建议
- [ ] Go → 进入 Task 8

---

## Task 8：定义迁移切片清单、依赖图与关键路径

**描述：** 将剩余工作负载拆成垂直切片，排序并识别关键路径，估算每切片工时区间。

**验收标准：**
- [ ] 切片清单完成，每切片可独立切流与回退
- [ ] 依赖图与关键路径绘制完成
- [ ] 每切片估算工时区间，无 XL 切片（超过则继续拆）

**验证：**
- [ ] 每切片规模 ≤ M（约 3–5 个交付物/系统）
- [ ] 切片顺序满足依赖、高风险切片靠前

**依赖：** Task 7（Go）

**涉及文件/系统：**
- `tasks/plan.md`（切片清单与依赖图）

**规模：** M

---

## Task 9：建立灰度切流、监控告警与回退机制并演练

**描述：** 部署流量开关、双写/双跑、关键指标监控告警，编写回退操作手册并完成演练。

**验收标准：**
- [ ] 灰度开关可按比例切流并可一键回切
- [ ] 监控覆盖 P95、错误率、成本异常等关键指标
- [ ] 回退操作手册完成并经一次演练

**验证：**
- [ ] 在非试点切片上演练回退成功，回退耗时达标
- [ ] 告警可触发到值班/决策人

**依赖：** Task 8

**涉及文件/系统：**
- 回退操作手册（按实际系统填写路径）
- 灰度/监控配置（按实际系统填写）

**规模：** M

---

## Checkpoint：迁移就绪
- [ ] Task 8–9 完成
- [ ] 回退演练通过、切流开关可用
- [ ] 每切片规模 ≤ M，无 XL 切片

---

## Task 10：逐切片迁移、验证、灰度切流与观察（模板，按切片数复制）

**描述：** 对单个切片按统一模板完成迁移、验收、灰度切流与观察期；具体切片清单与数量在 Task 8 后确定。

**验收标准：**
- [ ] 切片在目标环境通过验收清单
- [ ] 灰度切流完成，观察期（建议 ≥3 天，待确认）内无回退触发
- [ ] 切片成本纳入 run-rate 跟踪

**验证：**
- [ ] 业务验收通过
- [ ] 监控指标在阈值内
- [ ] 回退路径全程可用

**依赖：** Task 9，及前序切片

**涉及文件/系统：**
- 切片相关配置与数据（按实际系统填写）

**规模：** M（每切片一个任务，不合并）

---

## Task 11：全量端到端验证、成本 run-rate 复核与收尾

**描述：** 所有切片迁移完成后，做端到端业务验证、实际年度支出 run-rate 复核、文档归档与旧系统安排。

**验收标准：**
- [ ] 端到端业务流程通过
- [ ] 实际年度 run-rate ≤ 12 万
- [ ] 旧系统保留期与下线计划确定
- [ ] 回退方案转为旧系统下线/保留方案

**验证：**
- [ ] 业务最终验收
- [ ] 财务复核 run-rate
- [ ] 文档与操作手册归档

**依赖：** Task 10 全部分支

**涉及文件/系统：**
- `tasks/plan.md`（最终结论）
- 收尾文档（按实际系统填写）

**规模：** M
