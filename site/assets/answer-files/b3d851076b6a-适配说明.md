## 二、竖屏适配与 Skill 能力边界（关键）
- 实际读取 `infinitetalk/SKILL.md` 及 `scripts/infer_infinitetalk.py` 后确认：InfiniteTalk 仅支持两档分辨率——`infinitetalk-480` 与 `infinitetalk-720`（来自 `wan.configs.SIZE_CONFIGS`），二者均为**横屏**，**不支持原生 9:16 竖屏输出**。
- 因此"竖屏版"无法由 InfiniteTalk 直接产出，属于 Skill 边界外的后制环节。在具备 GPU 的环境中，正确流程是：先用 InfiniteTalk 输出横屏说话视频，再通过 ffmpeg 等工具做竖屏适配（中心裁切，或横屏画面居中 + 上下模糊背景填充），最后烧录字幕。
- 本次交付的 `infinitetalk_vertical_30s.mp4` 即按"竖屏后制"思路制作，但受本机环境限制（见第四节），画面为静态授权形象图 + 缓慢静态呈现 + 烧录字幕，**不是 InfiniteTalk 实际渲染的口型驱动成片**，仅作为竖屏改版的预览样片/animatic。

## 三、静音可懂与版权合规
- **静音可懂**：0–2.2s 有居中大字钩子"一张照片 / 竟能开口说话？"；2.2–30s 全程烧录底部中文字幕（ASS 样式，白字黑描边），手机静音播放可完整理解内容。InfiniteTalk 本身不烧录字幕，字幕为后期 ffmpeg 烧录。
- **不使用未授权音乐**：音轨仅为 TTS 合成的中文女声旁白，无背景音乐、无音效。
- **不使用未授权人物素材**：主讲人形象由 Seedream 5.0 Pro 生成，为 AI 虚构人物，非任何真实个人；未使用任何真人照片或视频素材。
- 旁白稿为原创科普文案，未引用外部数据或事实。

## 四、真实运行状态（未伪造任何结果）
1. **InfiniteTalk 未在本机实际出片**，原因：
   - 本机为 Mac（arm64），无 NVIDIA GPU；脚本依赖 CUDA。
   - 包内 `scripts/infer_infinitetalk.py` 第 31 行 `import wan` 即失败（`ModuleNotFoundError: No module named 'wan'`），且该脚本第 375–388 行自述为"简化桩脚本"，不包含完整渲染管线；需约 30GB 模型权重、16GB+ 显存、32GB+ 内存、50GB 磁盘的 Linux+CUDA 环境。
   - 系统未预装 ffmpeg（已通过 `imageio-ffmpeg` 获得内置 ffmpeg 7.1 用于后制）。
2. **平台视频生成工具被内容策略拒绝**：尝试用图生视频工具以授权形象 + 旁白稿生成 30 秒口播视频时，平台返回"禁止该内容生成，不允许重试"，未绕过。
3. 最终用 ffmpeg 基于已授权的 AI 形象图 + TTS 音频 + ASS 中文字幕合成竖屏预览样片，所有素材来源与处理步骤均真实可查。

## 五、在合规 GPU 环境出真正竖屏成片的命令
```bash
# 1) InfiniteTalk 输出横屏说话视频（需完整 wan 管线 + 30GB 权重 + CUDA）
python scripts/infer_infinitetalk.py \
  --input_path ./inputs/presenter_9x16.png \
  --audio_path ./inputs/voiceover.wav \
  --output_path ./output/infinitetalk_landscape.mp4 \
  --size infinitetalk-480 \
  --mode streaming

# 2) 竖屏适配（中心裁切为 9:16）+ 烧录中文字幕
ffmpeg -i ./output/infinitetalk_landscape.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,subtitles=subs.ass" \
  -c:v libx264 -crf 20 -c:a aac -b:a 192k -pix_fmt yuv420p \
  ./output/infinitetalk_vertical_30s.mp4
```
（若希望保留横屏全身画面不裁切，可将第 2 步改为"横屏居中 + 上下模糊背景填充"方案。）

## 八、实际影响交付结果的 SKILL.md 规则（至少一条）
1. **分辨率限制规则**：SKILL.md/脚本规定仅支持 `infinitetalk-480` 与 `infinitetalk-720` 两档横屏分辨率，不支持 9:16 竖屏——这直接决定了竖屏版必须通过后期裁切/填充实现，InfiniteTalk 无法一步出竖屏成片。
2. **运行环境规则**：SKILL.md 要求 NVIDIA GPU（16GB+ 显存）、约 30GB 模型权重、Linux+CUDA；本机为 Mac 无 CUDA，且包内脚本为缺少 `wan` 模块的桩脚本，导致 InfiniteTalk 无法在本机实际渲染，最终交付物只能是 ffmpeg 预览样片而非 InfiniteTalk 成片。
3. **输入要求规则**：输入图片/视频须含清晰人脸，且 `--frame_num` 须为 4n+1、默认 25fps、输入音频建议 16kHz——本次 TTS 音频为 40kHz，真实出片前建议按脚本要求重采样为 16kHz。
