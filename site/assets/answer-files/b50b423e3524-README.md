# 响应式组件与交互状态演示

## 前提说明

工作目录中没有现成的前端项目，因此从零搭建了一个纯静态单页应用（HTML/CSS/JS，无构建步骤）。
应用建立了一致的 hash 路由（`#/`、`#/products`、`#/products/:id`、`#/about`）和统一的设计令牌体系，
所有页面共享同一套视觉规范，不存在"破坏现有路由和视觉规范"的问题。

所有产品数据均为**示例数据**（非真实商品），仅用于演示布局与交互状态。

## 改动说明

### 响应式布局（严格遵循 responsive-design Skill）

| 技术点 | 实现方式 |
|--------|----------|
| 移动优先 | 基础样式面向窄屏，通过 `min-width` 媒体查询渐进增强 |
| 流式排版 | 字号和间距全部使用 `clamp()`，随视口平滑缩放，无跳变 |
| 容器查询 | 产品卡片（`@container product (min-width:28rem)`）和统计卡片（`@container stat (min-width:20rem)`）根据自身容器宽度调整布局 |
| CSS Grid 自适应 | `repeat(auto-fit, minmax(min(100%, 16rem), 1fr))` 实现自动换行网格 |
| 响应式导航 | 移动端汉堡菜单（`aria-expanded`/`aria-controls`），≥768px 横向导航 |
| 响应式表格 | 宽屏表格，≤639px 通过 `td::before { content: attr(data-label) }` 转为卡片列表 |
| 动态视口单位 | `min-height: 100dvh` 避免移动端地址栏高度问题 |
| 逻辑属性 | 全面使用 `inline-size`/`block-size`/`inset-inline-start` 等逻辑属性 |
| 触控目标 | 所有按钮、链接、表单控件最小 44×44px |
| 特性查询降级 | `@supports not (container-type)` 和 `@supports not (aspect-ratio)` 提供回退 |
| 系统偏好 | `prefers-reduced-motion` 禁用动画，`prefers-contrast: more` 增强边框 |

### 交互状态

- **加载状态**：骨架屏（shimmer 动画）+ 顶部加载条
- **空状态**：搜索无结果时显示图标、提示文案和"清除筛选"按钮
- **错误状态**：请求失败时显示错误信息和"重新加载"按钮
- **慢网络**：请求超过 1.5 秒未返回时显示横幅提示；产品列表页底部提供网络模拟面板（可调延迟、失败率、超时阈值）
- **竞态处理**：路由切换和列表快速筛选均使用请求序列号丢弃过期响应

### 键盘操作

- 所有交互元素可通过 Tab 聚焦，Enter/Space 激活
- `:focus-visible` 仅在键盘导航时显示焦点环
- 移动菜单支持 Escape 关闭，关闭后焦点返回触发按钮
- 菜单打开时焦点自动移入第一个导航链接
- 路由切换后焦点移至 `<main>` 并滚动到顶部
- 提供"跳到主要内容"跳转链接（skip-link）

## 无障碍说明

- 语义化 HTML：`<header>`、`<nav>`、`<main>`、`<article>`、`<section>`、`<footer>`
- ARIA：`aria-expanded`、`aria-controls`、`aria-current="page"`、`aria-pressed`、`aria-busy`、`aria-live="polite"`、`role="status"`、`role="alert"`、`role="progressbar"`、`role="group"`、`aria-label`
- 表单控件均有关联的 `<label>`（视觉隐藏类 `.visually-hidden`）
- 图片装饰性内容使用 `aria-hidden="true"`
- 搜索结果数量通过 `aria-label` 动态更新
- 颜色对比度满足 WCAG AA 标准
- 尊重 `prefers-reduced-motion` 和 `prefers-contrast` 系统设置

## 影响交付结果的 SKILL.md 规则

**"触控目标最小 44×44 像素"**：SKILL.md 明确要求所有可交互元素满足 44px 最小触控尺寸。
这直接影响了 CSS 中 `--touch-target: 44px` 令牌的定义，以及按钮（`min-block-height: 44px`）、
导航链接（`min-block-height: 44px`）、导航切换按钮（`inline-size/block-size: 44px`）、
视图切换按钮（`inline-size: 44px`）、搜索框和下拉框（`block-size: 44px`）的尺寸设定。

此外，**"移动优先"**规则决定了整个 CSS 的编写顺序——先写窄屏样式再通过 `min-width` 增强；
**"使用 clamp() 实现流式排版"**规则决定了字号和间距不使用固定像素值而是流式缩放；
**"容器查询"**规则决定了产品卡片和统计卡片使用 `@container` 而非媒体查询来响应自身宽度。
