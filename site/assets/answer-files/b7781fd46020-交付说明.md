### 节奏设计要点

- **前2秒钩子**：0–2秒画面即出现打哈欠小生物+大字提问"你现在……想打哈欠了吗？"，用第二人称直接互动，2秒内建立信息钩子。
- **信息密度**：7句字幕，平均每句4秒，长句（第4句6.5秒）自动换行，保证阅读时间。
- **情绪曲线**：提问（好奇）→ 解释（理性）→ 共情（温暖）→ 回扣提问（互动），首尾呼应。
- **场景切换点**（8s/19s/27.5s）与字幕切换对齐，避免跳切感。

## 三、竖屏适配说明

### 1. 画幅与构图
- 采用 1080×1920（9:16）标准竖屏，适配抖音、快手、视频号、小红书、B站竖屏等主流平台。
- 主体居中构图，关键元素（角色、字幕）集中在画面中部 1080×1400 安全区内，避开平台 UI 遮挡（顶部约200px、底部约350px）。
- 顶部"30秒冷知识"标签位于 y=100，在多数平台标题栏下方仍可见。

### 2. 静音观看适配
- **全程硬字幕烧录**：每句配音均有对应屏幕字幕，关闭声音可完整理解全部内容。
- 字幕分两级：
  - 钩子句/结尾句：76px 大字居中，暖色描边，视觉冲击强；
  - 叙述句：54px 白字+黑色描边，底部半透明圆角黑底（透明度约51%），在任何背景上均清晰可读。
- 长句按像素宽度自动换行，每行不超过画面宽度的87%。
- 顶部标签"30秒冷知识"提供内容类型预告，静音状态下也能快速判断视频主题。

### 3. 版权与素材合规
- **画面**：4张插画均由 Seedream 5.0 Pro 从零生成，扁平卡通风格，无真实人物、无明星肖像、无IP角色。
- **配音**：豆包 TTS 合成语音，非真人录音，不涉及声优授权。
- **音乐**：**未使用任何背景音乐或音效**，彻底规避未授权音乐风险。全片仅有人声旁白。
- **字幕**：文案为原创科普叙述，未引用受版权保护的文本。

### 4. 可访问性
- 字幕字号大（54–76px），对比度高（白字黑边/暖色描边），适合小屏和视力较弱用户。
- 配音语速适中（约3字/秒），关键句有停顿。

## 五、dashscope Skill 规则对交付的实际影响

### 实际读取的 Skill 文件

- `dashscope/SKILL.md`（ZIP 内唯一文件，相对路径：`dashscope/SKILL.md`）

### 影响交付结果的 SKILL.md 规则（至少一条）

1. **【API Key 前置要求——直接改变了配音与字幕方案】**
   SKILL.md 第8行明确要求 `Requires DASHSCOPE_API_KEY in .env`。经检查，当前环境既无 `.env` 文件也无 `DASHSCOPE_API_KEY` 环境变量，因此 SKILL.md 规定的 dashscope 原生 TTS（`qwen3-tts-flash`）和 ASR（`qwen3-asr-flash-filetrans`）均无法调用。**实际影响**：配音改用豆包 TTS 完成；字幕时间轴无法按 SKILL.md 第96行推荐的"从 ASR 词级时间戳 `result.data['words']` 构建"，改为按文案语义和音频总时长（30.00s）手动分配7段时间轴。

2. **【图片生成模型——与用户指令的冲突处理】**
   SKILL.md 第22行规定图片生成默认模型为 `qwen-image-2.0-pro`，但用户在任务中明确要求"使用 Seedream 5.0 Pro 生图模型，不要改用其他生图模型"。按用户指令优先，图片环节使用 Seedream 5.0 Pro，未走 dashscope 图片接口。

3. **【ASR 公网 URL 要求——即使有 Key 也需额外上传】**
   SKILL.md 第95行、第118行、第129行反复强调 ASR 的 `audio_url` 必须是公网可访问 URL，本地路径会被拒绝。本次因无 Key 未触发该流程，但该规则意味着即使配置了 Key，也需先将音频上传至公网托管才能获取词级时间戳。

4. **【安全规则——已遵守】**
   SKILL.md 第136行要求"Never print or write the API key to logs, metadata, patches, or project artifacts"。本项目全程未涉及任何 API Key 输出。

### 与"题目假设"的差异说明

- 题目将 Skill 分类为"音视频趣玩"，但 SKILL.md 实际描述的能力边界是：**图片生成 + TTS + ASR 三项原子能力**，并不包含视频剪辑、运镜、特效、音乐生成等"视频制作"功能。视频合成实际由 PIL + moviepy 在 Skill 之外完成。
- SKILL.md 中提到的 OpenMontage 模块（`tools.graphics.image_selector`、`tools.audio.tts_selector`、`tools.analysis.dashscope_asr`）在当前 Python 环境中不存在（`ModuleNotFoundError: No module named 'tools'`），因此未按 SKILL.md 第55–89行的 selector 方式调用，而是直接使用平台内置工具完成等效能力。
