【第1页·封面·约40秒】大家好。今天用8分钟聊一个几乎所有新经理都会踩的坑——你因为做得好被提拔，但提拔之后，"做得好"反而成了你最大的障碍。我自己第一次带团队时，前三个月每天加班到半夜，因为总觉得"这个我来做更快"。结果呢？我累得半死，团队成员闲得发慌，还觉得我不信任他们。今天分享的核心就一句话：你的价值不再是你自己做了什么，而是你的团队能做到什么。

Chapter 01

The Shift.

你被提拔，不是因为你能做更多的事，
而是因为你能通过别人做成更多的事。

chapter · 01 / 03
section
【第2页·核心转变·约50秒】这是整个分享最核心的一页。IC（个人贡献者）的成功公式是：我自己产出多少。经理的成功公式是：我的团队整体产出多少。这两个公式是完全不同的游戏。很多新经理的惯性是继续玩老游戏——我要证明我还是最强的那个。但你越证明自己强，团队越弱。因为你把所有有挑战的活都揽了，他们没有成长空间。记住：从你当经理那天起，你的"手"就变成了团队的十几双手。你的工作不是让这双手更强，而是让那十几双手变强。

【第3页·四个信号·约1分钟】来对照一下，这四个信号你中了几个？第一，所有关键决策都要你拍板——你成了唯一的大脑和瓶颈。第二，你是最忙的人——这不是敬业，是角色错位。第三，成员遇事就问你——这不是信任，是依赖。第四，"教他不如我自己做"——短期你做更快，但每次自己做就是放弃一次让他成长的机会，三个月后他还是不会，你还是得自己做，这是死循环。中两个以上的，今天的分享对你特别有用。

Mindset Reset

赋能不是
甩锅。

不是把活扔给下属然后等结果。
而是：定义清楚问题 → 给对资源 → 陪他走完 → 复盘沉淀。

× 假赋能 · 放羊

"这个你来负责" → 消失 → 最后一刻发现方向全错 → 自己救火。

✓ 真赋能 · 教练

共同定义目标和边界 → 确认他有资源和能力 → 定期check-in → 结束后一起复盘。

content · compare
04
【第4页·真赋能vs假赋能·约1分钟】很多人以为赋能就是把活分出去然后不管了，那不叫赋能，叫甩锅。你说"这个你负责"然后消失两周，回来发现方向全错，最后还是你救火——这不是他的问题，是你的问题。真正的赋能是教练过程：一起定义目标和边界；确认他有资源和能力，缺什么你去搞；定期check-in看有没有卡住；做完一起复盘沉淀。假赋能是"你做，做不好我骂你"；真赋能是"我陪你做，成了是你的功，砸了我一起扛"。

Framework

3 个 动作
开始转型。

1. ASK · 别急着给答案，先问："你觉得该怎么做？"
2. DELEGATE · 按能力分级授权，从"你决定我知情"开始
3. REVIEW · 结果导向 + 过程复盘，对事不对人

不是等你"准备好了"才授权，
而是在授权中让他准备好。

content · framework
05
【第5页·三个动作·约1.5分钟】具体怎么做？三个动作今天回去就能用。第一，ASK：下次有人问你怎么办，忍住别说答案，反问"你觉得该怎么做？"等他十秒钟。慢慢他会带方案来找你而不是带问题。第二，DELEGATE分级授权：分四级——你决定他执行、讨论后你决定、他决定你知情、他完全自主。从第三级"他决定你知情"开始，既给空间又不失控。第三，REVIEW复盘：定期看结果和过程，对事不对人，不是"你怎么搞砸了"而是"我们看看哪能改进"。关键：不要等他准备好了才授权，没人是准备好了才上场的。

06
【第6页·杠杆效应·约50秒】为什么这个转变重要？因为它是杠杆。转型前你是瓶颈，产出上限是你一个人的时间精力，1倍。转型后你是放大器，每个人都能独立产出，整体是N倍，而且N会随每个人成长越来越大。我自己的经历：转型前我扛了团队40%关键任务，每天12小时；转型后我扛不到10%，团队产出翻了不止一倍，我反而能准时下班。这不是偷懒，是你的角色本来就该做的事。

【第7页·本周行动·约1分钟】不要听完就完了，本周做三件事。第一，花15分钟列你现在亲自做的事，圈出2件能交出去的，下周就交。第二，下次有人问你问题，先反问"你觉得呢？"忍住10秒，这10秒很煎熬但在给他思考空间。第三，找一个成员约30分钟，不聊任务聊他想成长的方向，一起定一个比他现在能力稍高一点的小挑战，你支持他完成。不需要惊天动地，从小处开始，坚持一个月你会感到明显不同。
