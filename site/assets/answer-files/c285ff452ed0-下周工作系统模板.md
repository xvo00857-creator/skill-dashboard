## 二、下周行动清单（按优先级排序）

优先级判定标准：

- **P2 常规事务**：例行跟进、信息同步
- **P3 可延后**：有价值但下周不做影响不大

## 四、授权清单（执行前必须确认）

在将本计划付诸执行前，逐项确认：

- [ ] 所有 P0 事项的负责人已明确并同意承担
- [ ] 涉及跨团队协作的事项已与对方对齐
- [ ] 需要访问生产环境/敏感数据的操作已获得书面授权
- [ ] 需要花钱/调资源的事项已获预算批准
- [ ] 不可逆操作（删除数据、发送外部邮件、发布上线）有审批记录和回滚方案
- [ ] 个人敏感信息的处理符合公司数据安全规定

## 五、停止条件

出现以下任一情况，**立即暂停执行**并升级：

1. 发现输入信息与事实不符且影响 P0 决策
2. P0 事项的依赖方明确表示无法按时交付
3. 出现未登记的新高风险（红色级）
4. 执行过程中需要超出授权清单的权限
5. 任何操作可能造成数据丢失、服务中断或信息泄露

## 六、回滚方案

| 操作类型 | 回滚方式 |
|----------|----------|
| 文档/配置修改 | 修改前保留副本，命名为 `.bak-日期` |
| 发送外部消息 | 2 分钟内可撤回；超时则发送更正声明 |
| 数据变更 | 先备份再操作；保留变更前后快照 |
| 代码/系统变更 | 通过版本控制回退；不在周五下午做不可逆变更 |

## 使用说明

1. **归集**：将本周所有会议结论、待办、风险填入第一节，标注来源
2. **分级**：按优先级标准排序，P0 不超过 5 项（超过说明范围失控）
3. **确认**：完成第四节授权清单
4. **执行**：按每日节奏推进，遇到停止条件立即暂停
5. **复盘**：周五填写第八节，未完成项滚入下周但需重新评估优先级
