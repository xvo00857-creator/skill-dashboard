| 1. 首屏 Hero | 主标题（通勤保温痛点切入）+ 产品白底图 + 199 元 + 主 CTA"立即购买" | 3 秒内传达价值 |
| 2. 三大卖点 | 12h 保温 / 280g 轻量 / 可拆洗杯盖，各配图标 + 一句话 + 细节图 | 核心差异化 |

| 4. 规格参数 | 容量、材质、尺寸、重量等基础规格表 | 理性决策 |
| 5. 材质安全 | 食品接触材料说明 + 检测报告（报告待补，暂占位"认证中"） | 消除健康顾虑 |
| 6. 细节拆解 | 杯盖可拆洗结构爆炸图/步骤图 | 强化"易清洁" |

| 9. FAQ | 保温时效、清洗方式、防水说明（防水等级待补）、售后物流 | 降低疑虑 |
| 10. 底部 CTA | 重复"立即购买"+ 199 元 + 服务承诺 | 收口转化 |

**配色规范**：主色 #176B87 用于 CTA 按钮、标题强调、图标；辅色用白色/浅灰保证留白；价格用深色加粗。

## 五、最小可验证版本（MVP）

### 5.1 MVP 定义

在缺失素材与首发日期未确定的条件下，先上线**仅依赖已确认素材**的最小落地页，验证"卖点信息→加购"的基础转化链路。

### 5.2 MVP 包含区块

1. 首屏 Hero（白底图 + 主标题 + 199 元 + CTA）
2. 三大卖点区（图标 + 一句话，白底图裁切/局部特写）
3. 规格参数表
4. 杯盖拆洗说明（用白底图 + 文字步骤，无爆炸图时用编号列表替代）
5. 底部 CTA
6. 基础数据埋点（页面浏览、CTA 点击、加购、结账）

### 5.3 MVP 暂不包含

- 场景生活方式图（待拍摄）
- 用户评价区（待真实评价）
- 检测报告（待提供）
- 防水等级说明（待提供）
- 品牌故事（待提供文案）

### 5.4 关键步骤与验收标准

| 步骤 | 关键动作 | 验收标准 |
|---|---|---|
| S1 信息架构定稿 | 确认本方案第三节区块结构与文案框架 | 产品/市场负责人书面确认 |
| S2 页面搭建 | 在 Shopify 中用页面构建应用完成 MVP 区块，配色 #176B87 | 多端（桌面/移动）预览无错位；CTA 可点击跳转结账 |
| S3 埋点接入 | 配置页面浏览、CTA 点击、加购、结账事件 | 测试下单可在分析后台看到完整漏斗数据 |
| S4 移动端适配 | 检查首屏加载速度、图片尺寸、按钮可点区域 | 移动端首屏 LCP < 2.5 秒（目标，需实测）；按钮高度 ≥ 44px |
| S5 小流量验证 | 引入小额付费流量或自有渠道流量，观察 7 天 | 可采集到 ≥ 1000 次访问（目标，视预算）；漏斗数据完整无断档 |
| S6 复盘决策 | 依据数据决定迭代方向（加素材/A/B 测试/扩量） | 输出一页复盘，含各漏斗转化率与下一步动作 |

## 六、优先级行动项（Priority Actions: Quick Wins → Long-term）

### 快速见效（1 周内）

1. 用已确认白底图 + 规格上线 MVP 落地页。
2. 配置品牌主色 #176B87 与基础排版，保证移动端可用。
3. 接入基础转化漏斗埋点。
4. 自有渠道（公众号/邮件）预告，收集早期点击数据。

### 中期优化（2–4 周）

1. 拍摄/制作场景图与细节特写，补齐场景共鸣区与细节拆解区。
2. 获取食品接触材料报告与防水等级，补齐材质安全区。
3. 确定首发日期，上线首发倒计时/首发优惠机制。
4. 启动首轮 A/B 测试（首屏标题 + CTA 文案）。
5. 小红书/抖音内容铺量，小预算信息流测试。

### 长期建设（1–3 月）

1. 积累真实用户评价后上线评价区（带图评价优先）。
2. 基于 A/B 测试结果迭代页面，建立常态化测试机制。
3. 拓展集合页（Collection Page）与季节性促销页（如冬季保温专题）。
4. 接入再营销广告（落地页访客未购买人群定向）。
5. 建立落地页模板库，复用于后续新品。

## 十二、结论与假设分离

3. 移动端流量占比将超过 70%——需上线后用实际设备数据验证。
4. 第九节 KPI 目标阈值（跳出率 < 60%、LCP < 2.5s 等）为通用参考，非本店铺基线。
5. 各页面构建工具的价格档位为公开常见值，实际以 Shopify App Store 实时信息为准。
