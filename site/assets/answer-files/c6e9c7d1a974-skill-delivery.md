## 2. 现状评估（Current State Assessment）

### 2.1 商品归类判定

保温杯/随行杯属于 TikTok Shop **食品接触类商品——饮具**类目（与水瓶、马克杯同组）。该类目在美、英、沙特等市场均有强制检测、标签与资质要求，**不是**普通家居杂品（来源见第 11 节 S1）。

### 2.2 受限商品风险

- **食品接触材料安全**：与饮品直接接触的内胆、杯盖密封圈等部件，须按目标市场法规通过重金属迁移、总迁移、感官等测试。目前**食品接触材料报告缺失**，属上架前硬阻断（来源 S1）。
- **"智能"定性风险**：简报仅列出保温、重量、可拆洗杯盖三项物理卖点，未列明任何电子功能。若实物不含温度显示、蓝牙、电池等电子模块，则"智能"属无事实依据的营销命名，存在误导性宣传风险；若实物含电子模块，则触发电池/电子产品安全认证（如 UN38.3、CE/UKCA、FCC 等）这一额外受限类目，且"防水等级"才成为必要参数。**此项必须先澄清。**
- **包装与标签**：食品接触类商品须在销售包装上以英文标注产品名称/型号、生产商名称地址、原产国、"用于食品接触"字样或刀叉符号；目前标签方案未提供（来源 S1）。

### 2.3 知识产权现状

- 品牌名称与商标注册状态未提供，无法判断是否存在在先商标冲突或是否需要品牌资质（Brand Qualification）。
- 已确认素材为"产品白底图"，须确保为自有拍摄/已获授权，避免图片版权侵权；品牌主色 #176B87 本身不构成商标，但整体视觉不得与知名品牌保温杯构成混淆（反仿冒/反 knockoff 政策）。（来源 S3）

### 2.4 内容/宣传合规现状

- "12 小时保温"属**性能声称**，按平台真实性与可证实性要求，须有检测报告或实测数据支撑，否则构成误导性声称。（来源 S4）
- "可拆洗杯盖"为结构事实，可保留，但不得延伸为"医疗级""抗菌""健康"等未经证实的健康声称。
- 199 元定价本身合规，但不得使用虚构原价/划线价进行虚假折扣。
- 素材中不得出现第三方品牌 logo、名人肖像或未经授权的背景音乐/文案。（来源 S5）

### 3.1 结论（基于已确认信息与公开平台规则）

4. 食品接触类商品销售包装须具备英文标签四要素（品名型号、生产商名址、原产国、食品接触标识），当前标签方案缺失。
5. 品牌商标状态与素材授权状态未确认，存在知识产权不确定性。
