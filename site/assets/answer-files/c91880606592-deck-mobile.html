PRINCIPLES · 设计原则

三条原则，来自模板定义本身。

本规范严格依据 deck-simple 模板：横向滑动、单页单义、图文各一，不做杂志化排版。

横向滑动

每页占满一屏，左右方向键或触控滑动切换，滚动吸附对齐。

单页单义

每页只讲一个核心信息，配一张图或一个图表，降低认知负担。

克制通用

面向 pitch / overview / study，留白充足，拒绝杂志式多栏混排。

COLOR · 色彩体系

只有三种颜色，各司其职。

深蓝承载文字与结构，米白作为底色，亮橙只用于强调与进度。正文与背景对比度充足。

TYPOGRAPHY · 字体排版

层级靠字号与字重，不靠颜色堆砌。

系统无衬线字体，中文回退 PingFang / 微软雅黑；行高 1.6，正文不小于 17px。

H1 封面主标题 34–50 / 700
H2 内容页标题 25–34 / 700
BODY 正文，十七像素，行高一点六。 17 / 400
EYEBROW 栏目标签 12 / 600
DESKTOP · 桌面横屏

16:9 满屏，左右滑动。

桌面版每页占满视口，采用左右分栏或三栏网格，适合大屏演示与投屏。

  • 页内边距 72–96px，呼吸感充足
  • 图文分栏，图片最大宽度约占半屏
  • 顶部进度条 + 右下角页码
MOBILE · 手机竖屏

9:16 单列，触控滑动。

同一套内容与配色重排为单列，缩小边距与字号，正文不低于 17px，保证手机上可读。

  • 页内边距收窄至约 28–40px
  • 三栏网格折叠为单列
  • 保留横向滑动与进度条
INTERACTION · 交互

按模板要求实现键盘左右切换与 hash 同步：刷新或分享链接可直接定位到对应页。
