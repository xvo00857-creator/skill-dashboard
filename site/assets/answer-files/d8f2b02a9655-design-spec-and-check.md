# 设计规范与一致性检查

## 一、关键设计规范

### 1. 品牌色板（三色限定）

| 角色 | 色值 | 用途 | 实测值（生成图） |
|---|---|---|---|
| 深蓝 | `#1B3A5B` | 标题栏、底栏、阶段名、边框、箭头、正文文字 | 桌面 `#193656` / 手机 `#163353` |
| 米白 | `#F7F2E9` | 页面背景、深色栏上的文字 | 桌面 `#F6EFDF` / 手机 `#F7F2E7` |
| 亮橙 | `#FF6A13` | 情绪曲线、序号圆点、左侧强调条、关键数字 | 桌面 `#FF5C00` / 手机 `#FF6600` |

> 实测值由 Python 采样生成图像素得出，与目标值的微小偏差来自模型渲染与 JPEG 压缩，视觉上保持一致。
> 卡片底色为近白米白（`#FAF8F2` 量级），属米白色系内明暗变化，未引入新色相。

### 2. 尺寸规格

| 版本 | 比例 | 输出像素 | 实际像素 | 适用场景 |
|---|---|---|---|---|
| 桌面横屏 | 16:9 | 2048 × 1152 | 2730 × 1536 | 桌面网页、PPT、横屏展示 |
| 手机竖屏 | 9:16 | 1152 × 2048 | 1536 × 2730 | 手机端、社媒竖图、Story |

### 3. 版式规范

**桌面横版：**
- 顶部深蓝通栏标题区（主标题 + 副标题）
- 标题下方亮橙情绪曲线，7 个节点标注情绪值（65→45→30→55→75→85→95）
- 7 个等宽纵向卡片横向排列，箭头连接
- 每卡：橙色圆形序号 → 深蓝阶段名 → 三行标签（触点/痛点/机会）
- 底部深蓝通栏：关键时刻

**手机竖版：**
- 顶部深蓝通栏标题区（同桌面）
- 亮橙情绪曲线横向压缩展示
- 7 个横向卡片纵向堆叠，橙色左边框强调
- 每卡：橙色圆形序号 → 深蓝阶段名 → 两行标签（关键触点/核心机会）
- 卡片间向下箭头
- 底部深蓝圆角胶囊条：关键时刻

### 4. 字体与可读性

- 字体：无衬线黑体（中文）/ 无衬线体（数字与英文）
- 主标题：大号粗体，白字置于深蓝底上，高对比
- 阶段名：中号粗体，深蓝字置于米白底上
- 正文标签：中号常规，深蓝字，行距宽松
- 对比策略：所有文字均为"深蓝字/米白底"或"米白字/深蓝底"，亮橙仅作点缀不承载正文，保证对比度

### 5. 图形语言

- 扁平、极简、无渐变、无阴影、无纹理
- 圆形序号 + 卡片 + 箭头的统一语法
- 情绪曲线为唯一折线图元素

### 已知差异与说明

1. **情绪数值**：桌面版在曲线节点旁标注了数值，竖版因横向空间有限仅保留曲线形态。如需竖版也显示数值，可在后续版本中以纵向标签或缩小字号补充。
2. **卡片标签行数**：桌面版每卡三行（触点/痛点/机会），竖版每卡两行（关键触点/核心机会），以适配竖屏宽度。完整内容以 Markdown 分析文档为准。
3. **小图标**：桌面版标签前有微型线性图标，其颜色偏深灰（占比 < 1%），为模型渲染的抗锯齿色，非独立品牌色；不影响整体三色规范。
