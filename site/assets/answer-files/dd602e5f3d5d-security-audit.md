### 记录 1 — alice 登录成功
- 事实：`web/info/login_success`，用户 `alice`，IP `192.0.2.10`。
- 判定：正常基线行为，作为时间窗口起点参考。无异常。

### 记录 2、3 — admin 连续登录失败
- 事实：`198.51.100.23` 在 09:03:45 与 09:03:49（间隔 4 秒）两次以 `admin` 账户登录失败。
- 分析：短间隔对高权限账户的重复失败符合暴力破解/口令喷洒特征，但仅 2 次、窗口内未见后续成功登录或更多尝试。⚠️ 可能是：(a) 自动化暴破早期；(b) 合法用户输错口令；(c) 授权测试用例。缺少账户锁定策略与该 IP 历史行为数据，置信度中低。
- 注意：该 IP 与记录 4/5 的 `203.0.113.8` 不同，无直接证据表明二者关联，不能强行并案。

### 记录 4 — service-a 令牌作用域不匹配
- 事实：`api/high/token_scope_mismatch`，调用方 `service-a`，IP `203.0.113.8`。
- 分析：服务账号所持令牌的 scope 与其请求的 API 权限不符。可能原因：令牌配置错误（最小权限原则下的正常拒绝）、令牌被篡改/重放、或服务账号尝试越权访问未授权接口。仅凭此条无法区分配置失误与恶意行为。

### 记录 5 — 数据库非预期导出（最严重）
- 事实：`db/critical/unexpected_export`，用户 `unknown`（未认证/无法识别主体），IP `203.0.113.8`。
- 分析：数据库层发生非预期批量导出，且主体为 `unknown`，意味着导出可能绕过了应用层认证或使用了失效/匿名凭据。与记录 4 **同源 IP**、时间相差 3 分 28 秒、严重级从 high 升至 critical，疑似链路为：`service-a` 令牌越权尝试 → 利用所得访问或同一入口执行 DB 导出。⚠️ 缺少导出表名、行数、目标位置、会话关联，无法确认数据是否实际落盘外传，亦无法排除 IP 为共享出口/NAT 导致的巧合。

### 记录 6 — 畸形记录
- 事实：`web` 系统、事件 `malformed_record`，但 severity/user/source_ip 三字段为空。
- 分析：三种可能——(a) 日志采集/解析管道故障（字段丢失）；(b) 应用在异常路径下写出不完整日志；(c) ⚠️ 攻击者在关键事件（记录 5 之后 1 分 30 秒）后干扰日志以掩盖痕迹。发生在 critical 事件之后使 (c) 不能排除，但无证据证明篡改。该记录还导致基于 severity 的自动告警/分级规则漏判，本身即是监控盲点。

## 六、优先级修复建议

按"先止血、后加固、再补盲"排序。以下均为建议，未在真实环境执行。

### P0 — 立即处置（针对 R1/R5）
1. **核验记录 5 的导出事实**：在数据库审计日志中确认 09:07:30 前后是否存在实际导出作业、导出的表/行数/目标路径、执行账号与会话；确认 `unknown` 主体来源（匿名连接？失效令牌？共享账号？）。
2. **临时限制 service-a 令牌**：在授权范围内吊销/轮换 `service-a` 当前令牌，收敛其 scope 至最小权限，待复核后再恢复。
3. **核查 203.0.113.8 的所有活动**：拉取该 IP 在更大时间窗口（建议前后各 24 小时）的全量访问日志，确认是否存在数据外传、横向移动或其他接口调用。

### P1 — 短期加固（针对 R2/R3）
4. **令牌生命周期与 scope 治理**：为服务账号令牌设置有效期、audience/scope 白名单与自动轮换；对 `token_scope_mismatch` 建立聚合告警（单账号短时间多次触发即升级）。
5. **管理员账户保护**：对 `admin` 启用强口令 + MFA；配置登录失败阈值与临时锁定/速率限制；禁止 admin 从非管理网段登录。
6. **数据库访问控制**：禁用匿名/unknown 主体访问；应用账号与导出权限分离；批量导出需二次审批与工单留痕。

### P2 — 中期补盲（针对 R4 与可观测性）
7. **修复日志管道**：定位 `malformed_record` 产生原因（采集器/解析器/应用异常路径），确保 severity/user/source_ip 为必填或有默认值；对字段缺失率设置监控。
8. **日志防篡改与完整性**：日志集中存储并开启只追加/WORM 与哈希链；关键事件（尤其 DB 导出）同步独立审计通道。
9. **关联检测规则**：在 SIEM 中配置"同源 high→critical 时间窗递进""unknown 主体 DB 导出""登录失败后短时 API 异常"等关联规则。
