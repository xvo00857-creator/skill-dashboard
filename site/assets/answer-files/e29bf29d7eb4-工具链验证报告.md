## 1. build-url.py — URL 构建验证

### 1.1 默认参数（ebay.com，按结束时间排序）

命令：
```bash
python3 scripts/build-url.py "iphone 15"
```
输出（真实）：
```
https://www.ebay.com/sch/i.html?_nkw=iphone+15&LH_Sold=1&LH_Complete=1&_ipg=60&_pgn=1&_sop=13
```

验证点：
- `LH_Sold=1` 始终存在（只看已售出）
- `LH_Complete=1` 默认存在（BOA 检测需要）
- `_sop=13` = endedRecently
- `_ipg=60` 默认每页 60 条

### 1.2 全参数组合（ebay.co.uk，二手，价格区间，240/页，第 3 页）

命令：
```bash
python3 scripts/build-url.py "test" --ebaySite ebay.co.uk \
  --sortOrder pricePlusPostageHighest --categoryId 9355 \
  --itemLocation domestic --itemCondition used \
  --minPrice 10 --maxPrice 500 \
  --includeCompletedListings false --ipg 240 --page 3
```
输出（真实）：
```
https://www.ebay.co.uk/sch/i.html?_nkw=test&LH_Sold=1&_ipg=240&_pgn=3&_sop=16&_sacat=9355&LH_PrefLoc=1&LH_ItemCondition=3000&_udlo=10&_udhi=500
```

验证点：
- `includeCompletedListings=false` → 无 `LH_Complete=1`（BOA 不检测，符合 SKILL.md 说明）
- `_sop=16` = pricePlusPostageHighest
- `_sacat=9355` 分类过滤
- `LH_PrefLoc=1` = domestic
- `LH_ItemCondition=3000` = used
- `_udlo=10&_udhi=500` 价格区间

### 1.3 DRY_RUN 编排脚本输出（两个关键词，带筛选）

命令：
```bash
DRY_RUN=1 EBAY_SITE=ebay.com ITEM_CONDITION=used MIN_PRICE=50 MAX_PRICE=300 \
  bash collect.sh "airpods pro" "nintendo switch"
```
输出（真实）：
```
https://www.ebay.com/sch/i.html?_nkw=airpods+pro&LH_Sold=1&LH_Complete=1&_ipg=60&_pgn=1&_sop=13&LH_ItemCondition=3000&_udlo=50&_udhi=300
https://www.ebay.com/sch/i.html?_nkw=nintendo+switch&LH_Sold=1&LH_Complete=1&_ipg=60&_pgn=1&_sop=13&LH_ItemCondition=3000&_udlo=50&_udhi=300
```
