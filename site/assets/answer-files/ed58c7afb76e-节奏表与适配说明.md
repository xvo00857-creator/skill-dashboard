## 二、适配说明

### 1. 时长适配：25秒 → 30秒

- **Skill 原版**：5幕×5秒=25秒，情绪曲线为"热情神秘→专业详细→专注生动→自信有力→鼓励坚决"
- **改版**：6幕×5秒=30秒，新增第二幕"痛点共鸣"（亲切好奇），情绪曲线扩展为"热情神秘→**亲切好奇**→专业详细→专注生动→自信有力→鼓励坚决"
- 新增幕的作用：在钩子与产品介绍之间插入痛点共鸣环节，强化"换季泛红、熬夜暗沉"的用户代入感，使信息层次更完整
- 此改动遵循 Skill 的"五幕情绪递进"设计逻辑，将五幕扩展为六幕，每幕仍严格保持5秒、动作时序仍按0-1s/1-3s/3-5s分段

### 2. 前2秒信息钩子设计

- **0-1s**：人物双手快速举起产品至胸前（动作利落有冲击力），同步弹出黄色大字"这套护肤 我回购三次了！"
- **1-2s**：保持举产品姿势，头部微抬，直视镜头微笑（钩子定格），大字保持
- 钩子要素：**人物动作冲击 + 大字标题 + 产品视觉 + 直视镜头**，四重信息在2秒内同时建立
- 静音状态下，大字标题直接传达核心卖点，无需声音即可理解

### 3. 静音观看适配

- 每幕均烧录大号花字（字号36-50px），带半透明黑色底框，确保在各种画面背景上可读
- 花字内容与台词核心信息一致但更精炼，静音时仅看画面文字即可理解完整叙事
- 花字位置：顶部为主题/卖点，底部为补充/结论，中部为关键钩子/CTA
- 花字通过 ffmpeg drawtext 后期烧录（非AI生图文字），确保中文渲染准确无乱码

### 4. 音频合规说明

- **导购员语音**：使用 text_to_audio 工具从零合成的原创TTS语音，非真人录音，无声纹克隆
- **背景音乐**：使用 text_to_audio 工具生成的30秒原创纯音乐（钢琴+轻鼓点+电子轻音+弦乐），非版权曲目，非Suno生成
- **人物素材**：角色为Skill定义的虚构数字人"小省导购员"，使用 Seedream 5.0 Pro 生成参考图，非真人照片
- **产品素材**：护肤品为无品牌Logo的简约白瓶，AI生成，不涉及真实品牌
- **BGM混音**：BGM音量降至12%，确保语音清晰可辨

### 5. 工具链与Skill差异说明（重要）

| 环节 | Skill 规定 | 实际执行 | 差异说明 |
|------|-----------|---------|---------|
| 视频模型 | InfiniteTalk（Wan2.1-I2V-14B-480P） | seedance 2.5（图生视频） | InfiniteTalk模型环境本机不可用，使用可用的图生视频模型替代；Skill产出的结构化提示词已适配为视频画面描述 |
| 音乐生成 | Suno | text_to_audio | Suno不可用，使用TTS音频工具生成原创纯音乐，无版权风险 |
| 语音编码 | chinese-wav2vec2-base, 16kHz单声道 | text_to_audio合成, 44.1kHz立体声 | 编码格式不同，但语音内容、语速、情绪均按Skill规范设计 |
| 输出分辨率 | 1080×1920 | 720×1280 | seedance模型输出上限为720×1280，保持9:16比例不变 |
| 面部一致性 | face_consistency=True参数 | 参考图角色一致性+seedance生成 | 通过6张统一角色参考图保证一致性，无专用面部一致性参数 |
| 动作强度 | motion_strength=0.8 | 通过prompt描述控制 | seedance无此参数，通过提示词控制动作幅度 |
| 唇形同步 | InfiniteTalk音频驱动唇形 | 无唇形同步 | seedance图生视频不支持音频驱动唇形，人物口型为自然说话状态但不精确同步 |
| 视频水印 | 无 | 右下角"豆包AI生成" | seedance模型自带水印，无法去除 |

### 6. 质量核查结果

按 Skill 规定的四维度核查：

| 维度 | 核查项 | 结果 |
|------|--------|------|

| 情绪连贯性 | 热情→亲切→专业→专注→自信→鼓励递进 | 通过：情绪曲线自然，无断层 |
| 技术参数 | 5s/幕、9:16、动作时序0-1s/1-3s/3-5s | 通过：每幕严格5秒，动作时序在提示词中按秒分段 |

### 7. 仍需确认的假设

1. **产品主题**：用户未指定具体产品，沿用 Skill 示例中的"护肤品套装"主题，产品为虚构无品牌白瓶
2. **台词内容**：台词由我按带货视频常见结构撰写，未经用户确认修改
3. **InfiniteTalk不可用**：本机无InfiniteTalk模型环境，视频使用seedance替代生成，唇形不同步、分辨率为720p
4. **视频水印**：seedance生成的视频带有"豆包AI生成"水印
5. **TTS音色**：语音为合成音色，非真人配音，音色风格为年轻女性导购员
6. **BGM风格**：背景音乐为AI生成的原创纯音乐，风格为轻快时尚，具体听感以实际音频为准
