## 一、结论与假设分离

- **定价**：建议零售价 199 元（币种与目标市场需在 Phase 1 确认，见假设）。
- **目标受众**：一二线城市通勤人群（来自简报）。
- **已确认素材**：产品白底图、基础规格、品牌主色 #176B87。
- **缺失项**：首发日期未定；防水等级、食品接触材料报告未提供。
- **禁止编造**：第三方检测结论、销量、用户评价、竞品价格——本方案中凡涉及此类数据一律标注为"待补"或"假设"，不作为事实陈述。

### 假设（需在执行前确认，不视为既定事实）

| 编号 | 假设内容 | 影响范围 | 确认方式 |

## 二、受众画像

基于简报"一二线城市通勤人群"推导，以下为可执行的受众细分（属策略推导，非外部数据）：

| 细分人群 | 核心痛点 | 对应卖点 | 内容切入角度 |
|---|---|---|---|
| 地铁/公交通勤者 | 包重、杯子漏洒、清洗麻烦 | 280g 轻量化、可拆洗杯盖 | "通勤包减重实测"、"杯盖 30 秒拆洗" |

## 三、信息结构（Listing 与内容主轴）

信息层级按"卖点可信度"排序：已确认事实优先，待验证项不写入主卖点。

### 3.1 商品标题结构（待本地化）

`[品牌名] 智能随行杯 12小时保温 280g轻量化 可拆洗杯盖 通勤保温杯 [容量，待补]`

- 标题仅使用简报已确认的三个卖点；容量、材质等未提供信息留待补充。
- 具体英文标题需在确认目标站点（A1）后按 TikTok Shop 搜索习惯本地化。

### 3.2 详情页信息架构

1. **首屏主图/视频**：白底图（已有）+ 品牌主色 #176B87 视觉锤，突出 12h 保温与 280g。
2. **三大卖点模块**：
   - 12 小时保温——以时间轴图示呈现（不可标注未经检测的具体温度曲线，除非有报告支撑）。
   - 280g 轻量化——与常见物品（如手机）对比称重展示。
   - 可拆洗杯盖——拆解动图/视频，展示无死角清洁。
3. **通勤场景模块**：地铁、办公桌、健身房三场景图（需拍摄，当前仅有白底图）。
4. **规格参数模块**：仅列已确认基础规格；防水等级、食品接触材质待报告到位后补充。
5. **信任与合规模块**：食品接触材料报告（待补）、保修政策（待业务方确认）。

### 3.3 内容信息主轴（短视频/直播）

- **主线**："通勤人的杯子，轻一点、净一点、暖一点"——三个卖点各对应一个内容系列。
- **内容纪律**（来自 SKILL.md "Common Pitfalls"）：不做纯促销硬广，每条视频必须提供实用价值或场景共鸣；遵守 TikTok 社区规范。

## 四、渠道动作（按 SKILL.md 三阶段框架）

### Phase 1：基础搭建（第 1–4 周）

**账号与店铺搭建清单：**
- [ ] 确认目标站点（假设 A1），提交 TikTok Shop 卖家申请
- [ ] 完成企业资质验证与文件提交
- [ ] 配置支付收款与税务信息
- [ ] 设置运费模板与配送区域（跨境物流方案待供应链确认）
- [ ] 制定店铺政策：退换货、退款、服务条款

**店铺与商品优化：**
- [ ] 设计店铺主页与 Banner，使用品牌主色 #176B87
- [ ] 上传智能随行杯 Listing（首批以单品打爆为主，非 10–20 个 SKU；后续视表现扩展配色/容量）
- [ ] 优化商品标题与描述（按 3.1/3.2）
- [ ] 基于白底图制作首组商品视频（至少 3 条：保温实测、称重、拆洗演示）
- [ ] **阻断项检查**：食品接触材料报告、防水等级未到位前，Listing 中不得出现相关认证宣称；若站点要求此类认证方可上架，则首发日期相应顺延

**Phase 1 验收标准：**
1. 店铺通过审核且政策配置完整。
2. Listing 上线，标题/描述/图片/视频齐备，无未经证实的宣称。
3. 至少 3 条商品视频通过审核并可正常投放。
4. 合规文件齐备或已明确缺失项对上架的影响。

### Phase 2：内容与流量（第 5–12 周）

**内容策略：**
- **发布频率**：遵循 SKILL.md 建议，每日至少 1 条视频（minimum 1 video/day）。
- **内容配比**（按 SKILL.md Content Creation Plan 框架）：

| 内容类型 | 频率 | 目标 | 关键元素 |
|---|---|---|---|
| 产品演示（保温/称重/拆洗） | 3 条/周 | 直接转化 | 实测过程、卖点可视化 |
| 通勤场景/生活方式 | 2 条/周 | 共鸣与种草 | 地铁、办公、健身场景 |
| 幕后/品牌故事 | 1 条/周 | 建立信任 | 设计理念、工厂/品控（待素材） |
| 教育/干货 | 1 条/周 | 专业权威 | 保温杯选购、清洁技巧 |

- **话题标签策略**：以 #tumbler #insulatedbottle #commuteessentials #ecofriendly 等为基础池（具体 10–15 个标签需结合目标站点实时热门标签确定，列为待补，不臆测热度排名）。
- **趋势参与**：每周复盘 TikTok 创意中心趋势，筛选与通勤、饮品、办公相关的声音/挑战进行适配。

**流量组合：**
- 自然流量为主（短视频 + 直播间）。
- 付费推广：在有 3–5 条自然数据跑正的视频后，用 TikTok Shop 广告（如 Video Shopping Ads）小额测试，预算与 ROI 目标待业务方给定（不臆测金额）。
- 直播：第 8 周起每周 1–2 场，以"通勤杯实测+限时优惠"为脚本框架。

**Phase 2 验收标准：**
1. 连续 8 周保持日更，累计发布 ≥56 条视频。
2. 至少 3 条视频单条播放量突破账号自然流量中位数的 3 倍（具体阈值开播后按真实数据校准）。
3. 完成至少 4 场直播。
4. 建立内容数据周报机制（追踪播放、完播、点击、转化）。

### Phase 3：达人合作与规模化（第 13 周起）

**达人联盟计划：**
- [ ] 开通 TikTok Shop Affiliate 计划
- [ ] 佣金比例：待业务方根据利润空间确认（SKILL.md 框架要求设定，但本方案不臆测具体百分比）
- [ ] 达人画像：通勤/办公/生活方式/健身类中小达人（粉丝量区间待结合真实达人库确定）
- [ ] 样品计划：免费寄样换取内容，首批样品数量与预算待确认
- [ ] 绩效追踪：按达人维度追踪内容产出、GMV、ROI，每两周复盘

**SKILL.md 明确指出的局限（影响本阶段）：**
> "Creator recommendations require manual research" / "Trend identification needs manual monitoring"

因此达人名单不预设、不编造，需通过 TikTok Shop Creator Marketplace 手动筛选并建立真实联系。

**Phase 3 验收标准：**
1. 联盟计划上线且佣金配置完成。
2. 首批 ≥10 位达人确认合作（以真实确认为准）。
3. 建立达人绩效看板并完成首次双周复盘。
4. 根据真实销售数据决定是否扩展 SKU（配色/容量）。

## 七、最小可验证版本（MVP）

**目标**：在 4 周内用最低成本验证"产品—内容—转化"链路是否成立，不追求规模。

### MVP 关键步骤

1. **第 1 周**：确认目标站点与合规状态；店铺申请同步进行；基于白底图产出 3 条卖点实测视频（保温计时、称重、杯盖拆洗）。
2. **第 2 周**：Listing 上线（若合规允许）；账号开始日更，前 7 条视频全部围绕三个已确认卖点。
3. **第 3 周**：观察自然流量数据，筛选 CTR 与完播率最高的 1–2 条，小额投流测试（预算待业务方确认）。
4. **第 4 周**：完成 1 场直播；汇总首月真实数据，建立基线，决定是否进入 Phase 2 全量内容与 Phase 3 达人拓展。

### MVP 验收标准（通过/不通过判定）

| 编号 | 验收项 | 通过标准 |
|---|---|---|
| M1 | 店铺与 Listing 上线 | 审核通过且无合规警告 |
| M2 | 内容产出 | 4 周内发布 ≥28 条视频，无违规 |
| M3 | 数据基线 | 获得真实的播放、CTR、转化数据（无论数值高低，有数据即通过） |
| M4 | 转化验证 | 产生真实订单（数量不设硬性目标，以验证链路打通为准） |
| M5 | 决策输出 | 基于真实数据给出"继续/调整/终止"建议及下一阶段计划 |

> 说明：MVP 不以 GMV 规模为成功标准，而以"链路是否跑通、数据是否可获取"为标准——这符合 SKILL.md "Track metrics and optimize based on performance, not assumptions" 的要求，也遵守产品简报"不得编造销量"的约束。

## 八、待补项与数据差异

### 必须补充后才能执行的阻断项

1. **目标市场确认**：TikTok Shop 站点（US/UK/SEA）或是否实际为抖音电商。
2. **食品接触材料报告**：水杯类目上架合规必需。
3. **防水等级**：影响"可拆洗"宣传口径。
4. **首发日期**：排期倒推依据。

### 需要外部数据（明确列为待补，不臆测）

- TikTok 目标站点实时热门标签与趋势
- 竞品价格区间与竞品 Listing 表现（简报禁止编造竞品价格）
- 达人库与佣金行情
- 行业平均转化率/CTR 基准（用于设定目标基线）
- 跨境物流成本与关税（用于定价）

### 数据差异说明

- `product_release_notes.md` 内容为"星河笔记 2.3"（一款 Markdown 笔记软件）的发布说明，包含批量导入、标签筛选、快捷键面板、macOS/Windows 兼容性等信息，与智能随行杯产品无关联。本方案未采用该文件内容；若该文件为误传，请业务方确认是否应提供智能随行杯的发布说明。
