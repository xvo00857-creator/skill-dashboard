## 三、音色编制

1. **电钢琴（Rhodes 类）**：主奏乐器，温暖中频，演奏核心五音动机，是品牌记忆的主要载体。
2. **合成器 pad**：柔和长音铺底，提供空间感与城市氛围，不抢主旋律。
3. **手指响指 + 沙锤**：轻打击乐，建立都市律动感，音量控制在不干扰人声的程度。
4. **电贝斯**：温暖低音，支撑和声根基，低频不过量以兼顾手机扬声器。
5. **马林巴/钟琴**：末尾标识音，清脆明亮，与电钢琴形成音色对比，形成记忆点。

混音取向：温暖通透，中频饱满，低频克制，兼顾手机扬声器与耳机回放。

## 五、约束导致的方案变化说明

本次在基础任务之上新增了三项约束，对应方案调整如下：

### 1. 手机端可读
- **变化**：除 WAV 母带外，额外提供 AAC/m4a 版本。AAC 在 iOS、Android 及所有现代浏览器中原生支持，压缩效率高于 MP3，8 秒仅 120 KB。
- **未提供 MP3 的原因**：当前系统（macOS）的 Core Audio 框架仅含 MP3 解码器、不含编码器，且无 ffmpeg/lame 可用；AAC 是手机端等效甚至更优的分发格式。
- 混音时刻意控制低频量，避免手机小扬声器糊音。

### 2. 可编辑
- **变化**：保留未压缩 WAV 作为编辑母带（40 kHz/16 bit PCM），可直接导入 Audacity、Adobe Audition、剪映等软件剪辑。
- 本文档同时记录了完整生成提示词（见第六节），可据此重新生成或微调（如改速度、换音色、改时长），实现"参数级可编辑"。
- 短版与主版共享同一动机，可在剪辑中交叉使用。

### 3. 中文信息不丢失
- **变化**：所有文件元信息、HTML 页面（`lang="zh-CN"`、`charset="utf-8"`）、说明文档均使用中文并以 UTF-8 编码保存。
- 文件名使用英文短横线命名以保证跨系统兼容性，但文件内中文内容完整保留。
- 听感描述以中文文本形式写入 HTML，不依赖图片或音频传递关键信息。

### 4. 无障碍 / 低性能设备兼容方案
- **单声道低码率版**：60 kbps 单声道 AAC，8 秒仅 63 KB，适合低端机型、弱网环境和单声道手机扬声器，避免立体声反相导致的漏音。
- **HTML 无障碍**：
  - 所有播放器有中文 `aria-label` / `<label>`；
  - 交互控件可键盘 Tab 聚焦、回车/空格操作，焦点有可见轮廓；
  - 提供文字听感描述，供听障读者或无法播放时参考；
  - 波形装饰动画在系统开启"减弱动态效果"（`prefers-reduced-motion`）时自动停止；
  - 页面响应式布局，适配窄屏手机。

```
4秒城市生活播客短标识音，纯音乐无人声。风格：温暖都市轻爵士，亲切明亮。
```

### 常见微调方向

- 换速度：将"105 拍每分钟"改为 92（更慵懒）或 120（更明快）。
- 换调性：将"C 大调"改为"G 大调"（更明亮）或"A 小调"（更沉静）。
- 换主奏乐器：将"电钢琴"替换为"木吉他""尤克里里""手风琴"等。
- 加人声哼唱：将"纯音乐无人声"改为"轻柔的无词人声哼唱"。
- 改时长：修改开头秒数并相应调整结构描述。
