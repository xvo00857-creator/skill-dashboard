# Ahrefs 受约束批量自动化 — 流程说明与演示结果

## 一、Skill 能力边界（以 SKILL.md 为准）

本流程严格依据随附的 `ahrefs-automation/SKILL.md` 实现。该 Skill 的真实能力是：
通过 Composio 提供的 **rube MCP 服务器**（`https://rube.app/mcp`）调用 Ahrefs API，
完成站点指标查询、历史指标追踪、反链分析、关键词研究、自然关键词审计、批量 URL 分析等 SEO 任务。

**关键前置条件（SKILL.md Setup 节）：**
1. 必须在配置中添加 rube MCP 服务器；
2. 必须连接 Ahrefs 账号（OAuth 认证）；
3. 多数工具需要 `target`、`country`（ISO 3166-1 alpha-2），部分需要 `date`（YYYY-MM-DD）。

**本环境实际状态（已核验）：**
- 执行 `claude mcp list` 返回 `No MCP servers configured.`，rube MCP **未配置**；
- 无 Ahrefs 账号连接；
- 因此本次**无法发起任何真实 Ahrefs API 调用**，也不会编造任何 SEO 数据。

## 二、受约束的流程设计

### 1. 预检（Pre-checks）
| 序号 | 检查项 | 失败处理 |
|------|--------|----------|
| 1 | rube MCP 服务器是否已配置（`claude mcp list`） | live 模式直接阻断；dry-run 仅告警 |
| 2 | 任务配置结构与参数合法性（工具名、必填参数、日期格式、国家码、枚举值、target 格式） | 阻断并列出全部错误 |
| 3 | 批量目标数 ≤ 100（SKILL.md 硬限制） | 超过则自动按 100 分块 |
| 4 | select 中是否含高消耗列（traffic、difficulty 等） | 告警并在 live 模式要求人工确认 |

额外拦截：SKILL.md 明确 `offset` 参数已于 2024-05-31 废弃，脚本检测到即报错。

### 2. 幂等（Idempotency）
- 运行目录由任务配置内容的 SHA-256 哈希前 16 位决定：`ahrefs_runs/<run_id>/`；
- 相同输入复用同一目录，**不覆盖**已有成功结果；
- 每批结果独立保存为 `batch_NNNN_result.json`，重跑时已成功的批次自动跳过。

### 3. 重试（Retry）
- 指数退避：1s → 2s → 4s，最多重试 3 次；
- 仅对可重试错误重试：HTTP 429 / 5xx / 超时 / 连接错误；
- 4xx 参数错误、认证失败等不可重试错误立即失败，不浪费配额。

### 4. 人工确认点（Human-in-the-loop）
- 默认 **dry-run** 模式，不调用任何外部 API；
- live 模式执行前需确认：① 高消耗列告警；② 即将发起真实调用；
- `--yes` 可跳过确认（用于 CI），但预检阻断不可绕过；
- MCP 未配置或未认证时，即使 `--yes` 也会被阻断。

### 5. 批处理与可恢复
- `AHREFS_BATCH_URL_ANALYSIS` 单次最多 100 个 target，超出自动分块；
- 其他工具传入多 target 时逐个作为单目标调用；
- `checkpoint.json` 原子写入（临时文件 + rename），记录每批状态；
- 中断后 `--resume` 续跑，已成功批次幂等跳过。

select 含 `domain_rating, backlinks, refdomains, org_traffic`，国家 us。

## 六、实际影响交付结果的 SKILL.md 规则（至少一条）

1. **Setup 前置条件规则**（第 19-24 行）：必须先添加 rube MCP 并连接 Ahrefs 账号。
   这条规则直接决定了本次交付只能是 dry-run 演示——脚本在预检中检测到 MCP 未配置，
   live 模式被阻断（退出码 3），且全程未编造任何 API 返回数据。

2. **批量上限 100**（第 149 行）：脚本据此实现自动分块逻辑。

3. **select 必填与高消耗列告警**（第 146、148 行）：预检校验 select 非空，并对
   `traffic`/`difficulty` 等列触发人工确认。

4. **offset 已废弃**（第 151 行）：脚本检测到 offset 参数直接报错，引导改用 limit/游标分页。
