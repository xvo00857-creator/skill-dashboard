## 一、约束条件、优先级与取舍

### 1.1 约束条件
- **时间/资源受限**：本轮不针对某一真实在售型号做外部调研与参数核验。
- **产品信息缺失**：需求仅给出"便携咖啡机"品类，未提供品牌、型号、价格、具体卖点、目标平台、认证资质。
- **Skill 能力边界**：ecommerce-copywriter 为纯文本文案技能，不生成图片，仅输出 Markdown 文案（图片位以占位符表示）。

### 1.2 优先级排序（高→低）
1. **合规与真实**：不虚构参数、不使用绝对化用语、不写医疗功效——Skill 注意事项中的硬性要求。
2. **结构完整可用**：覆盖短标题、主图文案、详情页四段式正文、多版位文案表，拿到即可填参上线。
3. **卖点框架准确**：基于便携咖啡机品类的通用卖点搭建框架，具体数值留空待确认。
4. **风格与 emoji 规范**：符合 Skill 标题格式、四段式结构、emoji 10%-20% 及位置要求。

### 1.3 取舍说明
- **取舍 1**：不编造"15Bar 压力""30 秒萃取""一次充电做 50 杯"等吸睛但无法核实的数字，改为定性描述 +【待确认】占位。代价是文案冲击力略降；收益是零合规风险。
- **取舍 2**：不调用生图模型。原因：本任务交付物是"文案"而非商品图，Skill 本身无生图能力，主图文案指主图上的文字内容；若需主图视觉稿可另行生成。
- **取舍 3**：模板选择"数码配件类"为主（取其便携性/功能性结构），不强行套用"食品饮料类"（该类模板面向食品本身而非器具）。
- **取舍 4**：多版位文案表以 Markdown 表格交付，与 Skill 原生 Markdown 输出格式一致，便于直接复制到各版位。

### 1.4 验收标准
- [x] 标题含 emoji、产品昵称、核心卖点，10-20 字，格式 `**emoji 昵称：卖点**`
- [x] 详情页正文为四段式：痛点→产品介绍→2-3 个卖点→情感升华
- [x] emoji 与内容相关、位置合理（标题/段首/卖点处）、无堆砌
- [x] 无"最好/第一/100%/保证"等绝对化用语，无医疗功效暗示
- [x] 所有不可验证的产品事实均标注【待确认】
- [x] 覆盖短标题、主图、详情页、多版位文案表

## 三、模板选择

**选用模板：数码配件类**（references/copywriting_templates.md）

选择理由：
- 该类核心卖点为"功能性、便携性、高效性"，与便携咖啡机的"便携+一键萃取"高度吻合；
- 目标用户含"上班族、经常外出的人"，与便携咖啡机主力人群一致；
- 痛点"携带不便、功能单一"可直接迁移为"想喝好咖啡但身边没有趁手设备"；
- 情感诉求"随时随地、解决问题"与产品场景匹配。

## 五、待确认项清单（上线前必须核实）

以下信息无法在本轮验证，文案中已用【待确认】标注，**严禁带标记直接投放**：

1. 品牌名称、产品型号、注册商标
2. 价格与促销机制、活动时间
3. 充电方式（USB-C / 车载 / 磁吸等）与一次充电可萃取杯数
4. 额定萃取压力（Bar 数）、萃取时长、水温加热能力
5. 兼容类型：仅咖啡粉 / 仅胶囊 / 两者兼容；胶囊规格（Nespresso、多趣酷思等）
6. 水箱容量、整机重量与尺寸
7. 机身材质（是否食品接触级、是否 304 不锈钢、是否 BPA-Free）及相关认证
8. 是否带加热功能、电池容量与额定功率
9. 颜色 SKU、包装清单、保修政策
10. 目标电商平台（淘宝/京东/抖音/小红书等）及其标题字数、违禁词规则
11. 是否有第三方检测报告、专利、销量/评价数据等可用于背书的真实素材
