# 二维角色绑定工程 · 关键参数说明

角色名：**小克**　|　绑定类型：`svg_rig`　|　坐标系：`viewBox="0 0 400 500"`（SVG 原生坐标，单位与原画一致）

---

## 一、文件清单

| 文件 | 作用 | 可编辑性 |
|---|---|---|
| `index.html` | **自包含运行时**：内嵌 SVG 原画 + 绑定数据包 + 通用渲染引擎。手机浏览器直接打开即可播放。 | 用任意文本编辑器打开，可改数据、SVG、样式 |
| `rig_plan.json` | 独立绑定数据包（与 `index.html` 内嵌数据一致），便于在外部工具中复用或版本对比 | 纯文本 JSON |
| `character.svg` | 独立角色原画文件，每个可动部件为独立 `<g id="…">`，按 layer 从后到前排列 | 矢量编辑器 / 文本编辑器 |
| `关键参数说明.md` | 本说明文档 | 纯文本 |

> 运行时遵循 Skill 的核心原则：**运行时代码通用，角色本身是数据包**。`index.html` 中的引擎不包含任何写死的角色坐标，所有部件、枢轴、约束、动画轨道均来自 `<script type="application/json" id="rig-data">`。

## 二、绑定结构参数

### 1. 部件表 `parts`

共 13 个部件，每个部件有 `id / kind / layer / parent`：

| id | kind | layer | parent | 说明 |
|---|---|---|---|---|
| `leg_right` | limb | 5 | body | 右腿（身后） |
| `arm_right` | limb | 8 | body | 右臂（身后） |
| `body` | torso | 10 | — | 身体（根部件） |
| `leg_left` | limb | 12 | body | 左腿（身前） |
| `arm_left` | limb | 15 | body | 左臂（身前） |
| `ear_left` | ear | 25 | head | 左耳（随头） |
| `ear_right` | ear | 25 | head | 右耳（随头） |
| `head` | head | 30 | body | 头部 |
| `cheek_left` | detail | 34 | head | 左腮红 |
| `cheek_right` | detail | 34 | head | 右腮红 |
| `eye_left` | eye | 35 | head | 左眼（含眼白+瞳孔+高光，可整体缩放做眨眼） |
| `eye_right` | eye | 35 | head | 右眼 |
| `mouth` | mouth | 37 | head | 嘴巴 |

- **层级显式**：layer 数字越小越靠后。SVG 中元素按此顺序排列，不依赖生成后的源顺序（遵循 Skill "Keep layer order explicit"）。
- **父子关系**：头、四肢挂在 body 下；五官、耳朵挂在 head 下。运行时沿父级链组合世界变换。
- 眼睛按 Skill 质量清单拆为独立部件（瞳孔是眼组内子元素，如需视线变化可进一步拆为独立 part）；嘴巴为独立 path 组。

### 2. 关节与枢轴 `joints`

枢轴坐标全部在 SVG `0 0 400 500` 坐标系内定义（遵循 Skill "Define pivots in the same coordinate space as the artwork"）：

| 关节 | pivot [x, y] | 旋转约束 [min, max] | 位置说明 |
|---|---|---|---|
| `head` | [200, 232] | [-15°, 15°] | 头颈连接处 |
| `arm_left` | [150, 252] | [-45°, 45°] | 左肩 |
| `arm_right` | [250, 252] | [-45°, 45°] | 右肩 |
| `leg_left` | [180, 365] | [-30°, 30°] | 左髋 |
| `leg_right` | [220, 365] | [-30°, 30°] | 右髋 |

- **旋转约束**：运行时每帧对旋转结果做 `clamp`，防止手臂反转、腿部劈叉等不可能姿态（遵循 Skill "Store constraints on moving parts to prevent impossible rotations"）。
- 耳朵、腮红、嘴巴无独立运动，不设关节，仅继承父级变换。

## 三、动画参数

引擎为**帧驱动、确定性**：同一 (动画, 帧号, 低性能开关) 永远产出同一姿态（遵循 Skill 引用的 Remotion 原则 "frame-driven and deterministic via current frame"）。不依赖墙钟时间做姿态计算，速度只改变帧推进速率。

### 1. 轨道类型

| 类型 | 参数 | 公式 |
|---|---|---|
| `sine`（正弦循环） | amplitude, period_frames, phase_frames, offset | `offset + A·sin(2π·(frame+phase)/period)` |
| `keyframe`（关键帧） | keyframes[{frame, value}] | 线性插值，自动首尾钳制 |

支持属性：`translateX / translateY / rotation / scaleX / scaleY`。

### 2. 待机动（idle）

- 帧率 30fps，时长 120 帧（4 秒），循环。
- 身体呼吸：translateY 振幅 3px，周期 120 帧。
- 头部微摆：rotation 振幅 3°，周期 180 帧（标记 secondary）。
- 双臂轻晃：rotation 振幅 4°，周期 150 帧，左右反相（secondary）。
- 眨眼：scaleY 关键帧，在第 35 帧和第 95 帧快速闭合到 0.1 并在 3 帧内睁开（secondary）。

### 3. 行走动（walk）

- 帧率 30fps，时长 60 帧（2 秒/步循环），循环。
- 双腿：rotation 振幅 25°，周期 60 帧，左右腿相差 30 帧（反相）。
- 双臂：rotation 振幅 22°，周期 60 帧，左臂与右腿同相、右臂与左腿同相（对角摆动）。
- 身体起伏：translateY 振幅 4px、offset -4px，周期 30 帧（每步两次起伏）。
- 头部轻点：rotation 振幅 3°，周期 60 帧，相位 45（secondary）。
- 行走时不眨眼（scaleY 恒为 1）。

## 四、约束导致的方案变化

本次新增四项限制，相对"默认桌面端方案"的调整如下：

### 1. 手机端可读
- **viewport meta** + 响应式布局：SVG 宽度 `max-width:380px; width:100%`，在小屏上等比缩放不变形。
- 控制面板 `flex-wrap` 自适应换行，按钮 `min-height:44px` 符合触摸目标尺寸。
- 中文优先字体栈（PingFang SC / 微软雅黑 / Noto Sans CJK SC）。

### 2. 可编辑
- 交付**纯文本三件套**（HTML/JSON/SVG），手机上任意文本编辑器或在线代码工具均可改。
- 绑定数据放在 `index.html` 中独立的 `<script type="application/json" id="rig-data">` 块，与引擎代码分离；改角度、振幅、枢轴无需碰 JS 逻辑。
- SVG 原画内嵌且元素 id 与数据包一一对应，改颜色/形状后动画自动生效。
- 提供**逐帧滑块**和上一帧/下一帧按钮，可拖动查看任意帧姿态，便于调参。

### 3. 中文信息不丢失
- 全部文件以 **UTF-8** 保存（`charset="UTF-8"`、XML 声明 `encoding="UTF-8"`）。
- UI、注释、文档、动画名（`name_cn`）均为中文；角色名"小克"等中文直接写在数据中，无转义丢失风险。
- 未使用任何会剥离中文的压缩/二进制格式。

### 4. 无障碍 / 低性能设备兼容（提供两种方案）

**方案 A：系统级"减弱动态效果"（无障碍）**
- 通过 `prefers-reduced-motion: reduce` 媒体查询检测；若用户系统开启了减弱动效，自动停止播放、显示静态姿势，并展示中文提示。
- 仍可通过逐帧按钮/滑块手动查看，保障内容可访问。

**方案 B：低性能模式（设备兼容）**
- 一键切换，帧率上限从 30fps 降到 **12fps**，降低 CPU/GPU 占用。
- 跳过所有标记 `"secondary": true` 的轨道（眨眼、头部微摆、手臂轻晃），只保留身体起伏与四肢摆动等主动画，减少每帧计算量与重绘面积。
- 无任何外部依赖（不依赖 GSAP/CDN），离线可用、加载体积小，适合低端机。

### 5. 其他由 Skill 规则决定的选择
- 未采用 AI 位图生成角色：因为绑定要求部件独立变换、枢轴在原画坐标系精确定义，矢量 SVG 是唯一能满足"可编辑 + 精确枢轴"的形式。
- 未使用 CSS `transform-origin`：其行为在浏览器间对 SVG 坐标空间敏感（Skill Sources 明确提示），改为在 SVG `transform` 属性中用**显式坐标** `rotate(angle, px, py)`，等价于 GSAP `svgOrigin` 的确定性做法，但零依赖。
- 单视图：按 Skill "Start with one view"，只做正面视图，未增加多余视图。

## 五、验证方法与证据

1. **打开工程**：用浏览器（手机或桌面）直接打开 `index.html`，无需服务器、无需联网。
2. **循环验证**：点"行走"，观察双腿/双臂反相摆动、身体上下起伏，60 帧无缝循环；点"待机"观察呼吸与眨眼。
3. **帧确定性**：拖动帧滑块到任意帧再拖回，姿态完全一致；同一帧号在任意速度下姿态相同（速度只影响推进快慢）。
4. **约束验证**：将 `rig-data` 中 walk 的 leg amplitude 改为 90，运行时腿部仍被夹在 ±30°，不会反转。
5. **手机端**：Chrome DevTools 设备模拟或手机实机打开，布局自适应、无横向滚动、按钮可触摸。
6. **低性能模式**：点"低性能模式"，信息栏显示"≤12（低性能）"，眨眼停止、四肢摆动保留。
7. **减弱动效**：在系统辅助功能中开启"减弱动态效果"后刷新页面，自动静态并显示提示。
8. **中文**：页面标题、按钮、提示、角色名均正常显示中文，无乱码。
9. **键盘无障碍**：Tab 可聚焦所有按钮；空格暂停/播放，方向键逐帧，1/2 切换动画；按钮有 `aria-pressed` / `aria-label`，焦点有可见轮廓。
