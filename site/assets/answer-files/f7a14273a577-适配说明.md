# 30秒竖屏版 · 适配说明

## 一、改版目标

将原主题（"如果AI真的会改变未来，普通人到底该怎么参与？"）改编为30秒竖屏短视频，适配手机端信息流场景，满足以下硬性要求：

- **画幅**：9:16 竖屏（1080×1920），适配抖音/视频号/小红书等平台
- **前2秒钩子**：用提问式标题+警示色调建立信息钩子
- **静音可懂**：全程烧录硬字幕，顶部加标题/标签，不依赖声音
- **版权合规**：不使用未授权音乐（全片无人声以外的音乐），不使用真实人物素材（全部为AI生成插画）

## 二、与原主题的关系

原主题为开放式提问"如果AI真的会改变未来，普通人到底该怎么参与？"。30秒竖屏版将其浓缩为：

- **核心观点**：AI不会取代人，但会用AI的人会取代不会用的人
- **行动建议**：三个具体可执行的机会（用工具、练内功、动手试）
- **金句收尾**：未来不属于AI，属于会驾驭AI的人

文案约130字，按自然语速（约4.3字/秒）恰好30秒。

## 三、制作流程

1. **脚本撰写**：按信息钩子→观点反转→三条建议→金句收束的结构撰写，文案按语义短语分组（遵循 doubao-tts SKILL.md 第6条）。
2. **配音生成**：生成30秒中文女声解说，语速自然。
3. **画面生成**：使用 Seedream 5.0 Pro 生成5张9:16科技风插画，统一深蓝主色调，无真实人物、无文字。
4. **视频合成**：使用 moviepy 将画面（带Ken Burns推拉）、配音、硬字幕、顶部标题/标签、底部渐变遮罩合成为MP4。

## 五、字幕策略

- 每条字幕按中文语义短语切分，不按固定字数截断（如"把AI当工具"不拆为"把AI当工/具"）
- 长句拆为两条字幕依次出现（如"真正的问题不是AI取代你，/而是会用AI的人，取代不会用的人。"）
- 字号50–58px，底部距屏幕边缘100px，确保不被平台UI遮挡
- 底部加黑色渐变遮罩，保证任何画面上字幕均清晰可读

## 六、关于 doubao-tts Skill 的执行说明

### 实际读取的 Skill 文件

- `doubao-tts/SKILL.md`（唯一文件，ZIP包内仅含此文件）

### 影响交付结果的 SKILL.md 规则

1. **第6条（语义短语分组字幕）**：直接决定了字幕切分方式。脚本中的12条字幕均按语义短语分组，而非按固定字数截断。例如"第二，深耕AI做不到的事——"和"创造力、共情和复杂判断；"分为两条，保证"深耕AI做不到的事"这一完整词组不被拆开。

2. **第7条（时长服从配音节奏）**：SKILL.md规定"Let the video duration follow the approved voice rhythm unless the user explicitly asks to match a prior runtime"。用户明确要求30秒，因此以30秒为硬约束，文案字数按自然语速反推（约130字），配音生成结果恰好30.00秒。

3. **第86行（语速建议）**："For calm Mandarin explainers, start with speech_rate: 0"——配音采用自然语速，未加速。
