## 二、Skill 方法论应用：独立工作域识别

依据 `dispatching-parallel-agents/SKILL.md` 的核心原则——"每个独立问题域派发一个专注任务，可并行的并行执行"——将上线准备工作拆分为以下工作域：

| 工作域 | 是否独立 | 可否立即并行 | 依赖/阻塞 |
|---|---|---|---|
| A. 内容文案 | 独立 | ✅ 可立即启动 | 仅依赖已确认卖点与素材 |
| B. 视觉设计 | 独立 | ✅ 可立即启动 | 依赖白底图（已有）、品牌主色（已有） |
| C. 合规资质 | 独立但受阻 | ⛔ 阻塞 | 依赖 U2 防水等级、U3 食品接触材料报告 |
| D. 渠道运营准备 | 部分独立 | ⚠️ 部分可启动 | 依赖 U1 首发日期、U4 渠道确认 |
| E. 项目集成与评审 | 协调角色 | 贯穿全程 | 依赖 A-D 产出 |

**Skill 规则应用说明**：
- A 与 B 无共享状态、无相互依赖，符合 Skill 的"Can they work in parallel? yes"条件，第 1 周即并行启动。
- C 因关键输入缺失（检测报告），符合 Skill 的"Don't use when: Need full context"——在报告到位前不展开实质工作，仅做跟进清单。
- D 中不依赖首发日期的部分（店铺基础搭建、SKU 信息录入）可先行，依赖日期的部分（排期、投放）标记为待补。
- E 对应 Skill 第 4 步"Review and Integrate"，设两个检查点：Day 5 中期评审、Day 10 终审集成。

## 四、各工作域任务定义（遵循 Skill 的 Focused / Self-contained / Specific output 原则）

### A. 内容文案

- **范围**：商品详情页文案、社媒推广文案（小红书/微信/抖音至少 1 个平台）、产品包装文案
- **目标**：产出可直接用于上架的中文文案，突出 12h 保温、280g 轻量、可拆洗杯盖三大卖点
- **约束**：
  - 不得出现第三方检测结论、销量数据、用户评价、竞品价格
  - 不得声称防水等级（U2 待补）
  - 不得声称食品接触材料合规结论（U3 待补）
  - 品牌主色 #176B87 可在文案中以设计标注引用
- **预期产出**：详情页文案 v1（D5）/ 终稿（D8）；社媒文案 3-5 条（D5）
- **负责人角色**：内容策划

### B. 视觉设计

- **范围**：详情页视觉设计（主图+内页模块）、社媒配图、商品主图（白底图已有，需延展场景图）
- **目标**：基于已有白底图和品牌主色产出全套上线视觉素材
- **约束**：
  - 主色 #176B87；不得在图中伪造检测认证标志、销量徽章、评价截图
  - 场景图不得暗示未确认的功能（如防水浸泡场景）
  - 图片尺寸按目标渠道规范（渠道确认后输出对应规格）
- **预期产出**：详情页设计稿 v1（D5）/ 终稿切图（D7）；社媒配图（D5）
- **负责人角色**：视觉设计师

### C. 合规资质

- **范围**：食品接触材料报告审核、防水等级确认、详情页资质展示合规性
- **目标**：在报告到位后 2 个工作日内完成合规审核，出具通过/不通过结论
- **约束**：
  - 报告未到位前**不得开展任何合规声明撰写**，不得用假设材质替代
  - 仅依据真实检测报告下结论
- **预期产出**：合规审核结论单（报告到位后 D+2）；资质文件包
- **负责人角色**：合规/法务
- **⛔ 当前状态：阻塞。停止于"等待防水等级与食品接触材料报告提供"这一步。**

### D. 渠道运营准备

- **范围**：店铺搭建、商品上架、价格库存设置、下单流程验证
- **目标**：完成商品在首发渠道的上架准备，待合规通过后可立即上线
- **约束**：
  - 价格 199 元已确认；首发日期、渠道未确认前不得设定实际上线时间
  - 详情页上架必须在 C 合规通过之后
- **预期产出**：店铺商品草稿（D5）；上架就绪状态（D8，待合规通过）
- **负责人角色**：电商运营

### E. 项目集成与评审

- **范围**：跨工作域协调、中期评审、终审集成、验收
- **目标**：确保各域产出无冲突、合规无遗漏、交付物完整
- **约束**：对应 Skill 第 4 步——必须逐份审阅各域产出、检查冲突、全链路走查
- **预期产出**：中期评审纪要（D5）；终审交付清单（D10）
- **负责人角色**：项目经理

## 六、验收标准

| 域 | 验收标准 |
|---|---|
| A 内容文案 | ① 三大卖点均有对应文案；② 全文无第三方检测结论/销量/评价/竞品价格；③ 无防水等级声称、无食品接触合规声称（报告到位前）；④ 中文无错别字；⑤ 结论与假设标注清晰 |
| B 视觉设计 | ① 主色 #176B87 统一；② 无伪造认证标志/销量/评价元素；③ 详情页切图符合目标渠道尺寸规范；④ 场景图不暗示未确认功能 |
| C 合规资质 | ① 食品接触材料报告已审核并出具结论；② 防水等级已确认；③ 详情页资质展示与报告一致；④ 报告未到位则本项不通过，整体不得上线 |
| D 渠道运营 | ① 商品信息（价格 199 元、已知规格）录入准确；② 下单流程自测通过；③ 详情页版本为合规通过版本；④ 上线时间与首发日期一致 |
| E 集成 | ① A+B 文案与设计无矛盾；② C 合规结论覆盖所有对外声称；③ D 上架物料为最终版本；④ 交付清单逐项签字确认 |

## 八、关于未实际派发并行 Agent 的说明

Skill `dispatching-parallel-agents` 的适用前提是"面对 2 个以上可独立、无共享状态、可并行的任务"。本次任务为**编制方案**本身，而非执行上线工作：

1. 方案编制需要全局视角与跨域一致性，属于 Skill 中"When NOT to Use: Need full context"的情形；
2. 关键输入缺失（U1/U2/U3），属于 Skill 中"Exploratory"阶段——尚未具备并行执行的条件；
3. 用户明确要求"不得把计划、示例或模拟结果写成已执行"，因此未实际派发 Agent 执行内容/设计/合规工作；
4. 方案中 A、B 两域已按 Skill 模式设计为**执行阶段可立即并行**的任务结构，待阻塞项解除后即可按 Skill 第 3 步同步派发。

当前停止位置：**方案编制完成，执行阶段尚未启动**。阻塞于 U2（防水等级）、U3（食品接触材料报告）两项输入缺失，对应停止条件 S1/S2。
