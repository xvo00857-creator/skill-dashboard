AI Agent 新手训练营内部方案 v0.1

通过澄清问题、明确假设和分阶段共创，形成可继续迭代的内部训练营方案。

一、5 个关键澄清问题

#问题为什么重要
1目标受众是谁？全员 / 产品经理 / 工程师 / 运营 / 新入职员工 / 特定业务线？决定课程深度、案例选择和入门门槛
2核心目标是什么？普及认知 / 提升日常生产力 / 培养内部 Agent 专家 / 推动业务场景落地？决定课程是“宽而浅”还是“窄而深”
3训练营形式与周期？线上 / 线下、持续几周、每周频次、是否有实战项目？决定运营节奏和资源投入
4预算与资源约束？内部讲师 vs 外部、是否采购平台 / 工具、是否设激励奖金？决定方案可行性和落地难度
5成功衡量标准？完课率 / NPS 满意度 / 实战产出物数量 / 业务指标提升？决定复盘口径和向上汇报逻辑

二、基于明确假设的首版方案

假设声明
受众为公司全员（侧重产品 / 运营 / 研发）；目标为“从认知到实战”的能力提升；采用 4 周线上轻量训练营、内部讲师制，以完课率和实战产出为核心指标。所有假设项均需后续确认。

  • 01 项目背景与目标为什么做、要达成什么

  • 05 师资与资源讲师、平台、内容
