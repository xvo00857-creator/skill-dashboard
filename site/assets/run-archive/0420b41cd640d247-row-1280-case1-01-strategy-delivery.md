## 2. 受众定义

### 2.1 核心受众

- **人群**：一二线城市通勤人群。
- **典型场景**：每日地铁/公交通勤、办公室久坐、差旅短途。
- **核心痛点映射**：
  - 通勤途中饮品易凉 → 12 小时保温。
  - 包内负重敏感 → 280g 轻量化。
  - 杯盖缝隙难清洗、易滋生异味 → 可拆洗杯盖。

| 轻量敏感型 | 背包重量敏感、健身/差旅人群 | 280g + 外观 |

## 7. Google Ads 渠道阻断说明（严格依据 SKILL.md）

### 7.1 阻断点

`google-ads-api-mcp-setup/SKILL.md` 在「⚠️ Prerequisites: Credentials Required」一节明确规定：

> If you do not have your Developer Token, Client ID, Client Secret, Refresh Token, and Customer IDs yet:
> 1. **STOP** executing this skill.
> 2. **Transition to** the **`google-ads-api-quickstart`** skill first to generate them, then return here.

当前环境中以上 5 项凭据均未提供，因此按 Skill 规则**在凭据前置检查处停止**，不进入 Step 1（凭据校验）及后续安装、配置、集成步骤。

### 7.2 已执行的检查

- 已读取 SKILL.md 全文，确认前置要求。
- 确认当前无 Google Ads 凭据输入。
- 未执行 `pipx install google-ads-mcp`、未配置环境变量、未集成任何 AI 客户端，避免在无凭据状态下产生无效配置。

### 7.3 解除阻断的方法

1. 先执行 `google-ads-api-quickstart` 流程，获取：
   - Developer Token
   - OAuth2 Client ID
   - OAuth2 Client Secret
   - OAuth2 Refresh Token
   - Client Customer ID（10 位数字，无连字符）
   - Login Customer ID（MCC 层级时必填，10 位数字，无连字符）
2. 凭据齐备后，回到本 Skill 继续 Step 1 及后续步骤。
3. 本方案中 Google Ads 渠道动作的上线时间，以凭据齐备且 MCP 集成验证通过为前置条件。
