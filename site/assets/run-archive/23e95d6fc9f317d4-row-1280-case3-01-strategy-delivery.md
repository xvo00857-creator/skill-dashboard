### 5.2 Google Ads 渠道 —— 阻断说明与降级方案

#### 阻断原因（有证据）

按 `google-ads-api-mcp-setup/SKILL.md` 规则执行前置检查，发现以下全部阻断项：

1. **凭据缺失（核心阻断）**：SKILL.md 明确要求 5 项凭据 —— Developer Token、OAuth Client ID、Client Secret、Refresh Token、Client Customer ID（及 MCC 层级的 Login Customer ID）。当前环境**一项都不具备**。
   - SKILL.md 原文规则：*"If you do not have your Developer Token, Client ID, Client Secret, Refresh Token, and Customer IDs yet: 1. STOP executing this skill. 2. Transition to the `google-ads-api-quickstart` skill first to generate them, then return here."*
   - **因此按规则必须停止，不得继续安装或调用 MCP 服务器。**

2. **环境不达标**：
   - Python 版本：`3.10.12`，SKILL.md 要求 `3.12+`，不满足
   - `pipx`：未安装
   - `google-ads-mcp`：未安装

3. **MCP 服务器只读限制**：即使凭据齐全、环境达标，SKILL.md 明确说明该服务器**严格只读**（*"The Google Ads MCP Server is currently strictly read-only. It cannot modify bids, pause campaigns, or create new advertising assets."*），无法通过它创建或修改广告系列。

#### 降级方案

Google Ads 渠道降级为**纯计划文档**，包含以下待执行内容（凭据就绪后可落地）：

- **广告系列结构**：
  - 搜索广告系列 1：品牌词（"智能随行杯""[品牌名] 保温杯"）
  - 搜索广告系列 2：通用词（"通勤保温杯""轻量保温杯""可拆洗保温杯"）
  - 展示广告系列：再营销 + 相似受众
- **GAQL 查询模板**（凭据就绪后通过 MCP `search` 工具执行，参数 `customer_id` 为 10 位纯数字、`query` 为 GAQL 语句）：
  ```sql
  SELECT campaign.id, campaign.name, campaign.status, metrics.impressions, metrics.clicks, metrics.cost, metrics.conversions
  FROM campaign
  WHERE campaign.status = 'ENABLED'
  ```
- **账户 ID 格式校验**：必须为 10 位纯数字，不含连字符（如 `1234567890`，不可写 `123-456-7890`）。

#### 复测方法

1. 获取 5 项凭据后，先执行 `google-ads-api-quickstart` 流程
2. 升级 Python 至 3.12+，安装 `pipx`：`sudo apt install pipx && pipx ensurepath`
3. 安装 MCP 服务器：`pipx install google-ads-mcp`
4. 验证：`google-ads-mcp --help`
5. 在 Antigravity CLI 中执行 `/mcp` 确认服务器活跃
6. 运行测试查询：`list_accessible_customers` → 确认账户可见 → 执行上述 GAQL 查询

### 9.2 确实影响结果的 SKILL.md 规则

**规则一：凭据前置检查与停止执行规则**
> SKILL.md 规定：若未具备 Developer Token、Client ID、Client Secret、Refresh Token、Customer IDs，必须停止执行本 Skill，转至 `google-ads-api-quickstart`。

**影响**：因当前环境无任何 Google Ads 凭据，本方案中 Google Ads 渠道无法实际安装 MCP 服务器、无法查询账户数据、无法执行任何 API 调用，被迫降级为纯计划文档。这直接决定了交付物的"策略完整但执行阻断"状态。

**规则二：MCP 服务器严格只读**
> SKILL.md 规定：服务器当前严格只读，不能修改出价、暂停广告系列或创建广告资产。

**影响**：即使凭据齐全，也无法通过该 MCP 服务器自动创建或管理广告系列，投放操作仍需手动完成。这修正了"通过 MCP 自动化投放"的预期，渠道动作中已相应调整。

**规则三：Python 3.12+ 与 pipx 强制前置**
> SKILL.md 规定：Python 3.12+ 和 pipx 为严格必需前置条件。

**影响**：当前环境 Python 3.10.12、pipx 未安装，即使凭据就绪也无法在本机直接安装运行，需升级环境或改用 Cloud Run 部署。
