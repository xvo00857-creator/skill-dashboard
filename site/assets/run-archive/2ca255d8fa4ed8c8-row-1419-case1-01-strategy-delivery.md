- **人群标签**：一二线城市通勤人群（来源：product_brief.md）
- **可推断的典型画像**（标注为假设，非用户调研结论）：

  - 对随身物品的重量与便携性敏感

> **假设声明**：以上画像为基于"通勤人群"标签的合理推演，**非用户调研或用户反馈**。若后续有真实用户数据，应替换此节。

- 办公场景白领（桌面常驻使用）

## 3. 信息结构

按"核心信息 → 支撑信息 → 行动引导"三层组织，对应 SKILL.md 的 Unit / Integration / E2E 分层思想：

### 3.1 第一层：核心信息（Unit 级——单条事实，独立成立）

每条信息均可独立验证，不依赖其他信息：

| 编号 | 信息点 | 来源 | 可验证性 |
|---|---|---|---|
| MSG-01 | 12 小时保温 | product_brief.md | A+H（参数可自动化核对，实际体验需人工） |
| MSG-02 | 重量 280g | product_brief.md | A（可称重验证） |
| MSG-03 | 可拆洗杯盖 | product_brief.md | A+H（结构可自动化检查，清洁体验需人工） |
| MSG-04 | 建议零售价 199 元 | product_brief.md | A |
| MSG-05 | 品牌主色 #176B87 | product_brief.md | A |

### 3.2 第二层：支撑信息（Integration 级——信息组合，形成卖点叙事）

将核心信息组合为面向通勤场景的卖点叙事：

- **轻量通勤**：280g 重量 + 通勤场景 → "随身无负担"
- **全天保温**：12 小时保温 + 通勤 + 办公 → "从早高峰到下班都有热饮"
- **易清洁**：可拆洗杯盖 + 日常使用 → "无清洁死角"

> **约束**：以上叙事仅使用已确认卖点的组合，不引入未确认参数（如防水、材质安全报告）。

### 3.3 第三层：行动引导（E2E 级——端到端转化路径）

- 详情页 / 落地页：核心信息 → 支撑叙事 → 价格 → 购买 CTA
- 社媒内容：场景化卖点 → 产品图 → 跳转链接
- 渠道客服话术：FAQ 基于已确认信息，未确认问题统一回复"以官方详情页为准"

### 4.4 渠道动作的"主回归 + 增量"原则

> **Skill 规则映射**：SKILL.md 规则"不要每个 PRD 都从零重建整套测试""必须同时维护主回归套件 + 版本增量套件"。

### 6.3 人工补测 / 人工验证清单

以下项无法通过数据或自动化完全覆盖，必须人工执行：

1. **视觉走查**：详情页、社媒素材的品牌一致性（主色 #176B87 使用、排版、质感）
2. **文案合规审核**：所有对外文案是否包含未确认参数（防水、材质安全）、绝对化用语
3. **场景化内容评审**：种草内容是否准确传达卖点且不夸大
4. **客服话术校准**：FAQ 中未确认问题的回复是否统一为"以官方详情页为准"
5. **实物体验验证**：保温时长、重量手感、杯盖拆洗便利性的内部体验（非第三方检测，不对外宣称）

## 7. 最小可验证版本（MVV）

> **Skill 规则映射**：SKILL.md 工作流强调"增量测试""优先复用既有主回归用例""仅新增 PRD 差异用例"。MVV 即只验证最核心、最依赖已确认素材的部分，不追求全渠道覆盖。

### 7.1 MVV 范围

**只做以下三件事**，其余渠道动作列为后续版本：

1. **电商详情页上线**（P0）：使用白底图 + 已确认参数 + 品牌主色，不含未确认信息
2. **品牌官网产品页上线**（P0）：同上
3. **基础搜索关键词覆盖**（P0）：品牌词 + 核心品类词

### 7.2 MVV 关键步骤

| 步骤 | 动作 | 产出 | 负责人角色 | 依赖 |
|---|---|---|---|---|
| S1 | 确认待补项状态（M-01/02/03） | 阻断项清单 | 产品 | 无 |
| S2 | 制作详情页初稿（仅用已确认素材） | 详情页设计稿 | 设计 | 白底图、基础规格 |
| S3 | 文案合规审核（§6.3 第 2 项） | 审核通过的文案 | 市场 / 法务 | S2 |
| S4 | 详情页 + 官网页上线（灰度或正式） | 可访问的页面 | 运营 | S3 |
| S5 | 搜索关键词配置 | 关键词覆盖报告 | 运营 | S4 |
| S6 | 上线后 7 天数据采集 | 数据基线报告 | 数据 | S4 |
| S7 | MVV 验收评审 | 验收结论（PASS / FAIL） | 产品 + 市场 | S6 |

### 7.3 MVV 验收标准（完成门槛）

> **Skill 规则映射**：SKILL.md TEST_PLAN 模板第 2 节"完成门槛"：计划内用例全部通过、P0 通过率 100%、连续两轮稳定通过、无阻断/严重缺陷遗留。

| 编号 | 验收项 | 通过标准 | 优先级 |
|---|---|---|---|
| AC-01 | 详情页可正常访问 | 页面加载正常，无破损图片 / 错位 | P0 |
| AC-02 | 详情页信息准确性 | 所有参数与 product_brief.md 已确认信息一致；无未确认参数（防水等级、材质安全报告） | P0 |
| AC-03 | 品牌主色使用 | #176B87 按设计规范使用，无明显偏色 | P0 |
| AC-04 | 文案合规 | 无绝对化用语（最、第一）；无虚构第三方检测结论；无虚构销量 / 用户评价 | P0 |
| AC-05 | 官网产品页同步 | 与详情页信息一致，可正常访问 | P0 |
| AC-06 | 搜索关键词可检索 | 品牌词 + 至少 3 个核心品类词可搜到产品 | P0 |
| AC-07 | 数据采集就绪 | 上线后 7 天 UV / 转化率 / 加购率可正常统计 | P1 |
| AC-08 | 人工视觉走查通过 | §6.3 第 1 项完成且无严重问题 | P1 |

**MVV 通过条件**：
1. P0 验收项（AC-01 至 AC-06）全部通过（100%）
2. 无阻断 / 严重缺陷遗留（R-01 / R-02 在对外宣称中已规避）
3. 连续两轮稳定：上线后 48 小时内无页面故障 / 信息错误回滚
