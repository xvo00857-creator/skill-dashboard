## 一、执行摘要

本方案覆盖两款待推广产品：

| 产品 | 类型 | 核心信息 | 定价 |
|---|---|---|---|
| 智能随行杯 | 消费硬件 | 12 小时保温 / 280g / 可拆洗杯盖 | 建议零售价 199 元 |
| 星河笔记 2.3 | 桌面效率软件 | 批量导入 Markdown / 标签筛选 / 快捷键面板 | 未提供（待补） |

两款产品分属硬件与软件赛道，受众重叠有限但均指向"一二线城市效率敏感型用户"。方案以**分渠道、分节奏、共享品牌资产**为总策略，在 Google Ads 渠道因凭据与环境缺失暂时阻断的情况下，优先推进可立即执行的内容与社媒渠道，并将 Google Ads 列为凭据就绪后的第二阶段动作。

**关键结论（基于已确认信息）：**
1. 智能随行杯应以"通勤场景下的轻量保温"为单一核心信息，避免在缺少防水等级与食品接触材料报告的情况下做安全/耐用延伸宣称。
2. 星河笔记 2.3 应以"批量导入 + 标签筛选"解决存量笔记迁移痛点，已知问题（>500 文件索引慢）需在信息中主动管理预期。
3. Google Ads 投放当前不可执行：缺少 5 项必要凭据且运行环境 Python 版本不达标，需先补齐后方可启动。

## 二、受众分析

### 2.1 智能随行杯

- **核心受众**：一二线城市通勤人群（product_brief 已确认）。
- **画像假设**（待验证，非结论）：25–40 岁，日均通勤 ≥30 分钟，关注饮品温度与随身重量，对杯具清洁卫生有要求。
- **决策驱动**：保温时长可信度、便携性（280g 为已确认硬指标）、清洗便利性（可拆洗杯盖为已确认硬指标）。
- **购买阻力**：199 元定价高于普通保温杯均价（竞品价格为禁止编造项，此处仅标注为待市场调研补全）；缺少食品接触材料报告可能影响安全敏感型用户决策。

### 2.2 星河笔记 2.3

- **核心受众**（基于功能推断，非结论）：已有 Markdown 笔记存量的知识工作者、开发者、学生；使用 macOS 13+ 或 Windows 11+。
- **决策驱动**：批量迁移效率、标签组织能力、快捷键操作流畅度。
- **购买阻力**：>500 文件时首次索引较慢（已知问题，已确认）；定价未提供（待补）。

### 2.3 受众重叠与差异

- **重叠点**：一二线城市、效率导向、对工具品质有要求。
- **差异点**：随行杯是"场景驱动的冲动/替换购买"，决策周期短；星河笔记是"功能驱动的工具替换"，决策周期长且依赖迁移成本评估。
- **策略含义**：两款产品不宜共用同一套转化路径，但可共享品牌曝光层（如同一品牌主页的交叉导流）。

### 4.2 Google Ads 渠道 — 阻断说明（依据 google-ads-api-mcp-setup SKILL.md）

本方案原计划通过 Google Ads MCP Server 实现广告活动数据的自然语言查询与监控，但按 SKILL.md 执行时遇到以下不可跳过的阻断：

1. **凭据缺失（SKILL.md Step 1 / Prerequisites 章节）**：SKILL.md 明确要求 5 项凭据——Developer Token、OAuth2 Client ID、Client Secret、Refresh Token、Client Customer ID（MCC 层级还需 Login Customer ID）。当前环境一项均不具备。SKILL.md 原文规定："If you do not have your Developer Token, Client ID, Client Secret, Refresh Token, and Customer IDs yet: 1. STOP executing this skill. 2. Transition to the google-ads-api-quickstart skill first to generate them, then return here." 因 `google-ads-api-quickstart` Skill 不在当前可用范围内，无法自动过渡。
2. **Python 版本不达标（SKILL.md Step 2）**：当前环境 Python 3.10.12，SKILL.md 严格要求 3.12+。SKILL.md 规定："If Python is missing/outdated: Stop and ask the user to upgrade Python to 3.12+ on their host machine."
3. **pipx 未安装（SKILL.md Step 2）**：当前环境无 pipx。虽可按 Linux 指令 `sudo apt install pipx && pipx ensurepath` 安装，但因前两项阻断已触发 STOP，安装无意义。
4. **无 Google Ads 账户与客户 ID**：无法执行任何真实查询或获取平台数据，亦不得编造。

**结论**：Google Ads 渠道的 MCP 接入与数据监控当前不可执行。需用户提供：(a) 5 项 Google Ads 凭据；(b) Python 3.12+ 运行环境；(c) 确认是否使用 MCC 层级。补齐后按 SKILL.md Step 3–7 依次执行安装、配置、集成与验证。

## 六、约束与冲突（至少两种）

### 约束一：Google Ads MCP 接入阻断（技术约束）

- **描述**：如 4.2 节详述，缺少 5 项 Google Ads 凭据、Python 版本不达标（3.10.12 < 3.12）、pipx 未安装。按 SKILL.md 规则必须 STOP，无法执行 Google Ads 渠道的数据查询与监控。
- **影响**：搜索广告渠道无法启动，错失"保温杯""Markdown 笔记软件"等搜索意图流量；效果广告的数据驱动优化无法开展。
- **缓解**：优先推进内容种草与官网等不依赖 Google Ads 的渠道；将 Google Ads 列为第二阶段，凭据与环境就绪后按 SKILL.md 逐步接入。

### 约束二：产品信息不完整与禁止编造规则冲突（信息约束）

- **描述**：智能随行杯的首发日期、防水等级、食品接触材料报告均未提供；同时 product_brief 明确禁止编造第三方检测结论、销量、用户评价、竞品价格。这导致：
  - 无法确定上市排期（首发日期未定）
  - 无法做安全/防水延伸宣称（缺少报告 + 禁止编造）
  - 无法做竞品价格对比（禁止编造竞品价格）
- **影响**：信息面收窄，仅能围绕 3 项已确认硬指标（保温时长、重量、可拆洗）展开；排期无法锁定。
- **缓解**：上线前将材料报告与防水等级列为必须补齐项；首发日期确认后立即锁定排期；竞品调研以"待市场调研补全"标注，不使用具体数值。

### 约束三（附加）：两款产品资源分配冲突（资源约束）

- **描述**：智能随行杯（硬件，199 元，短决策周期）与星河笔记 2.3（软件，长决策周期，定价未定）分属不同赛道，若共享同一营销预算与团队，存在节奏与资源竞争。
- **影响**：硬件需要集中爆发式投放（上市窗口期），软件需要持续教育与迭代；同一团队难以同时维持两种节奏。
- **缓解**：采用"错峰发布"策略——先以星河笔记 2.3（已有明确版本号与功能，可立即上线）启动内容渠道积累品牌流量，待随行杯首发日期确认、材料报告补齐后再集中资源推硬件；两款产品共享品牌主页但独立运营内容线。
