## 二、约束与冲突（至少两项）

### 冲突一：输入文件产品错位——实体品与软件品混装

**现象**：`product_brief.md` 描述实体水杯，`product_release_notes.md` 描述桌面笔记软件。两者无品牌关联、无功能交叉、无共享受众证据。

**影响**：
- 无法用统一信息结构覆盖两产品；
- 渠道选择逻辑完全不同（水杯偏电商+内容种草，软件偏官网+开发者社区+应用商店）；
- 指标体系不可比（水杯看 GMV/转化率/退货率，软件看激活率/留存/付费转化）。

**取舍**：
- **决策**：拆分为两条独立上市线，共享品牌主色 #176B87 作为唯一视觉关联（若品牌归属一致，待确认）。
- **放弃**：不做联合 campaign、不做捆绑销售、不共享落地页。
- **依赖**：需产品方确认两产品是否属同一品牌主体；若否，则视觉关联也应解除。

### 冲突二：Google Ads 诊断工具与凭据缺失

**现象**：Skill `google-ads-api-account-diagnostics` 要求通过 MCP 服务器工具（`list_accessible_customers`、`search`、`get_resource_metadata`）执行 GAQL 查询来诊断账户表现。经检查，当前环境**未挂载该 MCP 工具集**，且无 Google Ads 客户 ID 与 OAuth 凭据。

**Skill 规则原文要点**：
> "If the customer ID is not explicitly provided by the user, you must first call the `list_accessible_customers` tool to retrieve the customer resource names/IDs."
> "you must call the `search` tool on the MCP server directly... Do not write or execute custom Python scripts or use the Google Ads client library to query the API, as they will fail authentication inside the evaluation sandbox."

**影响**：
- 无法执行转化流失诊断（Workflow 1）、展示份额机会诊断（Workflow 2）、低线索量诊断（Workflow 3）、离线上传管道诊断（Workflow 4）；
- 无法获取实际账户的 `metrics.conversions`、`metrics.search_impression_share`、`metrics.search_budget_lost_impression_share` 等数据；
- Google Ads 渠道的优化决策缺乏数据支撑。

**取舍**：
- **决策**：Google Ads 仍列为付费搜索渠道，但**仅输出诊断框架与待执行查询模板**，所有实际数据字段标注为「待补——需 MCP 工具 + 客户凭据」。
- **放弃**：不编造账户数据、不用 Python 脚本绕过认证（Skill 明确禁止）、不假设转化量或展示份额数值。
- **依赖**：上线前必须完成：① 挂载 Google Ads MCP 工具；② 提供客户 ID 或可访问的经理账户；③ 确认转化跟踪已部署。

### 附加约束：产品信息不完整

- 智能随行杯：首发日期未定 → 无法排定媒体投放周期；防水等级与食品接触材料报告缺失 → 影响合规宣称与详情页内容。
- 星河笔记 2.3：定价与目标用户未提供 → 无法制定获客成本上限与渠道优先级。

### 5.3 Google Ads 渠道——按 Skill 诊断框架的监控方案

由于 MCP 工具与凭据缺失，以下为**待执行的诊断框架**，非实际数据输出。

#### 5.3.1 上线前准备（阻断项）

按 Skill「Identifying Active Client Accounts」工作流，上线前必须：

1. 调用 `list_accessible_customers` 获取可访问客户列表；
2. 对每个客户执行 GAQL 查询筛选活跃子账户：

```sql
SELECT
  customer_client.id,
  customer_client.descriptive_name,
  customer_client.status,
  customer_client.manager
FROM customer_client
WHERE customer_client.status = 'ENABLED' AND customer_client.manager = FALSE
```

3. 仅对 `ENABLED` 且非 `manager` 的账户执行后续诊断。

> **当前状态**：步骤 1-3 均无法执行（MCP 工具未挂载）。**阻断**。

#### 5.3.2 投放中诊断工作流（查询模板）

**Workflow 1：转化与转化价值流失诊断**

当转化量或转化价值突然下降时，按 Skill 步骤执行：

```sql
SELECT
  campaign.name,
  metrics.conversions,
  metrics.conversions_value,
  metrics.cost_micros,
  segments.date,
  segments.device,
  segments.conversion_action
FROM campaign
WHERE segments.date >= '{start_date}' AND segments.date <= '{end_date}'
```

- 注意：`metrics.cost_micros` 需除以 1,000,000 得到标准货币金额（Skill 明确标注）。
- 按 `segments.device` 隔离是否为特定设备（移动端/桌面端）流失。
- 若使用离线导入，查询 `offline_conversion_upload_conversion_action_summary` 检查管道健康；若返回空结果，按 Skill 要求**立即停止并报告「无离线上传数据」**，不得重试或生成自定义脚本。

**Workflow 2：展示份额机会诊断**

```sql
SELECT
  campaign.name,
  metrics.search_impression_share,
  metrics.search_rank_lost_impression_share,
  metrics.search_budget_lost_impression_share
FROM campaign
WHERE segments.date >= '{start_date}' AND segments.date <= '{end_date}'
```

- `search_budget_lost_impression_share` 高 → 预算受限，考虑加预算；
- `search_rank_lost_impression_share` 高 → 广告排名低（出价或质量问题），考虑优化出价/质量得分。
- 注意：展示份额值可能为小数（0.35 = 35%）或格式化字符串（如 `"< 0.10"`），解析时需兼容两种格式（Skill 明确标注）。

**Workflow 3：低线索量诊断**

1. 确认下降：按日期分段查询转化量，对比近期与前期；
2. 隔离原因：检查流量（点击/展示）是否下降 → 若是，走 Workflow 2；检查转化率是否下降 → 若是，按 `segments.device` / `segments.conversion_action` 细分；
3. 检查变更：查询 `change_event` 资源，确认下降时间点附近是否有出价/预算/定向变更。

```sql
SELECT
  change_event.change_date_time,
  change_event.change_resource_name,
  change_event.resource_change_operation,
  change_event.changed_fields
FROM change_event
WHERE change_event.change_date_time >= '{start_date}' AND change_event.change_date_time <= '{end_date}'
LIMIT 10000
```

- Skill 约束：`change_event` 查询必须带 `LIMIT ≤ 10000`、必须按 `change_date_time` 过滤且在过去 30 天内、不可选择 `metrics.*` 字段。

**Workflow 4：离线转化上传管道诊断**

```sql
SELECT
  offline_conversion_upload_conversion_action_summary.conversion_action_name,
  offline_conversion_upload_conversion_action_summary.successful_event_count,
  offline_conversion_upload_conversion_action_summary.total_event_count,
  offline_conversion_upload_conversion_action_summary.status
FROM offline_conversion_upload_conversion_action_summary
```

- 若返回空 → 按 Skill 要求立即报告「无离线转化上传数据」，停止诊断。

- **可执行**：渠道策略方向、关键词规划、广告文案框架、诊断查询模板。
