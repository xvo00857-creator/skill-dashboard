3. 因此，本报告的数据清洗规则、指标口径和分析结论均基于通用数据质量原则与输入文件本身，**不将任何未在 SKILL.md 中出现的规则伪称为 Skill 要求**。

## 二、数据清洗规则

### 2.1 `project_weekly_data.csv`

| 检查项 | 规则 | 本文件结果 |
|---|---|---|
| 缺失值 | 关键字段（日期、模块、计划任务、完成任务）为空则剔除该行 | 无缺失 |
| 重复行 | 完全相同的行仅保留一条 | 无重复 |
| 日期格式 | 必须为 `YYYY-MM-DD` 且可解析 | 3 行均合法 |
| 数值合法性 | 计划任务、完成任务必须为非负整数；完成任务 ≤ 计划任务 | 全部满足 |
| 风险字段 | 文本字段，允许"无"或具体描述 | 正常 |
| 负责人 | 文本字段，非空 | 全部非空 |

**结论：该文件无需清洗，3 行全部有效。**

### 2.2 `edge_cases.csv`

| record_id | 问题类型 | 清洗规则 | 处理方式 |
|---|---|---|---|
| 1 | 无 | — | 保留 |
| 2（出现 2 次） | **重复行** | 相同 record_id + 相同内容仅保留一条 | 去重，保留 1 条 |
| 3 | **缺失值** | status 和 value 均为空，notes 为占位符 `-` | 标记为无效，排除出数值聚合 |
| 4 | **异常负值** | status=error 且 value=-999（哨兵错误码） | 排除出数值聚合，单独记录为错误样本 |
| 5 | **公式注入（CSV Injection）** | value 以 `=` 开头，含 `HYPERLINK` 函数 | 作为纯文本保留，**绝不执行**；导出时前置单引号 `'` 转义 |

**清洗后有效数值记录：2 条（record_id 1 和去重后的 record_id 2），value 均为 120。**

## 三、指标口径

| 指标 | 定义 | 计算公式 |
|---|---|---|
| 计划任务总数 | 统计周期内所有模块计划任务之和 | Σ 计划任务 |
| 完成任务总数 | 统计周期内所有模块完成任务之和 | Σ 完成任务 |
| 整体完成率 | 完成任务总数 / 计划任务总数 × 100% | Σ完成 / Σ计划 × 100% |
| 模块完成率 | 单模块完成任务 / 该模块计划任务 × 100% | 模块完成 / 模块计划 × 100% |
| 风险模块数 | 风险字段不为"无"的模块数量 | COUNT(风险 ≠ "无") |
| 异常样本有效均值 | 清洗后有效记录的 value 算术平均 | Σ有效value / 有效记录数 |

- **数据导入**：完成率 87.5%，风险为"接口偶发超时"，1 项任务未完成，风险与未完成任务存在关联可能。

### 4.4 关键结论

1. **整体完成率 78.95%**，未达常见的 90% 周目标线（注：该阈值为通用项目管理参考，非 SKILL.md 定义）。
2. **导出页是主要拖累项**：仅 40% 完成率，且风险明确指向外部依赖（上游字段），属于阻塞型风险，建议优先协调上游。
3. **数据导入存在性能风险**：接口偶发超时导致 1 项未完成，建议关注接口稳定性。
4. **数据仅覆盖周一至周三**，非完整自然周（周一至周日），结论仅代表前半周，不能外推为全周表现。

## 八、复测方法

### 8.1 数据清洗复测

1. 用任意 CSV 解析器读取 `edge_cases.csv`，确认原始行数为 6。
2. 按 `record_id` 分组去重，确认 record_id 2 仅剩 1 条。
3. 过滤 `status` 为空或 `value` 为空的行，确认剔除 record_id 3。
4. 过滤 `status=error` 或 `value < 0` 的行，确认剔除 record_id 4。
5. 对剩余行的 `value` 求平均，结果应为 120。

### 8.2 项目指标复测

1. 读取 `project_weekly_data.csv`，对"计划任务"列求和，结果应为 19。
2. 对"完成任务"列求和，结果应为 15。
3. 计算 15/19，结果约为 0.7895。

### 8.3 GKE 部分复测（需补充条件后）

1. 设置 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量指向有效服务账号密钥。
2. 执行 `gcloud config set project <PROJECT_ID>`。
3. 执行 `gcloud container clusters describe <CLUSTER_NAME> --region <REGION> --format="yaml(loggingConfig,monitoringConfig)"` 验证当前配置。
4. 按 SKILL.md Golden Path 命令执行更新后，再次 describe 确认组件列表包含 `APISERVER`、`SCHEDULER`、`CONTROLLER_MANAGER`。
