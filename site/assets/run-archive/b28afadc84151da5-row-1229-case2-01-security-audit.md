## 四、约束、冲突与关键取舍

本审计至少覆盖以下两组约束与冲突：

### 冲突一：告警阈值 vs. 漏报风险（admin 登录失败）

- **现状**：2 次失败低于常见暴力破解阈值（通常 5 次/5 分钟），按固定阈值规则会被静默。
- **冲突**：降低 admin 账户阈值可提前捕获，但会增加告警噪音与运维负担；维持通用阈值则可能漏掉针对高价值账户的慢速/试探攻击。
- **取舍**：对高权限账户（admin、service 账户）采用**差异化阈值**（如 3 次失败即锁定 + 告警），普通账户维持通用阈值。本报告将 #2/#3 定为中危而非低危，正是基于"目标账户价值优先于绝对次数"的研判。
- **依赖**：需要 IAM 系统支持按角色配置失败策略，以及告警平台支持分级阈值。
- **风险**：差异化阈值可能被攻击者通过分布式低频尝试规避，需辅以 IP 信誉与行为基线。

### 冲突二：隐私最小化 vs. 取证完整性

- **现状**：归因依赖 `source_ip` 与 `user` 字段（#4/#5 的 IP 关联是本次定级严重的核心证据）。
- **冲突**：数据最小化原则要求对 IP/用户字段脱敏或缩短留存期；取证与溯源要求保留完整原始字段足够长时间。
- **取舍**：采用**分级留存**——热数据（如 30 天内）保留完整字段用于实时检测与取证；温/冷数据对 IP 做掩码（如保留 /24）、对用户做哈希化，仅在有合法调查授权时可逆还原。本报告在分析阶段使用完整字段，但在对外分发版本中应脱敏。
- **依赖**：日志平台需支持字段级脱敏与访问审计；法务需明确留存期限与调取流程。
- **风险**：脱敏粒度不当（如过粗）会破坏同源关联能力，导致 #4/#5 这类关键链无法重建。

### 附加冲突：日志完整性 vs. 分析确定性（malformed_record）

- #6 无法区分是采集器故障、网络丢包还是人为日志篡改。在缺少原始 syslog、采集器指标与文件完整性校验（如哈希链）的情况下，不能排除其掩盖了更严重事件。本报告将其定为低危但标注"证据链缺口"，而非直接忽略。

## 五、修复建议

### 严重（立即执行，0–4 小时）

1. **封禁源 IP**：在边界防火墙/WAF 封禁 `203.0.113.8`，同时排查该 IP 历史 72 小时全部访问记录。
2. **吊销并轮换令牌**：立即吊销 `service-a` 相关所有令牌，强制轮换；审计该令牌在事件前后 24 小时的全部操作日志。
3. **数据外泄评估**：定位 `unexpected_export` 导出的具体表/字段/行数，评估数据敏感等级与影响范围；若涉及个人信息或受监管数据，启动数据泄露响应流程并通知 DPO/合规团队。
4. **保留证据**：对 #4、#5 及相关原始日志做只读快照与哈希存证，禁止修改或删除。

### 高危（24–72 小时）

5. **最小权限与 scope 强制校验**：在 API 网关实施 token scope 白名单校验，越权请求实时拒绝（而非仅记录）；令牌绑定服务身份与源 IP 段。
6. **服务账户行为基线**：为 `service-a` 等服务账户建立正常行为基线（调用接口、时段、数据量），偏离即告警。
7. **数据库导出管控**：对数据库导出操作实施双人审批/工单制，禁止 `unknown` 或未认证主体执行任何导出；启用数据库审计日志的实时推送。

### 中危（1 周内）

8. **admin 账户加固**：启用 MFA；失败 3 次锁定 15 分钟；登录异常（新 IP、非工时）实时告警。
9. **IP 信誉集成**：将 `198.51.100.23` 与 `203.0.113.8` 加入威胁情报观察列表，关联其他资产是否受影响。

### 低危（2 周内）

10. **日志管道修复**：修复采集器 schema 校验，malformed record 进入独立死信队列并触发告警；为日志增加逐条哈希链或签名，防篡改。
11. **日志完整性监控**：对日志条数、字段完整率建立每日巡检指标。

## 七、依赖与未决事项

- **依赖**：API 网关支持 scope 强制校验；数据库支持导出审批与审计；IAM 支持按角色差异化失败策略；日志平台支持字段级脱敏与哈希链。
- **未决事项**：
  1. `unexpected_export` 的具体数据内容与行数需从数据库审计日志进一步确认（本 CSV 未提供）。
  2. `malformed_record` 的根因需采集器侧日志与网络指标佐证。
  3. `198.51.100.23` 与 `203.0.113.8` 是否为同一攻击者基础设施，需威胁情报关联确认。
- **本报告不做的事**：未封禁任何真实 IP、未吊销任何真实令牌、未修改任何系统配置；所有修复建议为待执行项，需在授权变更窗口内实施。
