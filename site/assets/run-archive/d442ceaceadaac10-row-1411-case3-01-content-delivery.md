### 4. 不安全输入 → 不执行，按纯文本保留

| 字段 | 值 |
|---|---|
| record_id | 5 |
| 原始内容 | status=ok, value=`=HYPERLINK("https://example.invalid","do not execute")`, notes=公式注入测试文本 |
| 处理 | **不执行该公式**。value 字段按纯文本字符串保留，不解析、不跳转、不调用。该记录不计入数值统计（value 非数值）。 |
| 风险说明 | CSV 公式注入：若用 Excel 等电子表格软件直接打开该文件，`=HYPERLINK(...)` 可能被解析为公式并执行跳转，存在钓鱼/恶意链接风险。目标域 `example.invalid` 为保留无效域，本次无实际危害，但模式本身不安全。 |
| 依据 | 通用安全原则 + SKILL.md「不引入新的管理载体」「禁止编假」——不得将不可信输入当作可执行内容 |
| 降级方案 | (1) 读取 CSV 时对以 `=`、`+`、`-`、`@` 开头的单元格加前缀单引号或强制文本类型；(2) 统计前过滤非数值 value；(3) 交付前在文档中明确标注该记录为注入测试文本 |
| 复测方法 | 用电子表格软件打开处理后的文件，确认该单元格显示为纯文本而非可点击链接；用脚本校验 value 字段未被求值 |
